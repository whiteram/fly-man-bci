# bci/condstate12：各状态的头皮检测账——事件检测状态中性，静息态检测才是状态的正确应用

锁程序（condstate1-11）全部落在网络层；本弧线把状态接回项目的
主叙事（BCI 检测墙）：**同一个 A+ 驱动事件（KCg-m 1600 +
DAN_err 800，[17,19] s 或各弧训练窗）在五种网络状态下，
2-20 Hz 带通逐导 RMS 的头皮签名与 trials-to-d' 账**
（N = (2·bg/sig)²，bg = 11.4 µV；pitfall-#10 安全——不用 |mean|）。

闩锁臂现场验证成态（MBON 206.6 / ALPN 217.9）。pitfall #10 的
「693 Hz 闩锁 |mean| 0.73 µV」确认为 |mean| 度量伪影——band RMS
下**不存在事件放大**。

## 三个结论

1. **事件检测状态中性甚至受损**：静默锁（×0.89-1.00）与高锁
   （×1.11）不改变驱动事件的头皮签名；深状态（残留 ×0.16、
   闩锁 ×0.33）反而压低——AL 背景活动占据反应头寸，驱动响应
   的相对调制变小。「更大的活跃群体 → 更大的头皮事件」直觉
   不成立：事件签名由受驱的中央区室决定，不由状态背景决定。
   **检测墙不因状态移动（~2×10⁵ trials @ 此驱动）**。
2. **静息态检测才是状态的正确应用**：高锁的自发头皮活动
   0.083 µV = 幼稚底噪的 **75×**，trials 7.5×10⁴——全程序
   最佳 fly 读数之一（比事件预算好 3×）；残留 ×25、闩锁 ×13、
   静默锁 ×4。**状态本身就是信号**：读「苍蝇在什么状态」比读
   「苍蝇听到了什么」更省预算。
3. **应用排序**（本项目语义）：视觉 SSVEP 事件（0.25 µV，
   ~8.5×10³ trials）仍是最优信道；状态调制（高锁静息 7.5×10⁴）
   是状态时代的增量信道；状态内事件检测无增益且深状态有害。

## 诚实边界

best-electrode 选择在信号上做（乐观偏置；mean-electrode 低
~25% 但排序不变）；bg 取常数 11.4（历史日志 11.15-12.84）；单
种子（62）；静息窗取驱动前 2 s（高锁/残留的静息签名是持续自持
活动，窗口选择不敏感——c2 静默锁 1-1.9 s 与 12-15 s 窗一致）；
闩锁臂 t_end 22 s 单臂。
