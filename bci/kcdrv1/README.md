# bci/kcdrv1：平台态 KC +6 Hz 的驱动源定位

> **修订（2026-09-23，bci/kcdrv3）**：本文的「DAN→KC 兴奋行承接
> +6」归因已降级——kcdrv3 在静默锁与中层闩锁内直接注入 DAN 均
> 阴性，且本文所用的 sleep-era 平台态在今日代码不可复现（状态
> 地貌时代漂移）。奖励通道接管的 **MBON 分支**（DAN→MBON 直连
> 重道 w26）成立；**KC 分支**降为「与 DAN 锁相、未经因果确认」。
> 详见 bci/kcdrv3/README.md。

sleep7 留下的开口：平台态对点火脉冲的 KC 增量（+6 Hz）来自中央
直驱还是 ALPN 残余？纯分析 sleep5 既有 1-ms 群体轨迹（KC/MBON/
ALPN/DAN），零新采集——答案在**因果排序**里。

方法：对每个延迟点文件（D=35/50/80 s），幼稚相 p1 脉冲（0.8-2.8 s，
基线 [0,0.7] s）与平台相 p2 脉冲（[D, D+5] s，基线 [D−8,D−2] s）
各算 20 ms 平滑增量轨迹；KC 与各候选驱动的滞后互相关
（±100 ms，5 ms 步）；onset 用 10% 峰值阈值（跨群体峰值差 40×，
仅作参考，排序以 xcorr 为准）。

## 结果：谁领先 KC 按状态翻转

KC 与候选驱动的互相关（「超前 ms (r)」，正 = 候选领先 KC）：

| 相 | ALPN | MBON | DAN |
|---|---|---|---|
| **幼稚**（p1） | **+5 (0.96)** | −5 (0.98)（KC 领先） | 0 (0.91) |
| **平台**（p2, D=35/50/80） | +15~75 (0.38-0.49) | **+15~20 (0.94-0.95)** | **+60~80 (0.88-0.92)** |

- 幼稚相 = 标准前馈级联：ALPN 先于 KC 5 ms、KC 先于 MBON——
  DAN 随 MBON 动（在 KC 之后，因果上不可能驱动 KC）。
- 平台相 = 链路换轨：**DAN/MBON（中央链）领先 KC**，ALPN 与
  KC 只剩微弱共享方差（r 0.38-0.49，且 onset 在 KC 附近或之后）。

## 布线证据（CEN_C 表，区域键 693698e48fa257ee3380）

- **DAN→KC：5,608 行，100% 兴奋性（sign=+1），均权 6.43，
  权重和 36,034**——「突触级 US 递送」通道真实存在且是强边量级。
- MBON→KC：仅 258 行、96% 抑制、权重和 1,585——排除「MBON
  领先 KC」的直连解释；MBON 的 15-20 ms 领先是中央复发的时钟信号。
- LAL→KC：仅 21 行——脉冲不经 LAL 直达 KC。

## 结论：奖励通道接管，感觉腿让位

平台态 KC +6 Hz 的驱动源 = **中央链经 DAN→KC 兴奋行**，非 ALPN
残余。机制叙述：平台态 AL 引擎钉死（sleep7）→ 感觉通道（ALPN→KC）
增益坍缩；点火脉冲的中央复发先点亮 DAN/MBON（~200 ms）→ 经
DAN→KC 兴奋行抬起 KC（滞后 60-80 ms）。**KC 腿没死，是换了条
腿**：同一 KC 群的应答通道从感觉（ALPN→KC）切换为奖励（DAN→KC），
按网络状态启用的底物切换——与 condit3「PN→KC 被 CEN_C 工作点
压制」互补：被压制的是感觉腿，奖励腿不在压制集内。

语义侧写：平台态的「变蝇人」对世界的应答不再走感知通道，走
内部价值通道——外部脉冲进来，网络用奖励系统的方式回应。

诚实边界：单种子；xcorr 滞后是锁相证据而非突触因果证明（但布线
方向 + 幼稚相反例 + MBON→KC 排除构成三角定位）；onset 阈值跨
群体不可比（峰值归一），排序以 xcorr 为准；滞后分辨率 ±5 ms。
