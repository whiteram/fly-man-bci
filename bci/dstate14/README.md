# bci/dstate14：锁的解除——参数路治愈存在，无迟滞

dstate5 的「无动力学退出」与 dstate2/7/8 的形成边地图之间，最后
一个未测问题：**已建立的锁对增益下调作何反应**？新运行时旗标
`--gain-schedule t_ms:GRP=f`（步进钩子改 g_unit，GPU 层运行时
标量，零核心手术、无缓存键盐）实现中运行增益调度。

## 结果：形成边即退出边

| 臂 | t=30 s 调度 | pre [10,29] s | post [35,55] s |
|---|---|---|---|
| hold | 无 | 锁（19.65 / 0.0145） | **锁（20.17 / 0.0145）** |
| d0015 | ×0.75 → 0.0015 | 锁 | **部分溶解**（ALPN 7.7 / 0.0102） |
| **d001** | ×0.50 → 0.0010 | 锁 | **完全溶解=暗**（0.00 / 0.0051） |
| d0005 | ×0.25 → 0.0005 | 锁 | **完全溶解=暗**（0.00 / 0.0051） |

三个结论：

1. **参数路治愈存在**：已建立 30 s 的锁在增益跌破形成窗
   （0.0016）后完全溶解回暗态——**无迟滞**：形成边就是退出边，
   锁不携带「曾经成锁」的记忆。
2. **与 dstate5 合并的完整可逆性图**：动力学探针（感觉/点火
   脉冲）全部被吸收（锁内不可出）；**增益参数轴是唯一的退出
   通道**，且完全可逆、方向对称（降增益即解、回增益+脉冲即
   再成锁——dstate8 的补偿臂证明上行同样有效）。
3. **边缘过渡**：0.0015（窗下缘外一点）给出中间态残留
   （ALPN 7.7）——与 dstate3 窗图的 0.0015 无锁一致，窗缘处
   吸引子渐弱而非跳变。

「变蝇人」语义收束：静默锁是**增益依赖的可逆吸引子**，不是
永久损伤——「固化」的不可逆性是**动力学意义**的（无探针可出），
不是结构意义的（参数可解）。治疗学上的注脚：解开它的开关存在，
就是那个把它关上的旋钮反向旋转。

诚实边界：单种子；调度分辨率=1 步（0.5 ms）；只测了降增益
方向（回升再成锁由 dstate7/8 的形成数据外推）；「溶解后重暴露
是否更快成锁」（痕迹假说的最后残余）未测。
