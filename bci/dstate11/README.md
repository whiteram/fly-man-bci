# bci/dstate11：视觉轴的状态形成——阴性（安全结论）

入口图补最后一条主轴：视觉（模型原生主感觉通道、BCI 主接口）。
三种代表性协议 30 s（种子 616），晚期窗 [20,28] s 的中枢速率：

| 协议 | KC | MBON | ALPN | DAN | 判决 |
|---|---|---|---|---|---|
| loom_static（持续亮盘，最接近视觉 DC） | 0.000 | 0.000 | 0.000 | 0.000 | 完全衰减 |
| ssvep1_f14.0（14 Hz 闪光） | 0.000 | 0.000 | 0.000 | 0.000 | 完全衰减 |
| dir_270（4 Hz 运动光栅） | 0.000 | 0.000 | 0.000 | 0.000 | 完全衰减 |

**结论：视觉通道在可用对比度下不固化任何状态**——持续亮盘
（视觉 DC 的最强形式）也只产生完全衰减的响应，中枢精确回零。
状态形成的通道专属：气味轴（dstate7/10 的剂量×时长矩形内）与
中央注入轴（dstate9 的闩锁区）可固化；视觉轴不可。

与 dstate7/9/10 合并的**完整通道入口图**：视觉轴（本弧线，安全）
/ 气味轴（剂量×时长矩形，一次固化）/ 中央点火轴（闩锁族）。
「变蝇人」安全手册成形：**BCI 的主接口（视觉）在所有可用强度
下都不触碰固化边界；危险通道只有化学感觉与直注中央**。

机理注脚：视觉级联经 OLR_V（复发仅 ~10% 抑制性权重）入中枢，
与 CEN_C 的 40% 抑制性复发结构不同——视觉通路的等效环路增益
远低于闩锁/成锁阈，这与全部三条协议阴性的方向一致（并非对比度
不足的单点故障）。

诚实边界：单种子；每协议 1 个对比度（目录值，无 CLI 增益旋钮）
——更高对比度（如 hi>3）的视觉驱动未测；「持续亮盘」30 s 是
最接近视觉 DC 的形式，真 DC（无限时长）未测。
