# bci/sign4：逐腿再平衡手术——sign 重标定程序的终审判决

sign3 把路线收窄到「ALL 组按边符号拆分、E/I 腿独立缩放」。本弧线
实现该手术（**新旗标 `--al-leg-balance "E,I"`**：ALL 表内兴奋行
(sign=+1) 权重 ×E、抑制行 (sign=−1) ×I，ckey 盐 `+albE-I`）并做
二维（增益 × 平衡）判决扫描。

## 结果：2D 网格仍是「死或闩」

| 臂（增益, E,I） | ALPN A1 | 尾段 | 判决 |
|---|---|---|---|
| 0.002, 1.0/0.5 | +0.18 | 0 | 死 |
| 0.002, 1.0/0.3 | +0.19 | 0 | 死 |
| 0.002, 1.0/0.7 | +0.17 | 0 | 死 |
| 0.002, 1.5/1.0 | +0.14 | 0 | 死 |
| 0.003-0.004, I=0.5/0.3 | +0.16 | 0 | 死 |
| **0.005, I=0.5** | +0.14 | **166** | 闩 |
| **0.005, I=0.3** | +0.18 | **177** | 闩 |

10 个格点无一给出分级响应；**A1 在任何配置下不超过 0.19 Hz**
（base 11.3），从死到闩的过渡不经过任何模拟区。平衡旋钮只微移
闩阈（I=1.0 的积累闩点 0.005-0.007 → I=0.3/0.5 的 0.005），不
改变现象学。

## 终审：放大器 vs 继电器

三个弧线（sign2 幅度、sign3 组增益、sign4 二维平衡）的合并判决：

**全兴奋复发在 sign-off 模型里执行的是模拟放大功能（连续增益、
分级响应）；换成真符号后同一环路变成双稳继电器（不开不关，无
模拟区）。34× 气味塌缩不是参数失标定，是计算结构的差别。**

因此：**任何权重/增益/平衡参数调优都无法在现电路上恢复 sign 模型
的气味功能**——需要的是重构（新增兴奋性中间神经元类替代被抑制
腿吃掉的环路功能，或重新推导的权重集），超出重标定范畴。
sign-on 变体的定位就此明确：**癫痫受控但气味-AL 功能是继电器式
的**——作为「真抑制保真」的对照模型保留（`--use-sign-all` /
`--use-sign-groups`），不做功能等价重标定。

机制细节：A1 响应在所有配置下钉在 ~0.15 Hz ≈ ORN→PN 前馈直通
分量——环路在阈下贡献为零、阈上全部自持，没有渐变段。sign-off
模型的 11.3 Hz A1 里 ~98% 是环路放大（11.3 vs 0.15），这给出
放大器贡献的直接测量。

诚实边界：单种子；2D 网格 10 点（步长 0.001×0.2），更细网格
不能绝对排除窄于步长的窗口，但 A1 全程 ≤0.19 Hz 的平坦性强烈
表明阈下环路贡献为零而非「窄窗待找」；按方向拆分（PN→LN vs
LN→PN 独立增益）形式上未测，但在「响应从不变为分级」的证据面
前预期相同。
