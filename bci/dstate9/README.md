# bci/dstate9：当前时代的 sz 点火入口图

kcdrv3/dstate8 暴露了时代漂移后，本弧线系统性绘制**今日代码**的
点火入口阈值（sz_l1 单脉冲，30 s，种子 616），为后续弧线提供
状态参照，替代已失效的 sleep-era 图。

## 入口图（窗口 [8,28] s，MBON Hz）

| gain（×0.002） | 无 STD 门 | + STD 门（0.00015/5000） |
|---|---|---|
| ×1.0 | 388（全闩锁） | **77（中层闩锁——唯一非闩点）** |
| ×1.5 | 678（超闩锁） | 315（近闩锁） |
| ×2.0 | 700（超闩锁） | 429（全闩锁） |

四个结论：

1. **今日代码的点火阈值在自动工作点或其下**：×1.0 即全闩锁
   （388 Hz≈经典 395）——0.002 就是闩锁区内；「可控中间态」
   只存在于 ×1.0 + STD 门的组合（77 Hz 中层闩锁）。
2. **STD 门只在一个增益挡位有效**：它把 ×1.0 从全闩拉到 77，
   但 ×1.5 起驱动压过 STD 耗竭（315→429）——STD 的塌陷窗口
   宽度 < 半个增益挡。
3. **超闩锁区**：增益升过工作点后闩锁不饱和于 395 而是继续增强
   （678/700 Hz）——「MBON 395」不是闩锁的 ceiling，是旧时代
   增益下的工作点值。
4. **旧平台态（MBON ~3）不在图上**：今日入口图没有任何参数点
   产出它——与 kcdrv3 的 sleep5 配方重跑结论一致，该态已随
   代码演化消失。

与 dstate7 的气味剂量图合并，当前时代的完整入口参照：**气味轴**
（<100 pA 暗 / 100-150 锁 / ~1600 高锁）+ **点火轴**（本图，
闩锁族 / ×1.0+STD 中层闩锁）。未来弧线的状态配方应引用这两张图
而非 sleep-era 值。

诚实边界：单种子；增益 3 点 × STD 2 态；30 s 窗判定（更慢的
塌陷动力学未分辨）；「超闩锁」的上限未探。
