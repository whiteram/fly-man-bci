# bci/condstate44：静默锁诱导阈值定位——(150,175] pA 的全有全无双稳闩锁

## 问题

cs42/43 留下"seed-63 点火阈值在 (150,300] pA 内未定位"。本弧补
5 个 20 s 剂量臂（175/200/225/250/275 pA，新 chem 条目
cs44d{amp}，seed 63，dangate2 全套旗标；~3 min/臂串行）+ 三个
已知端点（cs42 150 不燃 / cs2·cs43 300 燃 / cs21 62@150 燃）。
点火判据：脉冲后 2-20 s ALPN 均值 ≥10 Hz（燃 ≈19.7 / 不燃
0.000 的双峰中间）。

## 结果（outputs/ignition_threshold_stats.json）

| DA1 剂量 | 脉冲窗峰 | 脉冲后 2-20 s 均值 | 点火 |
|---|---|---|---|
| 150 pA | 1.47 Hz | **0.000 Hz** | ✗ |
| **175 pA** | **35.29 Hz** | **19.46 Hz** | ✓ |
| 200 pA | 36.8 Hz | 20.04 Hz | ✓ |
| 225 pA | 32.4 Hz | 20.29 Hz | ✓ |
| 250 pA | 38.2 Hz | 19.79 Hz | ✓ |
| 275 pA | 33.8 Hz | 19.89 Hz | ✓ |
| 300 pA | 35.3 Hz | 19.81 Hz | ✓ |
| （62@150 参照）| 29.4 Hz | 19.98 Hz | ✓ |

**三个判定**：

1. **阈值括号 (150,175] pA**——seed 63 的点火阈值比 62 高不出
   17%：cs42 的"诱导脆弱性"收窄为**窄幅种子阈值移动**，不是
   巨大剂量缺口；
2. **全有全无（双稳闩锁）**：无任何中间态（0.5-10 Hz 区间零
   占据）——剂量增加 17% 使脉冲窗峰跳 24×（1.47→35.3 Hz），
   而一旦点燃，稳态引擎率与剂量无关（19.5-20.3 Hz 平坦）。
   AL 复发环路是标准双稳系统：剂量只决定**能否捕获**，不决定
   捕获后的运行点；
3. **对状态诱导协议的含义**：跨个体（种子）转移一个诱导配方
   需要留出 ≥~20% 的剂量余量（62 校准的 150 pA 落在 63 的
   阈下 17% 处）——这是"状态存在性种子门"（cs42）的定量版本。

## 语义

- 与 cs42/43 合成完整的诱导-寿命图景：**进入**是全有全无的
  种子敏感阈值（(150,175]），**进入后**的签名与寿命是连续的
  种子敏感漂移（τ 2× 散布）——两道独立的种子脆弱性；
- 引擎侧证词：双稳 + 剂量无关稳态与 cs35-39 的"尖峰梳引擎"
  图景一致（自持群齐射有固定点，不随输入幅度缩放）。

## 诚实边界

- 阈值括号 25 pA 宽（未二分细化）；单 trial/剂量（双稳系统
  的确定性使重复无意义，但未在中间剂量验证）；
- 仅 seed 63 扫描；62 的阈值只知 ≤150（未下扫）——"两种子
  阈值差 ≤17%"是上界表述；
- 20 s 臂只验证短时自持（300 s 自持已由 cs43@300 证明）。
