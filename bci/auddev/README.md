# bci/auddev：听觉偏差检测（MMN 类，诚实阴性）

单侧列车范式：双侧 JO-A 群 600 pA，四个 500 ms 脉冲歌爆发（25 Hz
包络），第三段换成 50 Hz 包络（偏差），比较偏差段与相邻标准段
（适应水平匹配）。MMN 的"预测误差"机制本模型没有；可检验的只是
外周/脑干级偏差响应。

## 结果（6 runs）

| 比较 | 结果 |
|---|---|
| 偏差段（50 Hz）1.3934 µV vs 相邻标准段（25 Hz）1.3939 µV | 差 −0.0005，**p=0.874 阴性** |

**机制解释**：PhotoCascade 适应的是**平均亮度/驱动水平**——25 Hz
与 50 Hz 包络占空比相同（各 50%），平均输入相同，故适应后响应
无差。要产生包络-速率偏差响应需要速率敏感的适应机制（如突触短时
抑制），列为机制方向而非范式调参。

## 用法

```bash
python bci/auddev/acquire.py
python bci/auddev/analyze.py
```
