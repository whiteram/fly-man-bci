# bci/arousal：唤醒状态范式（诚实阴性 + 机制发现）

设计：`--noise-scale` 缩放全部 OU 噪声 sigma 作为"安静（0.3×）vs
活跃（1.0×）"状态代理（文档化为合成操控，非真实睡眠/注意回路），
2 状态 × {暗屏, 近阈气味 75 pA} × 4 runs，检验状态可解码性与
"信号/底噪"随状态的改善（exp018 前提的动态版）。

## 结果（16 试次）

| 检验 | 结果 |
|---|---|
| 暗态底噪：quiet 0.3× vs active 1.0× | **1.3264 vs 1.3310 µV —— 无差异** |
| 极端对照（视觉单区，噪声×0.05 vs ×1.0） | 1.6239 vs 1.6363 µV —— **仅 −0.8%** |
| 状态解码（空间模式） | 名义 100%（p=0.0255）但底噪几乎相同、每类仅 4 试次（单次完美划分的偶然概率即 1.4%）——**不可下结论** |
| 气味净响应（75 pA，按试次基线） | quiet +0.0596 / active +0.0620 µV —— **状态×刺激交互为零**（与 dose 的 +0.0598 完全一致）|

**机制发现（阴性但有信息量）**：模型的自发头皮活动由**偏置电流
驱动的基线发放**决定，不由 OU 噪声幅度决定——LIF 群体的 i_base
把细胞钉在固定发放率上，OU sigma 缩小 20 倍底噪只动 0.8%（阈值
非线性压缩了亚阈噪声变化），气味响应也完全不受影响。**OU 噪声
不是有效的状态轴**；真正的唤醒/增益调制需要动基线电流（工作点），
而那会连带改变刺激响应增益——两者在本模型里不可分离。真状态范式
（睡眠/注意）需要独立的状态机制（神经调质电流、状态依赖增益），
列为机制方向。

（工程注记：`--noise-scale` 实现保留——它正确缩放 cal["OU"] 与
extras 的 ou_sigma，只是该旋钮在当前工作点下不改变自发活动。）
