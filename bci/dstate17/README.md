# bci/dstate17：闩锁@0.002 残留态定位——AL 同点、中央余燃

零采集分析（dstate16 的 latch_dn2 vs dstate6 的高锁参照，全 AL
乐器化）。

## 成分对比（对 ALPN 归一）

| 类别 | 残留（闩锁→0.002） | 高锁（dstate6） | 比 |
|---|---|---|---|
| ALPN | 98.2 | 100.6 | ×0.98 |
| ALON | 118.9 | 118.4 | ×1.00 |
| ALLN | 284.4 | 280.0 | ×1.02 |
| ALIN | 39.0 | 54.4 | ×0.72 |
| **KC** | 17.4 | 4.0 | **×4.5** |
| **MBON** | 44.6 | 11.8 | **×3.9** |
| DAN | 2.0 | 0.6 | ×3.3 |

## 判读

1. **AL 引擎落在同一个自持点**：残留的 AL 侧与高锁逐位同点
   （三主类差 ≤2%）——增益降到锁窗中心时，AL 引擎精确回到
   「高锁」不动点（与 dstate5 的剂量路高锁、dstate7 的 1600 pA
   直达高锁是同一个吸引子的第三个入口）。
2. **深迟滞的载体是中央余燃**：残留的中央侧（KC/MBON/DAN）
   比高锁重 ~4×——全闩锁的中央复发在 0.002 下没有熄灭，只是
   衰减到余燃水平。**闩锁的退出边深（要到 0.001）不是 AL 引擎
   顽固，而是中央复发的余燃需要更低的增益才能熄**。
3. **状态组合观点**：残留 =「高锁（AL）× 中央余燃（部分闩锁）」
   的复合态——dstate16 统一图上 0.002 点的隶属从此清晰：锁窗
   中心同时是高锁的 AL 不动点与中央余燃的存活区。

诚实边界：单种子；两参照窗不同 trial（种子同 62、增益同 0.002
但入口不同——残留自全闩锁下行、高锁自 10× 剂量）；ALIN 差异
（×0.72）未深究。
