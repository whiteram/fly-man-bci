# bci/dstate2：ALPN 自持的机制归因——CEN_C 增益阶梯

dstate1 发现静默锁里 ALPN 是唯一活性群体（自持 ~20 Hz）。本实验
用静态 CEN_C 增益阶梯（`--gain-scale`，锁的形成经 ORN_C 独立腿
不受影响）归因：突触介导还是 ALPN 内源？

## 结果：复归介导 + 三台阶状态图

| CEN_C 增益 | ALPN 锁内率 | 其它群体 | \|mean\| µV | 定性 |
|---|---|---|---|---|
| 0.00005 | 0 | 全 0 | 1.3895（暗态） | 无状态 |
| 0.001 | 0 | 全 0 | 1.3895（暗态） | 无状态 |
| **0.002（工作点）** | **19.9** | 全 0 | 1.8206 | **安静锁** |
| 0.003 | **148.8** | **ALON 365 / ALLN 338 / ALIN 73 / MBON 167 / KC 47 / DAN 9.5** | 6.46 | **多群体大吸引子** |

1. **自持是复归介导的，不是 ALPN 内源**：复归 <0.001 时脉冲
   不留任何痕迹（回暗态）；0.002 恰好越过成锁阈。ALPN 只是
   锁内唯一还在阈上的群体。
2. **AL 局部回路是引擎**：0.003 处最响的是 ALON/ALLN（365/338
   Hz）——AL 内部（PN↔LN↔PN）回路在 CEN_C 里，是锁与大吸引子
   的公共底物。
3. **三台阶状态图**：无状态 → 安静锁（ALPN 独走）→ 多群体
   大吸引子 → （0.004 = 已知的癫痫完全闩锁）。**化学工作点
   0.002 正坐在第一吸引子的悬崖边缘**——exp019 标定的工作点
   之所以「一惊就锁」（mmdev2 的 DC 开关阈值远低于快响应阈值），
   是因为它离成锁阈只差 2×。这也是 sign1 里气味响应脆弱的
   同源背景：整个嗅觉标定都骑在这条悬崖上。

## 结论

- 静默锁 = **复归介导的窄窗现象**（增益 0.002±窄带），不是
  ALPN 内源，也不是噪声——是复归刚好把 ALPN 顶在自持阈上。
- dstate1 的「开关阈值≪快响应阈值」之谜有了机理解释：快响应
  （ORN→CEN 直驱）与成锁（复归正反馈过阈）是两条腿，后者阈值
  低是因为工作点贴着成锁阈。
- 后续：锁窗宽度精确化（0.002–0.003 之间细扫）+ AL-local 拆分
  手术（把 AL 内部行拆成独立组做增益归因）为直接深化。

诚实边界：单种子；g150 处的 6.46 是 |mean|（abs 口径）；三台阶
由 4 个增益点支撑（0.0025–0.003 之间未细扫）。
