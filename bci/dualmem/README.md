# bci/dualmem：短/长时记忆分离——KC 子区室双恢复时间常数

果蝇记忆区室化的模型实现：KCM 按**突触前 KC 子类型**拆两组，
各自独立恢复常数（`--plastic-dual-tauw 30000,300000`）：

| 组 | 子类型 | tau_w | 生物学对应 |
|---|---|---|---|
| KCMg | KCg*（γ，1,548 细胞，14,298 对）| 30 s | γ 瓣 = 短时记忆 |
| KCMab | 其余（α/β 样，19,100 对）| 300 s | α/β 瓣 = 长时记忆 |

试次 5.2s：训练驱动**全 KC**（两组同学习）+ PAM 奖励；**每试次
双探针**——γ 窗 4.2-4.45s（KCg*）、α/β 窗 4.6-4.85s（KCab*）。
session = 获得 8（dual1）+ 消退 8（dualx 撤奖，仅恢复）。

## 结果

**机制层（w 轨迹，双 session 逐位一致）：**

| 阶段 | KCMg (γ) | KCMab (α/β) |
|---|---|---|
| 获得平台 | 0.16 | 0.03（慢恢复少对抗 → 更深）|
| 消退 8 试次 | 0.29→0.41→0.50→…→**0.79** | 0.05→0.08→…→**0.15** |

消退后 **γ w=0.79（几乎遗忘）vs α/β w=0.15（保持 5.3×）**——
区室化分离在机制层是压倒性的。

**头皮层（双探针净响应曲线，4 session）：** 获得双升（~0.31→0.40
平台）；消退 **γ −43%（0.394→0.226）vs α/β −19%（0.406→0.330）**，
4 个 session 全部同向（γ 斜率在每个 session 都更陡）；斜率差
−0.0082 µV/试次，置换 p=0.121——**恰为该检验的精确下限**（session
内交换的 16 种组合中只有恒等与全换达到 |obs|，2/16=0.125）：
四 session 全同向时可能的最强证据。机制层为逐位一致的双生曲线
（确定性），头皮层方差大——显著性的瓶颈是 session 数而非效应。

## 设计要点与诚实性边界

- 训练协议两组完全相同——分离**只**来自 tau_w 差（单一变量）；
- 恢复仍为同稳态性质（非反 Hebbian）："短时 vs 长时"= 恢复时间
  常数的映射，不是独立记忆系统；
- α/β 探针只覆盖 KCab*（KCa'b' 695 细胞被训练但不被探针读出，
  文档化）；
- 头皮读出受 condit3"读出腿份额"约束（弱），机制层 w 为主读出。

## 用法

```bash
conda activate ffbm
python bci/dualmem/acquire.py --pilot        # 1+1 链检查
python bci/dualmem/acquire.py --sessions 4   # 4 session × 16 试次（断点续跑）
python bci/dualmem/analyze.py                # 双曲线 + 消退斜率差置换
```
