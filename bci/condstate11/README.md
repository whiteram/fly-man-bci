# bci/condstate11：稳健性抽检——租金比跨家族复现，微池载体身份降级为种子特定

两个单家族（seed 62 为主）的头条结果用新种子家族（2042/2092，
seedchk1 惯例）抽检：cs2ctl/cs2lock 配对 ×2 家族，带 w 状态输出
与 per-neuron 记录（记录不影响仿真）。

## 结果 1：租金比复现（头条稳固）

| 家族 | ctl w_A | lock w_A | 比值 | 锁检查 |
|---|---|---|---|---|
| 62（condstate2） | 0.05682 | 0.05160 | 0.805 | 19.4 ✓ |
| 63（condstate2） | 0.05700 | 0.05150 | 0.796 | 19.6 ✓ |
| **2042** | 0.05543 | 0.05002 | **0.787** | 19.6 ✓ |
| **2092** | 0.05528 | 0.05055 | **0.813** | 20.6 ✓ |

四家族 0.787-0.813——**静默锁租金 ~20% 是家族稳健的**。

## 结果 2：微池载体身份是种子特定的（诚实纠偏）

MBON09 逐细胞计数（raw；s62 来自 condstate9 同文件）：

| 家族 | ctl | lock | 池总量变化 |
|---|---|---|---|
| 62 | [283, 613, 180, 638] | [628, 237, 649, 651] | **+26%** |
| 2042 | [268, 296, 597, 695] | [211, 671, 74, 122] | **−42%** |
| 2092 | [265, 653, 745, 677] | [245, 196, 741, 144] | **−43%** |

**池总量方向跨家族翻转**（+26% vs −42%/−43%），让位/点亮的细胞
身份每家族不同；MBON11（s62 趋同 / s2092 单细胞崩）、MBON30
（轻度）同样不一致。**判读**：

- condstate7 的「载体 = MBON09/30/11/03/31 微池」**降级为
  seed-62 实现**——哪些具体微池在锁内增 firing 是种子调味；
- 稳健的表述在**类级**：GABA 子集的工作点整体移动（Vsub 积分
  跨臂相似、租金比跨家族恒定）与**细胞级**（按 GABA 收敛度
  分配的钳制向量，condstate9 的 154 细胞相关——该检验未重跑，
  但基于接触权重解剖结构，预期稳健）。
- condstate8 的载体链（KC 家族 +4 Hz × 微池集中收敛）的**收敛
  结构**部分是解剖事实（权重分布不随种子变）；**具体哪些微池
  跳变**部分是种子调味。

## 语义

租金的存在、幅度、可逆性（condstate1-2/10）全部家族稳健；
租金的**微观记账科目**（哪个微池、哪个细胞让位）是每次实现
的细节——类比：税额固定，税单上的科目名随机。对「变蝇人」
叙事无影响；对机制语言的要求：说「GABA 子集工作点移动」，
不说「MBON09 载体」。

## 诚实边界

每家族 n=1 配对（共 4 家族）；condstate9 的钳制向量相关未在
新家族重跑（预期稳健但未证）；2042/2092 家族的 KC 家族类型
未记录（Vsub 分解不可比）。
