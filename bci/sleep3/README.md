# bci/sleep3 — 慢变量双稳态 + STD 恢复盘错误修复

前置：[bci/sleep2](../sleep2/README.md) 鉴定上行态维持者 = CEN_C 复发
（全增益 0.004 的兴奋锁定吸引子；饱和放电 MBON ~390 Hz）。机制 14
遗留问题：当时的 STD 门「从未咬住维持电流」，双稳态不可达 —— 归因
候选是 τ_rec 太快秒级回满。本轮按「慢变量」路线重做，结果发现并
修复了一个**潜伏的计算 bug**，它本身就是机制 14 遗留问题的答案。

## Bug：STD 恢复每步瞬时回满（任意 U 下 STD 无效）

现象链（U 扫描 0.001→0.2 全部与对照逐位相同 → U=0.9 判别试验也无
效 → 单细胞逐脉冲探针）：

```
spike 1: d 1 -> 0.1        ✓ 耗竭正确
step 后:  d 0.1 -> 0.99998 ✗ 一步回满！
spike 2: d 0.99998 -> 0.1  （从回满态再耗竭）
```

根因（GPU `k_std_rec` 与 CPU 孪生同错）：

```c
d[i] += (1.0f - d[i]) * rec;        // 错：rec=exp(-dt/τ)≈1 → 一步拉平
d[i] += (1.0f - d[i]) * (1.0f-rec); // 对：每步恢复 dt/τ 份额，时标 τ
```

后果：稳态 d≈1−ε，STD 在**任何** (U, τ) 下都是无效门 —— 这正是机制
14「STD 门从未咬住维持电流」的真相（非动力学原因）。历史影响：
mmdev 的 std_on/std_off 对照需要重新审计（其差异至多来自单步内
的瞬态门控）；本仓库所有依赖 --std-gates 的结论在 8e42dde 之前
均不可信。

修复验证：逐脉冲探针 d 0.1→0.01→0.001→0.0001（乘性耗竭），步间恢复
0.0023%/步 = dt/τ 精确吻合；55/55 测试通过。

## 设计

`sz_l2` = sz_l 点火给两次（0.8-2.8 s 与 35-37.3 s）的 60 s 试验 ——
第二次点火在 STD 塌缩之后 = 迟滞测试（再武装的网络能否再闩锁）。
STD 只挂在维持者 CEN_C 上（sleep2 归因的直接应用）。

增益二分（塌缩判据校准）：CEN_C ×0.5 塌、×1 维持 → 维持阈值在
(0.5, 1)×0.004 之间；STD 稳态 d_eq = 1/(1+U·r·τ) 的载流子有效增益
需压到 ~0.5 以下。

## 剂量-驻留曲线（修复后，60 s 双脉冲试验，seed 616）

| U (τ=5 s) | 行为 | 水平/rms | 上行驻留 |
|---|---|---|---|
| 0（ctl60） | 完整闩锁 | 10.4 µV（KC 74 Hz） | ∞ |
| 1e-4 | **耗竭上行态**（新不动点） | 4.7 µV（KC 26 / MBON 112） | ∞ |
| 1.5e-4 | 更低耗竭态 | 3.8 µV（KC 12 / MBON 75） | ∞ |
| 2e-4 | 缓慢衰减到中间耗竭态 | 3.3 µV（KC 6 / MBON 52） | ∞（慢漂移） |
| 2.5e-4 | **边界态**：塌缩 + 噪声再燃 | 下态 2.4-3.0 µV，MBON 短爆发 20-45 Hz | ~4 s（KC） |
| 3e-4 | 塌缩 | 2.3 µV 地板 | ~3.5 s |
| 5e-4 | 塌缩 | 2.1 µV | ~2 s |
| 1e-3 | 点火即耗竭 | 1.8 µV | <2 s（MBON 106→0） |
| 2e-3 | 点火近乎失败 | **1.4 µV（真下态**，= sleep2 塌缩水平） | <1 s |

判据：up = >3 µV、down = <1.5 µV（1-s rms 窗）。

## 结果：慢振荡循环在 τ_rec = 10 s 涌现

**U=1.5e-4、τ_rec=10 s**（U·τ 与 3e-4×5s 同深耗竭、恢复减半）：

```
点火1 (0.8-2.8s) → 上行态 ~5 s (MBON 225→80 Hz, KC 44)
  → 耗竭累积塌缩 @ ~6-7 s (MBON 15→0.4 Hz)
  → 下行态 ~28 s @ 2.3 µV (≈3τ 再武装; MBON 1-5 Hz 残余)
点火2 (35-37.3s) → 再点燃 (MBON 99.8, KC 13.2)
  → 再塌缩 @ ~39-40 s (MBON 15→3.8)
```

**完整 UP→DOWN→UP→DOWN 慢循环**——sleep2 归因（维持者=CEN_C 复发）
+ 修复后的慢 STD = 所需的最小慢负反馈：上行态自身放电耗竭其维持
电流（d_eq = 1/(1+U·r·τ)），跨过维持阈值（增益二分定位在
0.5-1×0.004 之间）即塌缩；静默期 d 以 τ 恢复、网络再武装。

三个 regimes 的结构地图（τ=5 s）：U<2e-4 耗竭上行态族（graded
不动点：10.4→4.7→3.8→3.3 µV）、U≥3e-4 塌缩+迟滞再点火、τ 加倍
把耗竭态族整体转为塌缩态 → 循环。

## 诚实框架

- 再点火依赖外部脉冲（sz_l2 第二次焦点驱动）；自发再点火（噪声驱动
  翻转）未观察 —— 真实慢振荡的自发翻转需要本模型噪声之外的起搏源
  （清醒果蝇的睡眠压/神经调质调制在此由外脉冲代理）。
- 塌缩后的「下态」带 ~2.3 µV 残余（MBON 1-5 Hz），非静默。
- STD 门作用于整组 CEN_C（1.7M 边），无逐室粒度；U/τ 为群体标定值。
- 上行驻留 ~5 s（τ=10 s 时）由载流子放电率分布与 U·τ 共同设定，
  尚未扫到 10-20 s 驻留的组合（需 U≈1e-4 量级 + τ≥15 s，60 s 试验
  只能容纳一个循环）。
- 历史更正：机制 14 的「STD 门控=全程下行零转移」一臂在 bug 下运行
  （当时 STD 无效，该臂的下行应另有原因，如点火失败）；其结论
  「STD 未咬住维持电流」由本 bug 完全解释。mmdev 的 std_on/off
  对照需要重跑审计（8e42dde 之前不可信）。
