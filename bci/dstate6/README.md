# bci/dstate6：高锁的成分 + 300 s 自然退出试探

dstate5 留下两条线：①「高锁」（10× 探针把 20 Hz 锁升级到 ALPN
100 Hz）是 AL 引擎整体升级还是 ALPN 孤立现象？②锁在 ≫60 s 是否
自然衰减？两个零假设检验，一弧线收掉。

## hi_comp：高锁 = AL 引擎整体升级（中央参与 ≤5%）

exit_1600 重跑（种子 62，全 AL 乐器化），20 Hz 锁窗 [10,29] s vs
高锁窗 [31,50] s：

| 类别 | 20 Hz 锁 | 高锁 | 倍数 |
|---|---|---|---|
| ALPN | 20.1 | 100.6 | **×5.0** |
| ALIN | 5.5 | 54.4 | **×9.9** |
| ALON | 41.3 | 118.4 | ×2.9 |
| ALLN | 47.3 | 280.0 | **×5.9** |
| KC | 0 | 4.0 | 平台的 5% |
| MBON | 0.01 | 11.8 | 平台的 3% |
| DAN | 0 | 0.6 | 平台的 1% |

**AL 四类全部升级（2.9-9.9×）**——高锁是 AL 局部环路作为整体的
第二不动点，非 ALPN 孤立现象（ALLN 在高锁里达 280 Hz 比_ALPN 还
高，dstate1/5 的 ALPN-only 视角漏掉了主drive）。中央侧 MBON 12 Hz
与 kcdrv2 的 DAN→MBON 直连重道相容（DAN +0.6），距平台水平
（395 Hz）差 33×——中央引擎确实未点火，高锁 = AL 主导 + 边缘
中央渗漏。dstate5 的分类（std 0.017、非平台非吸引子）得到成分级
确认。

## dc300：300 s 零衰减，无自然退出

单 DA1@150（da1_dc300，300 s trial，种子 62）：三个块
[10,29]/[100,190]/[200,290] s 的 std/mean **逐位稳定**
（0.0145/0.0146/0.0146 µV，mean −1.821），ALPN 20.1/20.3/20.2。
**锁在 5× dstate1 时标内零衰减**——结合 dstate5 的探针阶梯全
吸收，静默锁的「动力学退出」在现参数空间内不存在：退出只剩
参数路（dstate2：增益 <0.001 回暗）与未来的逐腿手术（sign4）。

「变蝇人」语义补完：静默锁一旦形成即**半永久**——不是睡眠
（有进入/退出循环），是**固化**；而它的形成只需一次普通气味
脉冲（da1@150 = 满量程的 1/10 强度）。模型层上「一次暴露、
永久改变」的代价结构完整了：锁（半永久静默）→ 高锁（更强
暴露）→ 平台（点火剂量）——剂量决定固化深度，路径不可逆。

诚实边界：单种子；300 s 只排除 ≤5× 时标（∞ 自然衰减不能
证伪）；hi_comp 的中央渗漏归因（DAN→MBON 道）是速率相容性
论证非突触测量；std 口径 = 窗内原始样本 std（与 dstate1 参照
同口径）。
