# bci/condstate9：逐细胞分解——门是钳制向量不是标量，池率是活跃集边缘读数

condstate8 的否定残差（K +4.4%/V +10% 而 r −2.9 Hz 无法闭账）把
仪器推进到逐细胞：现成 `--pop-rate-neurons` 旗标 dump 每神经元
spike 计数，DAN_err（154 细胞）的身份从精确 349 行 MBMD 行重建。

## 结果 1：DAN_err 的响应基线本身双极异质

US-only 幼稚臂（154 细胞全 trial 计数）分位数：p0=1 / p25=25 /
**p50=130** / p90=212 / p100=222——**约四分之一细胞对 800 pA 化学
驱动几乎不响应，半数以上满驱动**。「DAN_err 池」从来不是同质池，
池率 r 是异质集合的均值。

## 结果 2：锁的钳制按 GABA 收敛度逐细胞分配——除法预测定量成立

usl9/usn9 逐细胞比：中位 0.903、p10=0.111、p90=1.027、21% 细胞
<0.5——**不是均匀缩放**：21% 细胞被重钳、79% 基本不动。
**钳制深度 vs 每细胞 GABA 接触权重（349 行按 post 聚合）：
Spearman rho = +0.333（p = 2.4e-5）**——除法核（v∞ =
(v_rest+R_m·i_ext)/(1+R_m·g)）的预测定量兑现：GABA 收敛越大的
细胞钳得越狠。接触权重本身 22× 跨度（5-362）。

## 结果 3：池率的微观本体 = 活跃集边缘

训练臂（ctln9/lockn9）的 DAN_err 中位细胞全 trial 计数 = 0
（p50=0、p75=1、p90=10/7、p100=238）——**全训练中只有 ~10-15%
细胞在放电，池率 14.89/12.0 Hz 是这一小撮的贡献**。lockn9 相对
ctln9：中位比 0、p90 从 10 挤到 7.1——**−2.9 Hz 残差的载体 =
活跃集边缘细胞被 GABA 增量逐个挤出**（招募边际损失），聚合模型
按定义不可见。

## 结果 4：微池「跳变」的细胞级本体 = 重排，不是增益

| 微池 | 幼稚 4 细胞计数 | 锁内 | 
|---|---|---|
| MBON09 | [5660, 12260, 3600, 12760] | [12560, **4740**, 12980, 13020] |
| MBON30 | [4320, 5220] | [6240, 5360] |
| MBON11 | [12420, 8560] | [10880, 10660] |
| MBON03 | [3280, 4500] | [3500, 5020] |
| MBON31 | [1980, 100] | [2320, 660] |

MBON09 的类型均值 +78 Hz 在细胞级是**此消彼长的再平衡**（细胞 3
3600→12980 而细胞 2 12260→4740），招募=0（无静默细胞被点亮）。
类型均值的「浓集」实为微池内部的响应重排——可能与双侧/区室
对应细胞的抑制性耦合有关（开放）。

## 附录：微池重排的侧别判读（零采集跟进）

细胞身份（somaSide，compact 序）：MBON09 = L(x522)/L(x512)/R(x269)/R(x259)。
对照计数：ctl {L1:5660, L2:12260, R1:3600, R2:12760} → lock
{L1:12560, **L2:4740**, R1:12980, R2:13020}——不是干净的 L/R 交换：
L2 让位、L1/R1 点亮。MBON11/03/30 呈两细胞**趋同**（差异缩小），
MBON31-R 100→660 接近招募边缘。模式混杂 + 4 细胞小样本 + 单种子，
不再深挖（开放）；「重排非增益」的主判读不受影响。

## 语义收束

「门」的完整微观图像：**不是标量旋钮，而是一个按解剖收敛度分配
的逐细胞钳制向量**；池率 r 是少数活跃细胞组成的集合的边缘读数。
静默锁的租金在细胞级是：锁把活跃集边缘的 DAN 细胞一个个挤出
（21% 重钳、边缘 p90 10→7），池率读数下降 → mod 积分缩短 →
学习窗口变窄。condstate1-8 的全部池级账目（22%/33% 租金、
前置不复利、解锁退还）在细胞级的本体就是这个边缘侵蚀过程。

## 诚实边界

per-neuron dump 是记录点采样累积（每 2 步记录一次，spike 相位
混叠）——绝对计数有未知标度，本文全部判别用比值/相关/重排模式
（无量纲，不受影响）；单种子 seed 62；微池重排的机制（双侧
耦合？区室对应？）未测；MBON09 只有 4 细胞，重排的统计功效有限。
