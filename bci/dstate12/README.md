# bci/dstate12：退化×剂量固化面——细胞丢失消除固化，剂量不可救

dstate8（F=0.7 在成固剂量下失锁）与 dstate7（全群体剂量锐边）
之间的临床问题：**退化网络的固化边界是移动还是消失？更高剂量
能否重建？**

| 臂（F, 剂量） | ALPN | 判决 |
|---|---|---|
| F=0.7, 600 pA | 1.81 | 暗（微弱残余） |
| F=0.7, 1600 pA | 1.81 | 暗 |
| F=0.5, 600 pA | 0.00 | 暗 |
| F=0.5, 1600 pA | 0.00 | 暗 |

结合参照（F=1.0：150→锁、1600→高锁；F=0.7@150：暗）：

1. **退化不移动固化边界——直接消除固化**：F≤0.7 下从成阈剂量
   到满量程（10.7×）无任何剂量重建锁或高锁。细胞丢失后的网络
   不是「更难固化」而是「固化不相容」。
2. **三条退化出路合起来**（dstate8+12）：固定增益=暗（失锁）；
   F⁻² 增益补偿=跳过锁进强吸引子（113-165 Hz）；高剂量=无效。
   **锁吸引子的存在前提是全群体的精确平衡**——它不在退化网络
   的状态字典里，无论怎么驱动。
3. F=0.7 的 1.81 Hz 残余（F=0.5 为 0）是退化环路仅存的响应
   痕迹——剂量提升也不放大它（1.81 恒定），环路增益已低于
   任何驱动可及的再生阈。

「变蝇人」临床语义：**退化（细胞丢失）是把固化边界变成免固
护盾的——但代价是网络同时失去形成任何持久状态的能力**。危险
地图在退化网络上是「清空」而非「移动」：暴露既不再固化、也
不再有高状态风险；只有增益轴的人工回补（F⁻²）才会重新打开
状态形成——且直接落在强吸引子上（比健康网络的一次固化更强）。

诚实边界：单种子；F∈{0.5,0.7}×剂量 3 点；「消除」在增益轴的
含义限于中性工作点（补偿臂见 dstate8）；600 pA 与 1600 pA 的
暗侧逐位一致性未逐位核对（数值同暗态参照）。
