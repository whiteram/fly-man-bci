# bci/dstate18：多循环固解疲劳——三循环零疲劳

dstate15 闭合了单循环（治愈态=幼稚态）；本弧线把固解循环链到
**三循环**（单条 210 s 运行，`--gain-schedule` 六事件：每循环
脉冲成锁 → ×0.5 溶解 → ×2.0 恢复）。

## 结果

| 循环 | 成锁延迟 | 锁水平 | 降增益后 |
|---|---|---|---|
| 1 | 0 ms | 20.15 Hz | 0.0 Hz（全解） |
| 2 | 0 ms | 20.26 Hz | 0.0 Hz |
| 3 | 0 ms | 19.65 Hz | 0.0 Hz |
| 尾段（第三次恢复后无脉冲） | — | — | 0.0 Hz（无自锁） |

**判决：三循环零疲劳**——每循环即刻成锁（延迟 0 ms）、锁水平
一致（极差 3% = 噪声级）、每次降增益完全溶解、无脉冲无自锁。

## 终章：静默锁机制学的完整闭环（dstate1–18）

- **入口**：气味轴剂量×时长锐边（7/10）、视觉轴安全阴性（11）、
  点火轴闩锁族（9）；
- **结构**：AL 局部引擎承载（3/6/17），锁=全群体精确平衡的
  专属物（8），退化消除固化（12）；
- **转化**：锁↔闩锁连通、退迟滞不对称（16），深迟滞载体=
  中央余燃（17）；
- **生命周期**：动力学不可出（5）、半永久持续（6）、参数路
  治愈无迟滞（14）、治愈态=幼稚态（15）、**循环零疲劳（18）**。

「变蝇人」最终语义：静默锁是一个**可无限次循环的、由暴露触发、
由增益解除的可逆网络状态**——不是损伤、不留痕迹、不疲劳。
它的全部「病理性」在于触发阈太低（1/10 满量程 × 300 ms）与
动力学不可退出（锁内探针全吸收）的组合。

诚实边界：单种子；三循环（更长链未测）；「0 ms」分辨率=1 s
滑窗。
