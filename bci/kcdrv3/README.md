# bci/kcdrv3：状态阶梯上的通道门控测绘——DAN→KC 归因修订 + 状态地貌时代漂移

kcdrv2 留下的夹逼缺口（naive 死 / 旧平台活）本弧线补 causality，
结果是一个**双重诚实修订**：目标态不可复现 + 通道归因降级。

## 发现一：状态地貌随代码时代漂移（操作层重要事实）

sleep5 的原配方（sz_l3 + `--std-gates CEN_C:0.00015,5000`，种子
616）今天精确重跑：

| 窗口 | sleep5 存档（旧代码态） | 今天重跑 |
|---|---|---|
| 点火 1-2.8 s | ALPN 214/MBON 324 | ALPN 157/MBON 279 ✓ |
| 8-28 s | **ALPN 38/MBON 2.9（压制平台）** | **ALPN 83.6/MBON 76.7（中层闩锁）** |
| p2 响应 | ALPN 42/KC 11.2/MBON 103 | 无响应（已稳态） |

同一配方、同一种子——**稳态完全不同**：旧平台（ALPN 38/MBON 3/
KC 0.05）已不可复现，今天稳定在中层部分闩锁（83/76/12）。机理：
chem 自动工作点（exp019 → CEN_C=0.002）让点火站上刀刃——加 STD
门（d 最小只到 0.955，抑制本身可忽略）的核变体舍入扰动即可把
点火翻到阈下；显式 `--gain-scale CEN_C=2.0`（0.004）则跳过刀刃
得到中层闩锁。**跨时代引用旧弧线的状态相关结论必须标注代码时代**
（静默锁配方是跨时代稳定的：dstate5/6 的 ctl 臂逐位复现 dstate1；
漂移的是点火+STD 配方）。

## 发现二：DAN→KC 通道在今日所有可产状态中关闭

今日状态阶梯上注入同一 PPL103\* US（800 pA，15-17 s 窗）：

| 状态 | KC 基线 | KC 增量 | 判决 |
|---|---|---|---|
| naive 暗（kcdrv2） | 0 | +0.000~0.011（DAN 5.9 Hz 时） | 死 |
| **静默锁**（ALPN 20） | 0 | **+0.001** | 死 |
| **中层闩锁**（ALPN 83） | 12.0 | **+0.069（对照 +0.012，净 +0.06）** | 死 |
| 全闩锁 | 74 | —（饱和不可测） | — |

对照通道（DAN→MBON 直连重道）在中层闩锁内可见 +0.8 Hz——注入
本身有效。**KC 通道在任何可产状态都不开。**

## 修订：kcdrv1 的「DAN→KC 承接 +6」降级

kcdrv1 的证据链 = 平台态 DAN 超前 KC 60-80 ms（r≈0.9）+ 布线存
在（5,608 行 w6.4）+ naive 阴性（kcdrv2）。本弧线的因果补测在
锁与中层闩锁双阴性，且旧平台态不可复现——**归因降级为「与 DAN
锁相，未经因果确认」**。旧平台的 +6 KC 现在更可能由该态特有的
中央复发链直接驱动（kcdrv1 的 MBON 超前 KC 15-20 ms 分支——中央
去极化直接抬起 KC），DAN→KC（w6.4）保持为「已布线、未见开通」
的休眠通道。kcdrv1 的奖励通道接管叙事修正为：**MBON 分支（直连
重道）成立且随时可驱；KC 分支未获因果支持**。

「变蝇人」语义相应收窄：平台态对世界的应答经 DAN→MBON 价值道
（这点 kcdrv2 的 +12.3 Hz 与布线 w26 支持）——KC 层的奖励通道
开通仍是一个开放问题（需要的可能是比今日所有状态更高的 KC 去极
化 + DAN 输入的时序精确配对，即真正的 US×US 配对窗）。

诚实边界：单种子；中层闩锁 KC 基线 12 Hz 掩蔽 ≤0.1 Hz 级增量
（通道若以极小增益开通不可见）；旧平台态的不可复现未做逐代码
提交的二分定位（工作量超出本弧线）；「接管的 MBON 分支」在平台
态内的直接因果测量同样受时代漂移限制（kcdrv2 的 +12.3 是 naive 态）。
