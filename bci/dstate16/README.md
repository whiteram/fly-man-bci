# bci/dstate16：增益轴转化图——锁与闩锁连通，迟滞不对称

dstate2/3（幼稚形成窗）+ dstate14（锁的解除）之后的最后一块拼图：
**已建立状态内**移动增益跨区域，锁与闩锁能否互相转化？
（锁臂用 da1_dc60 气味脉冲在工作点成锁；闩锁臂 sz_l1 在 ×2.0=0.004
全闩锁——dstate9 g20。）

## 转化图（t=30 s 调度）

| 起点 | 调度 | pre | post |
|---|---|---|---|
| 锁（0.002） | ×1.5 → 0.003 | 锁（ALPN 19.6） | **高锁**（MBON 165/ALPN 154） |
| 锁（0.002） | ×2.0 → 0.004 | 锁 | **近全闩锁**（383/217） |
| 闩锁（0.004） | ×0.5 → 0.002 | 闩锁（396/217） | **高锁残留**（45/98） |
| 闩锁（0.004） | ×0.25 → 0.001 | 闩锁 | **全解=暗**（0/0） |

三个结论：

1. **锁与闩锁连通（锁→闩锁单向直通）**：锁的中央去极化基底把
   闩锁阈降到窗上方一点——升增益 ×1.5 即跳过中间态直达高锁，
   ×2.0 直达近全闩锁。**成锁后再升增益 = 一次小暴露把网络送进
   闩锁区**（幼稚网络在同增益下本来也闩锁，但锁起点跳过了
   dstate9 图里的过渡结构）。
2. **迟滞不对称**：锁的解除边 = 形成边（dstate14，窗下缘）；
   闩锁的解除边深得多——降到 0.002（锁窗中心）仍残留 MBON 45
   的强态，到 0.001 才全解。**闩锁携带比锁强得多的迟滞**（其
   退出需要把网络压到锁窗之下），与「锁窗是闩锁的边缘残余」
   的图像一致：锁住的是 AL 局部引擎的窗缘态，闩锁住的是整个
   中央复发的自持。
3. **统一增益轴图**（当前时代）：0.001 以下全暗（一切状态的
   共同解）→ 0.0016-0.0023 锁窗（气味可入、可解）→ 0.0023-0.003
   上行区（锁起点直达高锁）→ ≥0.003 闩锁族（0.004 全闩）。
   退出迟滞：锁在窗下缘解，闩锁要到 0.001 才解。

「变蝇人」语义：锁→闩锁的连通让「加深」有了一条增益路（不止
剂量路 dstate5）；而闩锁的深迟滞（需降到 0.001）意味着**闩锁
状态下的增益治疗窗比锁窄一倍**——解锁定格在窗缘，解闩锁要
深入禁region。

诚实边界：单种子；每转化 1 点（0.002-0.003 间的连续路径未采）；
闩锁@0.002 残留态的稳定性只看了 [40,55] s 窗；「高锁」分类在
MBON 165/383 两点上跨越了 dstate9 的中层/全闩界（成分读数见
summary，按最近参照分类）。
