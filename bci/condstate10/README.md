# bci/condstate10：长链渐近线——一次性相位滞后，两链平行前进

condstate5（5 环节）发现租金前置不复利、锁链滞后 ≈1 环节、后段
增量持平——但「渐近线是否追平」被标为未测。本弧线把两条链加倍
到 10 环节（同协议：cs5t/cs5lt，--plastic-state-in/out 传 w，
每环节单种子 62-71/72-81 去相关，链末探针）。

## 三个结论

1. **增量持平外推成立**：环节 6-10 比值在 1.0 ± 3%（噪声级）
   ——condstate5 的 5 环节结论不是巧合。
2. **恒定平行滞后，不是追平**：两条链以相同增量平行前进，
   差距恒定 0.0119 ≈ 0.72 个渐近环节当量（0.0119/0.0165）≈
   **前置租金的总和**。「锁买到的是延迟」精确化为**一次性相位
   滞后**：链首 2 环节付出的租金成为整条链的恒定位移，此后
   每一环节的边际学习率与幼稚链完全相同。
3. **表达端差距同样恒定**：探针 MBON 差 3.6%（w 差 5.5% 的
   读出），与 w 的恒定滞后一致——无追平也无扩大。

渐近线的本体：两链 dw 都稳定在 ~0.0165（mod 地板 ~360 对应的
增量），w 本身无饱和迹象（10 环节 0.218、无 floor-hit）——
是**增量平台**而非 w 上限。

## 语义终章

「变蝇人」学习账目的最后一块：静默锁对学习的影响 = **恒定相位
滞后**（幅度 = 前置租金总和 ≈ 0.7 环节当量），不是渐近线折损、
不是复利债务、不是天花板。锁定语义族完整：
机制（condstate6-9：除法钳制向量、活跃集边缘）+ 动力学（本弧：
平行轨迹）。病理全谱 = 触发阈低 + 锁内不可出 + 边缘侵蚀 +
0.7 环节当量的恒定相位滞后——每一条都可逆、都无疤痕。

## 诚实边界

单链 ×2（每环节单种子、种子去相关）；10 环节外未测（比值
稳定性已在 6-10 复验，更长外推风险低）；探针单次异种子；
「0.72 环节当量」依赖渐近增量估计（0.0165 的 ±2% 波动）。
