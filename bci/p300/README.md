# bci/p300：P300 oddball（外周适应版，诚实框架）

对齐经典 oddball 结构（频繁标准 + 稀有目标；人类被试只需默数、
**无需动作**），但如实声明：本模型没有注意/认知系统，这里的偏差
响应来自**感觉转导适应**（PhotoCascade 对重复标准闪光适应压制，
稀有亮闪解除适应产生大瞬态）——是"偏差可检测性"范式，不是认知
P300。

## 刺激（make_stimulus.py）

全场闪光列车：SOA 800 ms、闪宽 100 ms、12 s = 15 事件；标准=暗闪
（灰 148）×13，目标=亮闪（灰 228）×2（事件 4、11，13% 稀有率）。

## 结果（6 runs，90 事件 = 12 目标 + 78 标准）

| 指标 | 结果 |
|---|---|
| 目标事件响应（事件窗 rms − 基线） | **+0.8818 µV** |
| 标准事件响应 | +0.1436 µV |
| 差值 / 置换 p | **+0.7382 / 0.0002** |
| 单事件 AUC（目标 > 标准） | **1.00** |

**6 倍偏差增强、单事件完美可分**——适应驱动的偏差检测在本模型里
几乎免费。对照：真实认知 P300 的单试次 AUC 通常 0.7–0.9，本结果
是干净信号上界且机制不同（适应 vs 认知），不能混同宣称。

## 用法

```bash
conda activate ffbm
python bci/p300/acquire.py           # 6 runs（12 s/次，~4 min/run）
python bci/p300/analyze.py
```
