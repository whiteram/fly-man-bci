# bci/mmdev：失匹配偏差（MMN 类）+ 突触短时抑制机制

第三梯队机制①落地：**突触短时抑制（STD，Tsodyks-Markram 式资源
门控）**进入管线——边组 spec `"std": [U, tau_rec_ms]` 或运行时
`--std-gates "ORN_C:0.25,600"`（每次释放耗竭 25%，恢复常数 600 ms；
耗竭发生在释放时刻，效果经延迟环到达；CPU/GPU 双路径；STD-off
位级不变，回归测试通过）。

## 范式

单试次气味列车（3.6 s）：**DA1 标准脉冲 ×5**（150 pA，300 ms，
间隔 400 ms）→ **DM2 偏差脉冲**（600 pA，身份偏差）→ **DA1 恢复
脉冲**。对照设计：std_on / std_off 各 4 runs，量化突触级机制在
偏差响应中的贡献。

## 重审（2026-09-20，STD 恢复盘 bug 修复后）—— 旧结论撤回

**下表「std_on +16%」一栏作废**：bci/sleep3 发现 STD 恢复盘的
`d += (1−d)·rec` 错误（每步瞬时回满）使 STD 在任意参数下无效
（提交 8e42dde 修复）。旧 std_on/off 两条件的差异只来自 f32 末位
混沌 + 种子抽样，非机制。修复后重跑（std_off 位级复现旧值
2.74 ✓，确定性验证）：

| 指标 | std_off | std_on（真实 STD，U=0.25） |
|---|---|---|
| A1（首发） | +0.207 µV | **+0.0006 µV（300× 压制）** |
| 重复抑制 A5/A1 | 0.02 | 0.48（真实突触重复抑制显现） |
| 偏差比 devB/A5 | 2.74 | 7.83（分母塌缩驱动，意义有限） |

**U 剂量补充**（2 种子，scan_u*.npy）：U=0.05 A1 保持 +0.200，
但偏差脉冲被压至 +0.0015（7× 低于 std_off）→ deviance 0.78；
U=0.1 → −0.62。机制：**强度依赖的自耗竭增益控制** —— 偏差脉冲
（600 pA，4× 强）驱动 DM2 ORN 更猛，自身 300 ms 脉冲内
d_eq=1/(1+U·r·τ) 掉得更深，反转了 oddball 范式的偏差优势。
真实果蝇 ORN→PN 突触的 STD 恰是增益控制元件（Weakly related:
Nawrot/aperature），该行为定性合理；但对本范式意味着 STD 与
「强度=新异性」的对照设计冲突（偏差同时是最强脉冲）。

## 现行解读

1. **「身份偏差响应成立」已撤回**（2026-09-20，mmdev2 等强度/
   等响应设计收口）：旧 ~3× 偏差比全由 600 pA=4× 强度承载——
   等强度（DM2@150）下偏差头皮不可见；等响应（DM2@492，solo
   标定比 1.25）下偏差响应比标定低 ~25× = 交叉适应，无身份
   新异性。oddball 的真实主信号是 −0.43 µV 全有全无 DC 状态
   开关（单脉冲饱和、8 s 不恢复）。详见 bci/mmdev2。
2. **适应的主导位置是转导级联**（结论不变、更干净）：A1→A5 的
   ~50× 抑制来自 PhotoCascade 的刺激特异性适应；真实 STD 在
   生理量级（U≤0.1）下的边际贡献在 n=2 噪声地板内不可分辨，
   在 U=0.25 则整体过强。
3. **新增机制发现**：STD=强度依赖增益控制（见上），对强刺激
   自衰减 —— 与偏差范式的设计假设冲突，后续 oddball 类研究
   若开 STD 需改等强度偏差设计。
