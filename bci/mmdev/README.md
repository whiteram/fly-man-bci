# bci/mmdev：失匹配偏差（MMN 类）+ 突触短时抑制机制

第三梯队机制①落地：**突触短时抑制（STD，Tsodyks-Markram 式资源
门控）**进入管线——边组 spec `"std": [U, tau_rec_ms]` 或运行时
`--std-gates "ORN_C:0.25,600"`（每次释放耗竭 25%，恢复常数 600 ms；
耗竭发生在释放时刻，效果经延迟环到达；CPU/GPU 双路径；STD-off
位级不变，回归测试通过）。

## 范式

单试次气味列车（3.6 s）：**DA1 标准脉冲 ×5**（150 pA，300 ms，
间隔 400 ms）→ **DM2 偏差脉冲**（600 pA，身份偏差）→ **DA1 恢复
脉冲**。对照设计：std_on / std_off 各 4 runs，量化突触级机制在
偏差响应中的贡献。

## 结果（8 runs）

| 指标 | std_off（仅级联适应） | std_on（+突触 STD） |
|---|---|---|
| A1（首发） | +0.207 µV | +0.191 µV（STD 使首发略低）|
| A5（适应后标准） | +0.004 | +0.004 |
| 重复抑制 A5/A1 | 0.02 | 0.02 |
| 偏差脉冲 devB | +0.0108 | +0.0125 |
| **偏差比 devB/A5** | 2.74 | **3.17（+16%）** |
| 恢复 recA/A1 | ~0 | ~0 |

**解读**：

1. **身份偏差响应成立**：新鲜肾小球的偏差脉冲 evoke ~3× 适应后
   标准的响应——MMN 表型的果蝇版（"新异刺激 > 重复刺激"），
   与 auddev 的阴性对照：偏差必须换"谁在响应"（身份），仅换速率
   不够（级联适应跟踪均值）。
2. **适应的主导位置是转导级联**：A1→A5 的 50 倍抑制主要来自
   PhotoCascade 的刺激特异性适应；突触 STD 的边际贡献 +16%
   （偏差比）——机制定位清楚了。
3. 恢复慢：500 ms 间隔不足以从 5 连击恢复（recA≈0）——恢复
   时间常数是级联 800 ms 适配 + STD 600 ms 的卷积。

## 用法

```bash
conda activate ffbm
python bci/mmdev/acquire.py           # std_on + std_off 各 4 runs
python bci/mmdev/analyze.py
```
