# bci/condit2：获得-消退曲线——跨试次记忆

`condit` 的后续：KCM 可塑权重现在**跨试次持久**（`--plastic-state-in/out`
状态链）并带**慢恢复**（`--plastic-tau-w`），一个 session 画出经典
条件反射弧——获得（累试抑郁）→ 消退（撤奖后慢恢复）——而不再是
一次性快照。这是项目第一条**逐试次学习曲线**。

## 机制（进主管线，opt-in）

- `--plastic-state-out FILE`：运行后写出 KCM w_scale + 边身份校验和
  （表 id 字节的 md5；突触内部按 lexsort((pre,post)) 定序，是表内容
  的确定函数，故校验和唯一钉住 w_scale 排列；不匹配即拒绝加载）；
- `--plastic-state-in FILE`：从上一试次的状态继续（GPU 路径；elig
  试次间清零 = 假设 ISI >> tau_elig 400 ms）；
- `--plastic-tau-w MS`：慢同稳态恢复 `w += (1−w)·dt/tau_w`（每步、
  不受门控；0=冻结，默认关闭、位级不变）。门控关闭时它单独产生
  **消退**。CPU/GPU 双路径（k_plast_adv 增加 rec 参数）。

## 设计（5 s 试次，逐试次探针）

| 相位 | 试次 | 化学 | 塑性 |
|---|---|---|---|
| 获得 a | 10 × | `condt2`：KC 训练 0.5–2.5 s 1600pA + PAM 奖励 800pA；探针 4.2–4.7 s | 窗 500,2500 开 → 抑郁**累试累积** |
| 消退 x | 8 × | `condtx`：同 KC 训练，**无 PAM** | 不传窗 → 门关 → 仅慢恢复（tau_w=30 s ≈ 每试次 +15%）|
| 对照 c | 8 × | `condtx`（从未奖励的独立 session）| 平坦曲线排除漂移/顺序伪迹 |

paired = a→x 链式一个 session；ctrl 独立链。各 2 个 seed session。
读出 = 每试次探针净响应（窗 rms − 前 200 ms 基线），统计 = 逐
session OLS 斜率跨 session 合并，置换检验 = **session 内打乱试次
顺序**（保留 session 水平、破坏时间结构），双侧。

## Pilot 验证（3 试次链，机制侧）

| 试次 | w_scale 均值 | 探针净响应 |
|---|---|---|
| a0（首获得）| 1.000 → 0.357 | +0.228 µV |
| a1（第二获得）| 0.357 → **0.202**（跨试次累积）| **+0.305 µV** |
| x0（首消退）| 0.202 → **0.324**（纯恢复）| +0.274 µV（回落）|

方向全部机制一致：响应随 w 下降升高、随 w 恢复回落。

## 结果（52 试次：paired 18×2 + ctrl 8×2）

| 相位 | 探针净响应轨迹 | w_scale 均值轨迹 | 斜率（µV/试次）| 置换 p |
|---|---|---|---|---|
| 获得 ×10 | +0.228 → +0.305 → 平台 ~+0.315 | 0.36 → 0.20 → **0.15**（抑郁-恢复平衡点）| **+0.0053** | **0.0002** |
| 消退 ×8 | +0.283 → +0.178（−37%）| 0.28 → 0.78（纯恢复爬升）| **−0.0142** | **0.0002** |
| 对照 ×8 | +0.119 ~ +0.128 平坦 | 恒 1.00 | +0.0004 | 0.30（n.s.）|

early→late：paired **+0.0332 µV** vs ctrl +0.0014 µV（24×）。双 seed
session 几乎重合（确定性驱动主导、噪声方差小）。曲线形状机制一致：
**单试次快获得 + 平台**（首试次即 +0.228→+0.305，之后向抑郁-恢复
平衡点缓升）、**指数式消退**（w 每试次 +15% 恢复 → 探针逐级回落）。
对照水平 +0.12 µV 与 `condit` 的 nolr（+0.1221）一致；paired 平台
（w 0.15）比 `condit` 单发（w 0.36）更深——跨试次累积的证据。

## 诚实性边界

- 强化门仍是**时间窗 proxy**（真实实现应为 PAM DAN 活动门控）；
  消退试次"撤奖 = 不传窗"是这一 proxy 下的诚实翻译；
- 恢复是同稳态性质（非反 Hebbian），消退时间常数 = tau_w 的直接
  读数，不是独立机制；
- 身份特异性同 `condit`：被驱动 KC 子集（PN→KC 通路约束未变）。
