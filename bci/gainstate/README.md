# bci/gainstate：工作点状态轴（唤醒的诚实实现）

arousal 实验证明 OU 噪声不是状态轴（底噪由偏置电流驱动）。本范式
用**真正的状态变量**：`--base-scale` 缩放全部 `*_BASE` 偏置电流——
工作点既定自发发放也定刺激增益，对应"增益调制型唤醒"。状态
lo 0.85× / hi 1.15×，刺激 暗屏 vs 150 pA DA1 气味脉冲，2×2 × 4。

## 结果（16 试次）

| 指标 | lo 0.85× | hi 1.15× |
|---|---|---|
| 暗态底噪 | 1.3584 µV | 1.3069 µV |
| 气味净响应（按试次基线） | +0.2033 µV | **+0.4960 µV（2.4×）** |
| 响应试次间波动 | **±0.1423（近阈随机）** | ±0.0010（稳定） |
| 状态解码（空间模式） | 名义 100%（p=0.0255；4+4 试次，同 arousal 的谨慎解读）| |

**解读**：

1. **工作点轴有效**：底噪、刺激增益、响应可靠性三者都随
   `--base-scale` 移动——与 arousal 的噪声轴（全部不动）形成
   干净的机制对照。
2. **状态依赖的可检测性**：低工作点下气味响应进入近阈随机区
   （试次方差 140 倍于高工作点）——"同一个刺激，有的试次响应
   有的不响应"，这是真实神经系统状态依赖可靠性的定性复现。
3. **状态与增益不可分离**（本实验的设计发现）：偏置电流状态轴
   天然同时调制自发活动与刺激增益——这正是唤醒的增益调制定义，
   但也意味着"纯状态"与"纯增益"在单 knobs 模型里无自由度分开。
