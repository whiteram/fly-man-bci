# bci/motivate：动机门控学习——强化门强度轴（--plastic-mod-scale）

强化门从二值时间窗升级为带**强度**的轴（mod 幅度 = 多巴胺 proxy
增益）——模型的动机/奖励强度控制，与"饥饿果蝇对气味+糖条件化
更好"同构。门强度直接进入权重更新：Δw ∝ lr × mod × elig。

## 设计（单发剂量-反应，5s 试次）

一次配对试次（KC 训练 1600pA + PAM 奖励 800pA，窗 0.5-2.5s），
mod-scale ∈ {0.125, 0.25, 0.5, 1.0} + lr=0 零参考，各 4 runs
= 20 试次。读出：单发后 KCM w 均值（状态文件）+ 探针净响应相对
零参考的增量。统计：w 与探针增量对 mod-scale 的 Spearman 趋势
（臂标签置换）+ 单调性检查。

## 结果（20 试次：4 门强度 × 4 runs + lr=0 参考 × 4）

| mod-scale | 单发后 w 均值 | 探针净响应 | 相对零参考增量 |
|---|---|---|---|
| 0（lr=0 参考）| 1.000 | +0.1231 µV | — |
| 0.125 | 0.855 | +0.1597 µV | +0.0366 |
| 0.25 | 0.731 | +0.1825 µV | +0.0594 |
| 0.5 | 0.535 | +0.1956 µV | +0.0725 |
| 1.0 | 0.286 | +0.2493 µV | **+0.1262** |

**完美单调剂量-反应**：w 对 mod-scale Spearman ρ=−1.0、探针增量
ρ=+1.0（置换 p=0.08 = 4 臂排序检验的理论下限 2/24——完美排序下
可能的最强证据）；臂内 sd ≤0.003（驱动主导，近确定性）。门强度
线性进入学习深度（Δw ∝ mod），头皮表达同步分级——**动机轴成立**。

## 诚实性边界

- mod-scale 是门强度的**标量 proxy**（真实实现 = PAM DAN 群发放
  率门控可塑性——那是把 mod_fn 接到 PAN 群活动的机制改造）；
- PAM 驱动幅度固定 800pA：本实验变化的是"门控增益"而非奖励
  刺激本身（两者在真实果蝇里耦合，在这里分离——文档化）。
