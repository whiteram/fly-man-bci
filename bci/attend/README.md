# bci/attend：注意 = 通路增益调制（--gain-scale）

注意的标准机制实现——**增益调制被注意通路**：`--gain-scale OLR_V=k`
运行时缩放视觉级联→中央脑前馈组（OLR_V，30 万对上限）的 g_unit
（运行时标量，不动内核缓存）。三个问题：

1. **恢复剂量-反应**：hybrid 发现双任务下 SSVEP 线被掩没 ~500×；
   k=4（生理上界）或 k=16（超生理）能否把视觉线找回来？
2. **代价**：提升视觉通路是否损害想象流解码（注意权衡）？
3. **hybrid 混杂修正**：hyb_n 对照臂代码里没传 `--chem-input`
   （默认增益），而其 chem 条目意图是 0.002 工作点——500× 掩没
   把工作点衰减与真双任务干扰混在一起。"nwp" 臂重跑无想象对照
   **带** 0.002 工作点，拆分两者。

## 设计（10.5s，2 频率 × 2 想象侧 × {k0, k4, k16} × 2 重复
= 24 双任务试次 + 2 nwp 试次）

全部双任务臂带 `hyb_{l,r}` 想象 chem（0.002 工作点）；k 臂追加
`--gain-scale OLR_V={4,16}`。

## 结果（26 试次）

**恢复剂量-反应（双任务试次，10/14Hz）**

| 臂 | 线 SNR 中位 | CCA 频率准确 |
|---|---|---|
| k0（OLR_V×1）| 0.72 | 3/8（随机）|
| k4（×4，生理上界）| 1.15 | 4/8（随机）|
| k16（×16，超生理）| 1.17 | 4/8（随机）|

- **注意增益无法恢复被掩没的视觉线**：×4/×16 仅 +60% SNR
  （+1.7 dB），线 SNR ~1.2 仍无线可言；恢复到纯视觉电路水平
  （347）需 ~25 dB——通路增益调制在这个结构里加不出线功率
  （OLR_V 终端贡献的中枢视觉跟随成分相对总中枢背景太小）；
- **想象流零代价**：三臂全部 8/8——视觉增益提升不触碰想象
  空间模式（无注意权衡，至少在此剂量范围）。

**hybrid 混杂修正（nwp 臂）**

| 电路/臂 | 10Hz 线 SNR |
|---|---|
| 纯视觉电路（ssvep_benchmark，visual_bilateral）| **347** |
| hybrid 无想象、默认增益（hyb_n，原对照）| 1.08 |
| hybrid 无想象、0.002 工作点（nwp，修正对照）| 1.12 |
| hybrid 有想象、0.002（k0）| 0.81 |

→ 工作点份额 **×1.0**（混杂排除：hyb_n 代码漏传 chem 无影响），
双任务份额 ×1.4——**~300× 掩没来自"纳入中枢区域"本身**（宽带
中枢背景抬高 10Hz 处底噪，线仍在但被埋）。hybrid README 原归因
（"被中央 OU 背景掩没 ~500×"）在"哪个背景"上需要修正：不是
工作点、不是想象任务，是中枢区域的整体自发活动。

## 诚实性边界

- 增益调制是注意的**机制下界**实现（无竞争池、无时间动力学）；
  生理范围注意增益 ~×2-4（k4 臂），k16 是超生理参考点；
- OLR_V 是视觉→中央的**主**前馈组（CEN_V 仅 152 行，不缩放，
  文档化）；
- 想象流是 chem 驱动（不经边组），增益调制不作用于它——只测
  单向权衡。
