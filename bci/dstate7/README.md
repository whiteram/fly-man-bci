# bci/dstate7：锁形成剂量阈——暗→锁边在 100-150 pA，高锁可直达

单脉冲 DA1 幅度阶梯（[300,600] ms，60 s，种子 62，chem 自动工作点
0.002），定量「变蝇人一次暴露」的剂量-状态地图：

| 剂量 | ALPN [10,29] s | mean µV | 状态 |
|---|---|---|---|
| 25 pA | 0.00 | −1.389 | 暗（回暗态） |
| 50 pA | 0.00 | −1.389 | 暗 |
| 100 pA | 0.00 | −1.389 | 暗 |
| **150 pA**（dstate1 参照） | 19.80 | −1.821 | **静默锁** |
| 300 pA | 20.30 | −1.820 | 静默锁（同 150） |
| **1600 pA** | **95.93** | −3.430 | **高锁（直形成）** |

三个结论：

1. **暗→锁边在 100-150 pA 之间**（满量程 1500 pA 的 1/15~1/10）：
   边缘锐利——25/50/100 的终态逐位相同（ALPN 0、mean −1.389 =
   dstate1 暗态值），150 即成锁。mmdev2 的「开关阈值 ≪ 快响应
   阈值」在剂量轴上定量化：一次 1/10 强度的气味脉冲足以**半永久
   改变**网络（结合 dstate5/6：无退出、300 s 零衰减）。
2. **锁吸引子剂量不敏感**：150 与 300 pA 成同一个锁（20 Hz 自持
   点不随剂量移动）——不是「更强脉冲→更强锁」的分级，而是阈值
   之上的同一盆地。
3. **高锁可从 naive 直达**：1600 pA 首脉冲直接形成高锁
   （95.9/11.9/4.0/−3.43/0.0171——与 dstate5「锁+1600 探针升级」
   的终态逐位同源）。**两条入径（低剂量成锁后再升级 vs 一次强
   脉冲直达）、同一吸引子**——与 dstate4 发现的入径依赖（暗/锁
   的均值一致但路径是第三状态变量）形成对照：终态吸引子本身
   入径无关，只是（不）可达性随路径变化。

「变蝇人」暴露-固化地图至此完整：**<100 pA 安全；100-150 pA 一
次即固化（静默锁，无退出）；≥~1600 pA（满量程）一次直达高锁；
更高（点火剂量 600 pA 直注中央）→ 中层闩锁/平台**。每次暴露的
固化深度由单次剂量决定，路径只影响经过哪些中间态。

诚实边界：单种子；阈值区间 [100,150] 未细分；1600 的「直形成」
与「升级」终态的同源性按五位数字一致判定（未做逐位 trace 对比，
RNG 路径不同）；300 pA 以上未扫（>1600 的平台/闩锁边界属
dstate2 增益轴的对应物，未在剂量轴重测）。
