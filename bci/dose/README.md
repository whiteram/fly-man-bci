# bci/dose：气味浓度（剂量）解码（3 档）

DA1（cVA）三档浓度：75 / 150 / 300 pA（0.5×/1×/2× 标定幅度），
900 ms 单脉冲，类别 = 浓度档，6 重复。区域集同 bci/olfactory
（缓存命中）。

## 结果（18 试次，干净信号）

| 浓度 | 净响应（rms − 基线） |
|---|---|
| 75 pA | +0.0598 µV |
| 150 pA | +0.4622 µV |
| 300 pA | +0.5117 µV |
| **3 类解码** | **100%（p=0.0005，chance 33%）** |

**解读**：

1. 浓度可解码——但看剂量-响应曲线：150→300 pA 翻倍只增
   +0.05（**Hill 型饱和**），0.5×→1× 却增 +0.40。转导级联的
   适应把高浓度端压缩了，解码主要靠 75-vs-其余的对比。
2. 这正是生物剂量-响应的形状（Webster/Abraham 型饱和曲线），
   也提示"浓度档位 BCI"在低端更有效；高端档差需要更长的脉冲间
   恢复或不同的适应状态设计。

## 用法

```bash
conda activate ffbm
python bci/dose/acquire.py           # 3 档 × 6

```
