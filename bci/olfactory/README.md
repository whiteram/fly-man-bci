# bci/olfactory：气味身份解码（3 类）

每试次 3.6 s，单一气味 900 ms 脉冲（@300 ms），类别 = 气味身份，
6 重复：**DA1**（cVA 雄性信息素，ORN_DA1 204 细胞）/ **DM2**（果醋
酯，54 细胞）/ **VA1v**（脂肪酸，130 细胞）。电路复用 exp019
（`olfactory` 区域，ORN_C 57k 对入触角叶）。映射依据
docs/SENSORY_INPUTS.md §2（Vosshall 2000 / Hallem & Carlson 2006）。

## 结果（18 试次，干净信号，17 维空间模式 LOO 最近质心）

| 解码 | 准确率 | perm-p | chance |
|---|---|---|---|
| 3 类气味身份 | **89%** | **0.0005** | 33%（perm 95 分位 56%）|

三类 rms 等高（1.80–1.83 µV）——可分性来自空间模式而非幅度。

## 标定注记（诚实版）

- 首版 150 pA 均一幅度的结果：DA1 +38% 响应、**DM2/VA1v 仅 +4%**
  （解码 39%，p=0.63，不显著）——exp019 的"嗅觉头皮可见
  ×1.4–1.65"实质上由 DA1（cVA 通道）主导，这是个值得记住的修正。
- 修正：按 ORN 群大小补偿幅度（DA1 150 / DM2 600 / VA1v 250 pA，
  等效总驱动），三类响应均衡后 3 类 89%。群大小（204/54/130）是
  连接组事实——气味通道的"增益"天然不均。
- 响应时间过程：脉冲结束后 rms 平台保持到试次结束（+29–38%），
  与 exp019 报告的"AL 特异性衰减响应"相比本次持续时间更长——
  单气味 900 ms 脉冲 + chem 工作点下的持续态候选，与 JOA 观察一致，
  增益扫描列为后续。
