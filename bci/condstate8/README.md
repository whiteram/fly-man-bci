# bci/condstate8：微池特写 + 前向闭合的极限——载体链闭合，聚合模型到顶

condstate7 留下两个问题：① 锁为什么专推 MBON09/30/11/03/31 微池
（最后一跳未定位）；② V→mod 定量前向缺 R_kcdan 项。本弧线全类型
记录（76 组：全部 KC 家族 + 全部 MBON 类型 + DAN 子类型 + 候选池）
lock vs naive 配对，配内核级机制确认。

## 结果 1：载体链闭合——锁 → KC 家族微增 × 微池集中收敛 → 微池跳变

微池驱动分解（dI = Σ_T sign·W_{T→M}·Δr_T，训练窗，lock−naive）：

| 微池 | 正驱动前二 | 负驱动前二 |
|---|---|---|
| MBON09 | **KCg-m +148k**、KCa'b'-ap2 +25k | MBON09 自抑制 −19k、APL −8k |
| MBON11 | **KCg-m +96k**、KCab-s +5k | MBON11 自抑制 −3k、APL −1.4k |
| MBON03 | KCa'b'-ap2 +37k、KCa'b'-m +26k | MBON09 −22k、PAM06 −16k |
| MBON30 | KCg-m +43k | **MBON09 −37k**、MBON11 −1.3k |
| MBON31 | KCa'b'-ap1 +16k、KCa'b'-ap2 +10k | LHMB1 −14k |

判读：**锁的网络背景使 KC 家族训练响应 +4 Hz（KCg-m 161.7→165.7），
经微池上极度集中的 KC 收敛（MBON09 总传入 70,800 中 KC 占 ~64k，
4 个细胞 → 每细胞 ~16k 权重）放大成 +25~78 Hz 的响应跳变**；微池
间互抑制（MBON09→30/03）与 APL/LHMB1 塑形其余模式。DAN→MBON
主干与 DPM/CRE067 是次要项。没有神秘的锁专属通路——是增益结构
（收敛集中度）把 4 Hz 放大成 78 Hz。

## 结果 2：内核级机制确认——除法性（分流）抑制

gpu.py `k_lif_g32`：`v∞ = (v_rest + R_m·i_ext) / (1 + R_m·g_tot)`，
g_tot 累积 `g_unit×w×s`（s 有 [0,1] 突触资源界）。**字面意义的
除法抑制**：g 大时 v∞ 由电导比决定，增量 V 的边际效应 ∝ 1/g²。
这就是 condstate6/7 观测到的「均匀 32 Hz MBON 全灭、训练均值
101 Hz 只到 r≈9」的饱和的物理本体，也解释了调制自由度：锁内
状态改变的是分母，学习改变的是分子。

## 结果 3（否定结果，带牙）：类型级聚合前向无法闭账

线性/除法形式 r ~ (a0 + b·K)/(1 + c·V)（K=KC→DAN 加权和、
V=GABA 子集加权和，均为类型聚合）：

- lock8 vs ctl8：K **+4.4%**、V **+10%**、r **−2.9 Hz**——任何
  非负系数模型都到不了（极限 b→0、c→∞ 也只能 r≈13.8）；
- naive2r：V 最高（731k vs 411k）而 r 第二高（13.75）；
- 拟合 c→0（两臂窗内 V-r 相关被 K 共线淹没）。

**判读：r 的账目在类型级聚合分辨率下闭合不了**——残差住在
154 个 DAN_err 细胞的逐细胞异质性（GABA 行只接触其中一部分）
与 DAN 池自身的网络状态里。这不是模型失败而是聚合分辨率的
边界：类型均值能定位载体（结果 1）但不能定量预测门。下一级
仪器是逐细胞 DAN_err 记录。

## 语义

「变蝇人」学习账目的突触级收束：**锁的租金 = KC 家族 +4 Hz 的
网络背景微增，经微池的集中收敛增益结构放大，落到 349 行 GABA
除法抑制的分母上**；学习吃的是同一批微池的分子侧。账目分母
（状态租金）与分子（习得读出）在同一个除法式里对峙——
condstate5 的「减速带」语义在电路层就是这条除法式。

## 诚实边界

单种子 seed 62 配对；类型均值近似（2-4 细胞微池的招募 vs 增益
未分辨——MBON09 的 +78 Hz 可能部分是招募）；condstate7 臂缺
KC 家族类型记录（K 跨弧不可比，本弧内配对可）；聚合模型的
否定结论限于 (K,V) 二元聚合形式。
