# bci/condstate46：种子-62 阈值下扫——双侧括号定案，阈值种子移动 ~+18%

## 问题

cs44 只扫了种子 63（(150,175] pA），62 只知 ≤150——"阈值差
≤17%"是上界表述。本弧补 62 的两点下扫（100/125 pA，新条目
cs44d{100,125}，20 s ×2 跑 ~7 min GPU），把两侧都变成实测括号。

## 结果

| DA1 剂量 | 种子 62 | 种子 63（cs44）|
|---|---|---|
| 100 pA | **不燃（脉冲峰 0.00 Hz）** | — |
| 125 pA | **不燃（脉冲峰 0.00 Hz）** | 不燃（1.47 Hz 瞬态）|
| 150 pA | 燃（19.98 Hz 自持）| **不燃（0.000 Hz）** |
| 175 pA | — | 燃（19.46 Hz）|
| **阈值括号** | **(125,150]** | **(150,175]** |

**三个判定**：

1. **双侧括号定案**：62 ∈ (125,150]、63 ∈ (150,175]——两括号
   **相邻不重叠**，阈值种子移动为实测的**一档剂量步**（中点比
   ~137.5/162.5 ≈ **+18%**，硬界 [0%, +40%]）——cs44 的上界
   表述升级为实测值；
2. **全有全无跨种子成立**：62 的阈下响应比 63 更锐利（100/125
   pA 脉冲窗**零尖峰**，63@150 尚有 1.47 Hz 瞬态）——双稳闩锁
   的"剂量决定能否捕获"在两种子上同构；
3. **cs2 的历史剂量选择被定量解释**：62@150 恰在其阈值括号
   顶端（(125,150] 的右端）——老配方踩在阈值边上运行，难怪
   63 在同一剂量失燃；跨种子配方余量应 ≥1 档（25-50 pA），
   与 cs44 的"≥~20%"结论一致。

## 语义

- 诱导阈值程序完整收官：**进入门槛（双侧括号）+ 全有全无 +
  稳态剂量无关**（cs44/46）——种子间差异是一档相邻移动，不是
  定性差别；状态存在性门（cs42）的定量版完全落地。

## 诚实边界

- 每剂量单 trial；括号宽 25 pA（未二分）；
- 62@100/125 的零响应意味着其阈下瞬态低于 1-ms 池率分辨
  （~0.001 Hz/神经元）——输入端增益差异未单独测量。
