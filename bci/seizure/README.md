# bci/seizure：癫痫样发作检测与灶侧别定位（本模型独有）

exp019 标定时发现的**中央脑点火吸引子**（默认复归增益下任何超阈
chem 输入使全 CEN 锁入 ~82 Hz 自持态）本身就是一个癫痫样病理状态。
本范式把它当作"被试的疾病"：焦点驱动一侧 LAL 群播种偏侧发作，
从头皮 EEG 做 (i) 发作 vs 健康、(ii) 灶侧别定位——临床 EEG 的标准
分析，而模型**天然自带病理机制**（其他模拟项目需要人为注入癫痫
模型）。

## 协议（每试次 3.6 s，3 类 × 4）

| 类别 | 设置 |
|---|---|
| sz_L / sz_R | **默认 CEN_C 增益（0.004，`no_cen_damp` 退出 exp019 安全工作点）**+ 800–2800 ms 同侧 LAL 焦点驱动 600 pA = 发作灶 |
| ctl | 同幅驱动但保持 CEN_C=0.002 工作点（健康网络） |

## 结果（12 试次）

| 检测 | 结果 | perm-p |
|---|---|---|
| 发作 vs 健康（ictal 窗空间模式） | **100%** | **0.0025** |
| 灶侧别定位（sz_L vs sz_R） | **100%** | **0.0255** |
| 起始时刻 | sz 各试次 **~545–578 ms**（早于 800 ms 驱动）；ctl 全部无发作 | — |

**两个发现**：

1. **自发癫痫生成（spontaneous ictogenesis）**：默认增益下网络在
   **无任何焦点驱动、纯背景噪声**时 ~0.55 s 内即自燃——比 exp019
   "任何超阈输入触发"更强的陈述：噪声已足够。发作样吸引子在暗屏
   条件下是默认增益网络的基线行为。
2. **焦点决定侧别签名**：虽然起始时刻与驱动窗无关（驱动 800 ms 才
   开始），ictal 态的空间模式仍由焦点侧别决定（100% 可定位）——
   类似临床"发作灶侧别 imprinting 到头皮"。

诚实边界：起始时刻检测在本范式里检测到的是**网络性质**而非刺激
锁定事件；要做出"驱动锁定起始"，需要从亚点火增益逐渐逼近阈值
（增益扫描），列为后续。

## 增益扫描（sweep.py）：分岔是硬的

显式设定 CEN_C 增益（600 pA 焦点驱动，各 2 重复）：

| CEN_C 增益 | 发作起始（ms） |
|---|---|
| 0.002（工作点） | 无 ×2 |
| 0.0025 | 无 ×2 |
| 0.003 | 无 ×2 |
| 0.0035 | 无 ×2 |
| 0.004（默认） | ~550 ×4（自发） |

**结论**：0.0035→0.004 之间是硬分岔——不存在"驱动锁定的中间
增益"；可控性限于**侧别签名**而非起始时刻。临床上类似的观察是
发作阈值的双稳态切换（要么不发作、要么自持）。

## 用法

```bash
conda activate ffbm
python bci/seizure/acquire.py        # 3 类 × 4（区域集复用缓存）
python bci/seizure/analyze.py
python bci/seizure/sweep.py          # 增益扫描 4 增益 × 2
```
