# bci/blocking2：预测误差门下的 Kamin 阻断——与 bci/blocking 成对

`bci/blocking`（窗门）证明纯三因子规则**不产生阻断**（w_B 两条件
同触底 0.0200）。本研究把强化门换成 **Rescorla-Wagner 预测误差门**
（实验层实现：每试次 `error = R − ΣV_呈现气味`，`mod = clip(error,
0,1)`，试后 `V_x += α·error`，α=0.3，V 按 session 持久化；经
`--plastic-mod-scale` 注入，**突触规则本身一字未改**）——预测：
阻断应当涌现。

## 结果（40 试次，blocked/control 各 2 session × 4+6）

| 门 | w_B blocked | w_B control | 判定 |
|---|---|---|---|
| 窗门（bci/blocking）| 0.0200（触底）| 0.0200（触底）| **无阻断** |
| **误差门（本研究）** | **0.5997** | **0.1255** | **阻断涌现**（对照多学 4.8×）|

- V 轨迹教科书式：blocked V_A→0.879（阶段 1）→ AB+ 误差 ≈0.12 →
  B 几乎不学（w_B 0.60）；control 的 V_C 在 AB+ 中无关 → 误差→
  满幅 → B 深学（w_B 0.13）；
- 子类型特异性完好：blocked 的 C 保持 0.98（未驱动）；
- 效应确定性（两 session 逐位一致，驱动主导——本项目反复确立的
  性质）；n=2+2 的标签置换检验对此退化（p=0.34 为检验地板），
  如实标注——效应量 −0.474 为组内零散布的确定差异。

**合并结论**：同一突触规则（elig × mod 抑郁）下，阻断完全由
**门的计算类**决定——时间窗门（无误差项）不阻断，预测误差门
（Rescorla-Wagner）阻断。学习规则的类属边界由两个实验共同钉死。

## 诚实性边界

- 误差计算在**采集层**（per-odor V 表）；电路级实现（MBON→DAN
  反馈使多巴胺本身编码误差——果蝇的真实候选机制）是机制级后续；
- R=1 恒定奖励、α=0.3 未标定（经典值）；无背景泄漏修正（误差
  ≈0 时 mod=0，泄漏也被关闭——与窗门行为不同，门语义差异所致）；
- 头皮 B 探针曲线仍平（读出腿份额约束不变），机制层 w 为主读出。
