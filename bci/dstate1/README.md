# bci/dstate1：气味 DC 态 vs 癫痫平台态——统一性检验

两条线索的均值三位小数一致（mmdev2 气味 DC 开关目标 −1.825/
std 0.179；sleep4–6 癫痫平台 −1.825/0.18），假设它们是同一个
被压制状态。本实验：单 DA1@150 脉冲（da1_dc60）60 s trial ×
2 种子，测 DC 持续性与状态内群体速率。

## 结果：强统一否定——均值相同的两个不同状态

| 读出 | 气味 DC 态（本实验） | 癫痫平台态（sleep4–6） |
|---|---|---|
| mean | −1.8206±0.0008 | −1.825 |
| **std** | **0.0145（暗态的 1/7！）** | **0.18（暗态的 1.8×）** |
| MBON | **0.0 Hz** | 3–5 Hz |
| KC / DAN | 0.0 / 0.0 Hz | 0.1 / 0.2 Hz |
| ALPN | **~19.8 Hz（暗态 38 的一半）** | ~38 Hz |
| 持续 | ≥60 s 零衰减（双种子，10 s 起全程平坦） | ≥80 s（sleep4） |

气味 DC 态是**深度静默锁**：全部受监视中央群体静默、方差比
暗态还低 7 倍、ALPN 砍半——一个超 quiet 的吸收态；癫痫平台
则是「静默中带残余活动」的活性压制态。**均值一致是巧合或共享
的上游机制**（如感觉级联的持久适应把 mean 场压到同一点），
不是同一网络态。

## 结论与后续

1. **dstate = 静默锁**（新状态定性）：被任意有效气味脉冲触发
   （开关阈值远低于快响应阈值——mmdev2），进入后全网络近默、
   ≥60 s 不衰减。对 BCI：这是一个**气味触发的基线静默轴**。
2. sz 平台与 dstate 的分离判据 = std（0.18 vs 0.015）+
   ALPN（38 vs 20）：后续跨范式实验用这两个数判态。
3. 开放问题：mean 一致是否共享上游机制——加 ORN 到 pop-rate
   即可检验感觉级联持久适应假说（下一个廉价实验）；dstate 的
   退出条件（更强刺激能否唤醒）未测。

## 补验：ORN 探针否定感觉级联假说

da1_dc60 + `--pop-rate ORN,MBON,ALPN`（种子 62）：ORN 在静默锁内
**完全归零**（脉冲期峰值仅 3 Hz——与 mmdev 重审的「活跃 ORN 边
~3 Hz」一致），dark MBON 也是 0（「43 Hz 基线」是 condit 工作点
特异的）；唯一持续放电的是 **ALPN 自己**——被脉冲从 0 推到
~19.9 Hz 后自持（dark 0 → lock 19.9）。

- **感觉级联持久适应假说否定**：mean 偏移不是上游 ORN 适应
  托底的。
- **ALPN 是静默锁里唯一的活性群体**（自持 20 Hz）——它也是
  sz 平台里唯一活跃的群体（38 Hz，两倍）。两个状态的分辨
  进一步收敛到 **std + ALPN 率**（0.015/20 vs 0.18/38）；
  ALPN 的自持机制（其局部回路经 CEN_C）是共享候选底物，
  mean 一致的解释仍开放。

诚实边界：单脉冲 150 pA 一个剂量（mmdev2 证明开关幅度不敏感，
但状态内速率画像只在此剂量下验证）；2 种子；ORN 未监视。
