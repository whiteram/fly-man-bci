# bci/condstate4：高锁内条件化——租金曲线第三点，驱动变量判别

condstate3 留下两点租金-深度数据和一混淆：残留态租金 −32% 同时
伴随 ALPN 99 与中央余燃（MBON 24/KC 17）——谁在压制门？高锁
（da1_d1600 直达路线，dstate7/6/17 画像 ALPN ~100 / MBON ~12 /
KC ~4）把混淆拆开：**AL 水平与残留态匹配（~100），中央余燃小
一个量级**（本协议实测 MBON 6 / KC 4）。

## 协议（t_end 22 s，dangate2 标定）

| 时刻 | 事件 |
|---|---|
| 0.3-0.6 s | DA1@1600 pA 单脉冲（naive 直达高锁，无调度） |
| 12-16.5 s | 签名校验窗（对照 dstate6/17 高锁画像） |
| 17-19 s | A+ 训练（KCg-m 1600 pA + DAN_err 800 pA） |
| 20-20.5 s | 探针 |

臂：ctl（复用 condstate3 的 cs3ctl，同窗时间匹配）/ hl / hlnt
（无训练纯漂移探针——高锁 KC 4 Hz 微活）× 种子 62/63。

## 结果

| 臂 | ALPN/KC/MBON（训练前） | w_A 增长 | mod_ms | 训练比* |
|---|---|---|---|---|
| ctl62 | 0 / 0 / 0 | 0.0267 | 593.5 | — |
| hl62 | 99.7 / 3.9 / 6.2 | 0.0185 | 379.9 | **0.658** |
| hlnt62 | 99.7 / 3.9 / 6.2 | **+0.0009** | 35.9 | — |
| ctl63 | 0 / 0 / 0 | 0.0263 | 586.0 | — |
| hl63 | 99.4 / 3.9 / 5.9 | 0.0185 | 378.7 | **0.669** |
| hlnt63 | 99.4 / 3.9 / 5.9 | **+0.0009** | 35.1 | — |

*训练比 = (w_hl − w_hlnt) / (w_ctl − w0)。

## 三个结论

1. **驱动变量判别成功：门压制跟 AL 自持水平走**。高锁租金
   0.66-0.67 / 门 −36%（380 vs 593）与残留态（0.67-0.69 / −37%）
   无差别——尽管 MBON 6 vs 24、KC 4 vs 17。中央余燃对租金的
   边际贡献 ≈ 0；**租金-深度曲线的横轴是 ALPN**。
2. **三点曲线**：ALPN 0（幼稚）→ 1.0；ALPN 20（静默锁）→ 0.79
   / 门 −20%；ALPN ~100（高锁 = 残留态，两态重合）→ 0.66-0.69
   / 门 −36~-37%。单调、20→100 Hz 段近似对数/饱和形（仅两级，
   形状未测）。
3. **债务仍可忽略但非零**：hlnt 漂移 +0.0009（基线 3%，
   grown_frac 0.3%）；高锁的 DAN 门有微弱自发调制（35.9 ms vs
   残留态的 2.2-2.5）——写入通道微开，写入量相应微增。全谱
   结论不变：债务 ≤3%，租金 100% 主导。

## 机制注脚（开放）

AL 自持压制 DAN 门的通路未定：不是经平均 MBON 率（高锁 MBON 6
与残留态 24 同租金）——可能是 AL→KC→MBON 的持续结构化输入
对误差门背景（r0/适应态）的作用。condstate1 的「锁压低误差门
背景」表述在三点上同时成立，逐突触通路留待后续。

## 诚实边界

单 trial × 6 臂（两种子）；曲线仅三个 ALPN 级（0/20/100）；高锁
MBON 6.2 低于 dstate6 参照 11.8（本协议 12-16.5 s 窗 vs 参照的
30 s 后窗——成熟度依赖，同 condstate3 注脚）；「ALPN 相同则租金
相同」依赖两态 AL 侧同点这一 dstate17 结论。
