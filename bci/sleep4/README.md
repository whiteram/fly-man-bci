# bci/sleep4：慢振荡是内源的吗？+ τ≥15 s 驻留标度

sleep3 的诚实注记：完整慢循环（上行→塌缩→下行→再点火）的再点火
靠 35 s 第二次外部脉冲——「内源 vs 外源」未定。本研究直接关闭它。

## Arm 1：内源性检验（sz_l1，单脉冲 90 s，2 种子）

U=1.5e-4、τ=10 s（sleep3 循环剂量），只有 800–2800 ms 一次点火；
[40, 90] s 是再武装完成（塌缩 ~8 s + 3τ=30 s）后的**无脉冲窗**。

**判定：外源驱动（externally driven）**——两种子一致：

| 读出 | s616 | s617 |
|---|---|---|
| 脉冲1 瞬态峰 | 8.35 µV | 8.29 µV |
| 平台电平（10–30 s） | 2.30 µV | 2.30 µV |
| 无脉冲窗最大值 | 2.36 µV | 2.36 µV |
| 窗内 >3 µV 上行 episode | **0** | **0** |

塌缩后 ≥8τ（64 s+）零自发再点火：资源按 3τ 模型 ~30 s 就应
全武装，但**噪声单独无法重新越过闩锁阈值**——慢振荡的再点火
必须有外部事件。sleep3 的开放注记以直接演示（而非外推）关闭。

## 附带收获（trace 精化）

- **确定性交叉验证**：sz_l1_s616 前 60 s 与 sleep3 sz_l2_s616
  逐位相同（同种子不同 chem 条目）——机制无暗变。
- **下态头皮签名修正**：慢 STD 剂量下塌缩后是 ~2.3 µV 持续平台
  （群体速率：MBON 3–5 Hz vs 对照闩锁 388 Hz = 电路意义上真下态；
  ALPN 38 Hz 残余活动托高头皮），**不是**高 U 快塌缩的 1.4 µV
  深塌缩水平。读慢 STD 实验时下态阈值应取 1.5 µV 判据 + 群体
  速率共同定态。
- **上行相实为 1–2 s 瞬态**（MBON 窗均 157 Hz 在衰减，非 5 s
  持续 >3 µV 平台）；35 s 第二脉冲（~2.7τ，部分再武装）只把平台
  再闪到 3.6 µV。

## Arm 2：τ 网格（sz_l3，第二次点火 80 s，120 s 试验）

τ ∈ {15, 20} s × U ∈ {1e-4, 1.5e-4}，种子 616（单种子，趋势指示性）：

| 臂 (τ, U) | p1 峰 | 平台 µV (MBON Hz) | p2 峰 (MBON Hz) | p2/p1 |
|---|---|---|---|---|
| 15 s, 1e-4 | 8.67 | 2.24 (2.1) | 3.96 (93.8) | 46% |
| 15 s, 1.5e-4 | 8.34 | 2.03 (0.7) | 4.81 (74.1) | 58% |
| 20 s, 1e-4 | 8.66 | 1.97 (0.4) | 2.29 (8.1) | 26% |
| 20 s, 1.5e-4 | 8.33 | 1.92 (0.2) | 2.99 (31.7) | 36% |

四个读出：

1. **外源驱动在 τ=15/20 s 同样成立**：所有臂的 p2 都只是 1–4 s
   瞬态后回平台，无第二次持续闩锁；周期 vs τ 标度**无定义**
   （不存在自由运行周期——这是结论而非缺失）。
2. **再武装不完全（超出单 τ 模型的新定量发现）**：p2 在塌缩后
   ~72 s（≈4.8τ/3.6τ）打向全武装网络，单 τ 模型预测 d 已恢复
   99%+ → p2 应≈p1；实测只有 26–58%。资源恢复之外还有**更慢的
   第二恢复分量或状态依赖兴奋性**（点火后下态 MBON 0.2–5 Hz
   深于自发基线 ~43 Hz = 活动性压制持续存在）。τ 方向与模型
   定性一致（τ=20 弱于 τ=15，恢复更慢 ✓）。
3. **平台深度对 U·τ 剂量单调**（唯一的干净模型确认）：1.92–2.24
   µV 随 U·τ 增大而降低，MBON 平台 0.2→2.1 Hz 同向。
4. **τ=20/U=1e-4 出现迟发二次爬升**：p2 后 MBON 8→46.6（p2 后
   5–15 s）→12.7 Hz——网络仍会从平台尝试再爬，但无法越阈闩锁。

诚实边界：网格单种子，p2 强度百分数带种子噪声相位；第二恢复
分量的底物未定位（候选：非 CEN_C 边、内在适应、网络态依赖阈）；
再武装恢复曲线（扫描 p2 延迟 20/35/50/80 s）是直接后续。
→ **已由 sleep5 回答**：不是更慢的第二 τ，是 ~42–45% 的响应
封顶（点火后平台态上限），见 bci/sleep5。

## 用法

```bash
conda activate ffbm
python bci/sleep4/acquire.py --chem sz_l1 --t-end 90000 \
    --tau 10000 --us 0.00015 --seeds 616,617      # 内源性检验
python bci/sleep4/acquire.py --chem sz_l3 --t-end 120000 \
    --tau 15000 --us 0.0001,0.00015 --seeds 616   # τ 网格
python bci/sleep4/analyze.py
```

条目：`sz_l1`（单脉冲 90 s）/ `sz_l3`（双脉冲 120 s，第二次
80 s——τ=15/20 s 时旧 35 s 脉冲会打在未武装完的资源上）。
汇总：outputs/summary.json（含逐秒 rms 全序列 + 群体速率）。
