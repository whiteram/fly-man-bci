# bci/odormix：嗅觉混合物非线性 + 顺序解码

气味不只是单一分子——天然气味是混合物。本范式用两气味体系
（DA1 cVA 150 pA / DM2 果醋酯 600 pA，均衡响应幅度）检验三件事：
**混合是否线性、混合物是否是独立"感知类别"、时间顺序是否可解码**
（依赖上一轮修复的 chem 同 pop 多通道累加——重叠通道首次科学用途）。

## 条件（5 类 × 5 重复，区域集同 bci/olfactory，缓存命中）

| 条件 | 内容 |
|---|---|
| a / b | DA1、DM2 单独（复用 odor_da1/dm2_short） |
| ab | 两气味同一脉冲 [300,1200] 同时给 |
| abseq / baseq | A→B / B→A 顺序（各 400 ms 脉冲） |

## 结果（25 试次，干净信号）

| 分析 | 结果 |
|---|---|
| **混合非线性** | A 1.803、B 1.826、AB **1.844** vs 线性预测 2.297 → **AB/预测 = 0.80（次线性，20% 压制）** |
| 3 类身份 {A, B, AB} | **100%**（p=0.0005，chance 33%）|
| 顺序 A→B vs B→A（时间形状模板，早窗 300–900 ms） | **100%**（p=0.005，chance 50%）|

**解读**：

1. **次线性混合**是嗅觉的经典现象（嗅小球层 lateral inhibition /
   前感受器适应）——本模型在中央靶群共享 + 级联适应下复现出 20%
   压制，且混合物在头皮空间模式上是**独立的第三类**（AB ≠ A+叠B
   的感知）。
2. **顺序信息**留在响应时间形状里（先来的气味占据早窗）——时间
   模板解码 100%。这给"气味时间结构感知"提供了 BCI 通道。

## 用法

```bash
conda activate ffbm
python bci/odormix/acquire.py        # 5 条件 × 5
python bci/odormix/analyze.py
```
