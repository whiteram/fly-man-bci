# bci/dstate5：静默锁的退出条件——吸收态、保护性与第二锁位

dstate1–4 留下的开口：静默锁（单 DA1@150 脉冲诱导；ALPN 自持 ~20 Hz、
std 0.0145、≥60 s 零衰减）**怎么出来**？本弧线在锁建立 30 s 后加
探针阶梯（60 s trial，种子 62/63，chem 自动工作点 0.002）：
DA1@150（同强）/600（4×）/1600（10×）/LAL\*@L 600 pA×2.3 s（中央
点火脉冲，naive 网络同剂量即闩锁）。

## 结果：没有出口，但有结构

| 探针 | pre（锁） | post | 判决 |
|---|---|---|---|
| ctl 150 | ALPN 20.1, std .0145 | ALPN 20.3, std .0147 | 吸收 |
| 600 | 20.1 | 20.3 | 吸收 |
| **szl 中央点火** | 20.1 | ALPN 20.3, **MBON 0.13** | **吸收（保护！）** |
| **1600** | 20.1, mean −1.82 | **ALPN 100, MBON 11.8, KC 4.0, mean −3.43, std .017** | **升级为新锁位** |

三个结论：

1. **静默锁是吸收态（单向门）**：感觉重注入（≤4×）被完全吸收；
   没有任何探针把网络送回暗态（ALPN→0）。锁的退出在此参数空间
   内不存在——暗→锁容易（单脉冲），锁→暗（本弧线）无路。
2. **锁对中央癫痫点火有保护性**：同一个 LAL 点火脉冲（600 pA ×
   2.3 s）在 naive 网络引发完全闩锁（MBON 324 Hz、10.4 µV 平台，
   sleep3 ctl60 基线），在锁内只留 MBON +0.13 Hz 的涟漪——锁住
   的 AL 把网络按在一个中央引擎点不着的工作盆里。**功能损伤
   （静默锁）与癫痫保护同源**：两者都是 AL 引擎钉死的表现。
3. **状态空间分层，且只升不降**：10× 感觉探针把锁升级到第二个
   自持位——ALPN ~100 Hz、MBON 12、KC 4、mean −3.43、std 仍只有
   0.017（中央引擎仍未点火：非平台态、非大吸引子）——**第四态
   「高锁」**（双种子 99.4/100.6 Hz 重现）。AL 引擎至少有两个
   自持不动点（20/100 Hz），感觉探针在其间只做向上迁移。
   dstate2 的增益阶梯（0.003→大吸引子）是中央引擎的入口；这里
   的是 AL 引擎自己的阶梯。

「变蝇人」语义：平台态的静默锁不是等待被唤醒的休眠——是一个
**只能加深、不能自然解除**的吸收态，且它顺带获得了抗癫痫性。
退出（若存在）需要本弧线未覆盖的机制：抑制性操纵、STD 时标
扰动或增益下调（dstate2 已示 0.001 以下回暗态——参数退出存在，
动力学退出未发现）。

诚实边界：双种子（exit_1600 两种子数值差 <2%）；探针窗后 20 s
内判定稳定（60 s 内无退出，更长时标未测）；「高锁」的中央引擎
参与度以 MBON 12 Hz 为准仍属边缘；.protective 结论依赖 naive
闩锁剂量与锁内吸收剂量的同源比较（同 chem、同工作点）。

## 用法

```bash
conda activate ffbm
python bci/dstate5/acquire.py                     # 4 探针 × 2 种子
python bci/dstate5/acquire.py --arms exit_600 --seeds 63   # 补跑
python bci/dstate5/analyze.py
```

汇总：outputs/summary.json。状态参照（dstate1/3）：暗态
ALPN 0/std 0.10；锁 20/0.0145；平台 38/0.18。
