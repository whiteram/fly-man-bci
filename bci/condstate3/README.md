# bci/condstate3：残留态内条件化——租金更深，债务仍为零

condstate2 判明静默锁的学习受损是状态租金（解锁逐位退还）。最后
未测的状态是**闩锁深迟滞残留态**（dstate16/17：闩锁降到 0.002 后
AL 引擎仍在高锁不动点、中央余燃未熄）——它与静默锁的质差是
**KC 活着**（17 Hz vs 0 Hz），状态自身可能写可塑性。本弧线把
残留态的学习代价拆成**语境租金**（门）与**结构债务**（状态期间的
w 漂移）两部分直测。

## 协议（t_end 22 s，dangate2 标定，dstate16 latch_dn2 同代配方）

| 时刻 | 事件 |
|---|---|
| 0.8-2.8 s | LAL*@L 600 pA 点火（no_cen_damp，默认增益 0.004 全闩锁） |
| 6 s | `--gain-schedule` CEN_C ×0.5 → 0.002 残留态 |
| 12-16.5 s | 签名校验窗（对照 dstate17 画像） |
| 17-19 s | A+ 训练（KCg-m 1600 pA + DAN_err 800 pA） |
| 20-20.5 s | 探针 |

臂：ctl / res（残留内训练）/ **resnt（点火+残留、无训练——纯漂移
探针）** × 种子 62/63，各臂单 trial。

## 结果

| 臂 | ALPN/KC/MBON（训练前） | w_A | w_A 增长 | mod_ms |
|---|---|---|---|---|
| ctl62 | 0 / 0 / 0 | 0.0567 | 0.0267 | 593.5 |
| res62 | 99.3 / 17.2 / 23.7 | 0.0482 | 0.0182 | 372.5 |
| **resnt62** | 99.3 / 17.2 / 23.7 | **0.0302** | **+0.0002** | **2.5** |
| ctl63 | 0 / 0 / 0 | 0.0563 | 0.0263 | 586.0 |
| res63 | 98.3 / 17.2 / 27.1 | 0.0482 | 0.0182 | 371.8 |
| **resnt63** | 98.3 / 17.2 / 27.1 | **0.0302** | **+0.0002** | **2.2** |

分解（预注册）：**债务 = resnt 增长 = +0.0002**（基线 0.7%，
grown_frac 0.0）；**训练增长 = res−resnt = 0.0180/0.0180**，
**训练比 = 0.673 / 0.685**。

## 三个结论

1. **结构债务为零（含最深状态）**：全程经历全闩锁（0-6 s，0.004）
   + 残留态（KC 17 Hz 活动背景）后 w 仍停在 w0（grown_frac 0.0）。
   机制：可塑性写入需要 KC eligibility × DAN 调制，而残留态里
   DAN 门关死（resnt mod_ms 2.2-2.5、DAN_pre 0.18 Hz）——**写入
   通道被门把关，状态再深、门关着就写不进账**。全状态谱的学习
   代价都是租金。
2. **残留态的租金更深**：训练比 0.67-0.69 vs 静默锁 0.78-0.80；
   门积分 −37%（372 vs 593）。与 condstate1/2 合并成**租金-
   状态深度剂量曲线**：ALPN 20 Hz → 门 −20% / 学习 −21%；
   ALPN 99 Hz → 门 −37% / 学习 −32%——租金随 AL 自持水平单调
   加深（两点，曲线形状未测）。
3. **KC 悖论在残留态重现且更强**：训练窗 KC 直驱 63-64 Hz（幼稚
   54）——驱动不但没坏反而更高（17 Hz 基底叠加），学得更少；
   瓶颈纯在门。与 condstate1 的门介导结论跨状态稳定。

## 附带观察（诚实记录）

- 残留签名 ALPN/KC 与 dstate17 死吻（98-99 / 17.2）；MBON 23.7-27.1
  低于参照 44.6、DAN_pre 0.18 低于 2.0——本协议闩锁期仅 6 s
  （dstate16 为 30 s），中央余燃仍在衰减中：**残留态画像有成熟度
  依赖**，租金数字对应「6 s 闩锁 + 11 s 残留」这个时点。
- res 与 resnt 的训练前逐位同前缀（同种子确定性，与 condstate2
  一致）。

## 语义

「变蝇人」学习账目的完整版：状态谱最深的残留态也不产生结构债务
（DAN 门是可塑性写入的守门人，状态深不等于写入深）；租金随状态
深度分级——静默锁 −1/5、残留态 −1/3——且解锁即退（condstate2）。
病理性的完整描述：**触发阈低 + 锁内不可出 + 租金随深度加深，
但永远不是疤痕**。

## 诚实边界

单 trial × 6 臂（两种子）；租金-深度曲线仅两点；残留成熟度未扫描
（闩锁时长→MBON 余燃水平→租金的关系未测）；训练增长分解假设
「状态漂移与训练写入可加」（债务近零时该假设无害）。
