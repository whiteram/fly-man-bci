# bci/condstate27：明适应底对照——不可表达（结构性负结果）

## 问题

所有 s 值（态−naive）都以暗适应底为参照（cs25：视觉通路强直）。
真实场景环境光可变——本弧试图测"明适应底"：新目录条目 `light`
（单白帧，与 dark 单黑帧同构）+ 与 cs25 完全相同的协议（无 chem、
seed 62、20 s、层速率提取），1 跑 2.6 min GPU。

## 结果（outputs/compare.json）

**明适应底在本输入路径下不可表达**：

- 恒亮跑的头皮与暗跑**全程 20 s 逐位相同**（diff=0）、层速率
  完全一致（R=0/L=100/MID 18.2/T4 6.9/T5 1.4）；
- 原因：视频输入管线按刺激做对比度归一化——**恒定帧零对比度，
  白帧与黑帧驱动等价**；
- 目录条目 `light` 已如实标注（"实测与 dark 逐位相同…留作 cs27
  记录"），避免误导后续弧。

## 语义

- **s 参照的环境误差棒在输入路径层为零**：暗底（"单黑帧视觉
  静默"约定）是本管线唯一可达的静息参照——不存在暗/亮底漂移
  这个误差源；光照变化的效应只能通过**时变**刺激研究（如
  ssvep1_f14 已做）；
- 对总账的一处加固：所有 s/σ* 数字不必携带"环境光"误差棒；
- 方法论入 pitfall：恒定刺激经归一化管线 = 无刺激。

## 诚实边界

- 结论限于视频输入路径；化学/本体感觉输入不涉及；
- "逐位相同"以相同种子为前提（RNG 流一致证明是输入路径本身
  无差异，非巧合）；
- 未尝试非均匀恒定图案（如棋盘格静止帧——仍有对比度，可测
  "图案适应底"，属另一问题，未测）。
