# bci/condstate33：cs32 干净 MI 的类不均衡敏感性

## 问题

cs32 头条（干净 I_dec=1.26 bit）带 caveat"naive 池 44 样本（类
不均衡，MI 对 naive 偏保守）"——方向是猜的。本弧用平衡子抽样
（各态下采样到 naive 的 11 窗、20 次重复）直接检验。

## 结果（outputs/balance_check.json）

| 估计器 | I_dec (干净) |
|---|---|
| 全样本（11/148/148/145）| **1.26** |
| 平衡子抽样（11/11/11/11 ×20）| **1.62 ± 0.13** |

**不均衡是把 MI 往低估**（原 caveat 方向猜反）：naive 类的稀薄
样本在全样本混淆矩阵中拉低 I。真实干净 MI 应读作**样本受限带
1.26-1.62 bit**（naive 记录只有 20 s——诚实修复需 naive 300 s
长跑，另一高成本可选项）。

**死亡判据不受影响**：0.1 µV 归零/11.4 µV 零 bit 与估计器选择
无关（背景加成态的类间重叠是物理的）。

## 复现

```bash
python bci/condstate33/balance_check.py
```
