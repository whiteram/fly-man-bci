# bci/fanin1：KC→MBON 读出腿的扇入密度

队列原命题「APL 扇入密度（降连接组阈值）」经审计**否决**；转向
唯一有大弱尾巴的活性回路腿 **KC→MBON**（可塑底物腿），问题变为：
**把 w∈[W,5) 的弱突触补进可塑池，学习可见性与稳定性变吗？**
答案：**几乎不变——w≥5 的强边核心已功能饱和**。

## 三层发现

1. **APL 命题否决**：APL→KC 在 w≥5 已覆盖 100% 的 KC（4,104 对
   /4,064 KC），弱尾巴只 +13% 突触、零新增覆盖；PN→KC 同样近饱和
   （93% 覆盖，+13%）。降阈值增密对这些腿不存在空间。
2. **弱尾巴的身份（装配层发现）**：KC→MBON 弱尾巴 +27,714 对
   （+83%），但连接组 raw id 与电路 CEN 表 id 是**两个 id 空间**
   （raw 1xxxxx 族 vs 合成 10062xxx 族）——弱行必须经 `_rmap`
   重映射才能入表（首轮未映射在延迟查查处 KeyError，已修）。
   可映射的弱行 w≥1 时 +27,286 → 60,684 边（raw 61,210 与之差
   = 真正在 CEN 群体外的 body）。弱尾巴与 CEN 成员资格的边界
   高度重合——w≥5 截断基本就是建模群体的边界。
3. **功能上弱尾巴可忽略（本研究的答案）**：dangate2 标定协议、
   全局门、5 连试 A+ 学习曲线、4 臂：

| 臂 | 池大小 | lr | w_A t4 | mod_ms t0→t4 | grown% t4 | max 头皮 µV |
|---|---|---|---|---|---|---|
| base | 33,398 | -2e-7 | 0.273 | 1817→702 | 59.7% | 2.5 |
| f2 | 50,779 | -2e-7 | 0.256 | 1663→663 | 59.0% | 2.5 |
| f1 | 60,684 | -2e-7 | 0.252 | 1632→659 | 60.2% | 2.6 |
| f1r | 60,684 | -1.094e-7（按池比缩放） | 0.177 | 1795→892 | 54.6% | 2.2 |

- **固定 lr**：池 +82% 使学习曲线只慢 ~8%（w_A 0.273→0.252）、
  RW 递减与稳定性不动——**读出腿功能饱和，w≥5 组装截断被验证**。
- **f1r 对照**（同总可塑性）：成比例变慢，确认固定 lr 臂的差异
  全部来自稀释而非新边贡献。
- 全程无 latch（基线头皮 1.36 µV 恒定；mb-mod DPM 的教训未重演）。

## 结论

连接组的强边核心（w≥5）承载了全部回路功能；扇入密度不是这个
模型的学习可见性杠杆。`--kcm-fanin` 机制保留（重映射 + 去重 +
盐化缓存键，供未来 Tier 级装配扩充复用）；DAN→KC（+123k 对）
与 KC→DAN（+136k 对）的超大弱尾巴在被压制的非活性腿上，若未来
激活突触级 US 递送才是它们的战场——记为方向，不在本轮。

诚实边界：单会话 5 trial、单种子；f1r 的 lr 缩放用池大小比
（0.546）近似总前向电流比（弱边 weight 更小，真实总前向比更小）。
