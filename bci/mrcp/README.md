# bci/mrcp：运动准备电位 MRCP（2 类，执行前解码）

对齐人类 MRCP/Bereitschaftspotential 范式思路（Niazi et al. 2011）：
**运动执行之前**的准备期信号可否解码"将要动的侧别"。

## 范式（每试次 3.6 s，类别 = 侧别）

- **1300–3500 ms LAL 阶梯坡道**（同侧 LAL* 群，300/600/900/1200 pA
  阶梯 @1300/1900/2500/3100——同一群上堆叠多通道实现；PhotoCascade
  30% 适配后稳态 90→360 pA）= 准备电位上升期；
- **2800–3500 ms 同侧腿 PRO 400 pA 复反馈** = 运动执行（感知副本）；
- 区域集与 MI 一致（含 VNC 反射弧）。

## 结果（12 试次，干净信号）

| 解码 | 准确率 | perm-p | chance |
|---|---|---|---|
| **运动前坡道窗 L/R（1500–2700 ms）** | **100%** | **0.0035** | 50%（perm95 83%）|

时间分辨 rms：坡道阶梯上升可见（0.733→0.737 µV 峰，随步进），
2800 ms 执行后回落（0.70，PRO 复反馈的轻度抑制签名与 mi 一致）。

**解读**：意图侧别在执行前 1.3 s 即可从头皮单试次解码——果蝇版
"意图触发" BCI 场景成立（MI-v2 证明保持态可解码，本范式证明
*坡道爬升期*同样可解码且先于执行）。

## 工程注记（顺带修掉的管线 bug）

首版采集的 rms 时间表不升反降，暴露 `export_data.chem_fn` 的
**同 pop 多通道覆盖 bug**（`out[pop] = inc` 后通道覆盖前通道）——
历史协议通道从不重叠所以从未暴露；已改为累加（对旧协议数学等价），
重采 12 试次后阶梯正确呈现。

## 用法

```bash
conda activate ffbm
python bci/mrcp/acquire.py           # 2 类 × 6（~110 s/试次）
python bci/mrcp/analyze.py
```
