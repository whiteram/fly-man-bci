# bci/kcdrv2：DAN→KC 通道的因果检验——状态门控 + DAN→MBON 直连

kcdrv1 用锁相+布线三角定位了平台态 KC +6 的驱动源（DAN→KC 兴奋行），
但仍是相关性证据。本弧线做直接因果实验：**naive 暗网络（KC 基线
精确为 0）里单独注入 DAN 池**，看 KC 是否被抬起来。

布线预测（CEN_C 表）：PPL103\* 的 2 个细胞广布 **1,978 行 / 1,469 个
KC（均权 7.07）**——天然 US 广播通道；PAM07\* 14 细胞仅 147 行/138
KC（w 5.47）——扇入差 13×。

## 结果：直驱不通，通道是状态门控的

| 臂 | DAN（注入池）速率 | **KC 增量** | MBON 增量 |
|---|---|---|---|
| dark | 0 | 0 | 0 |
| us_pam07（800 pA） | 4.53 Hz | **0.000** | +0.012 |
| us_ppl103（800 pA） | 0.67 Hz | **0.000** | +0.035 |
| us_ppl103 ×4 | 1.18 Hz | **0.000** | +0.73 |
| us_ppl103 ×16（12.8 kPa） | **5.88 Hz** | **+0.011（≈0）** | **+12.33** |

判决链：

1. **注入本身有效**（DAN 速率可测、dark 全零基线干净），但
   **PPL103 DAN 达 5.9 Hz（= 平台态 DAN 增量同量级）时 KC 仍为
   0**——DAN→KC 通道在 naive 态**速率足够也不放电**。
2. **状态门控结论**：kcdrv1 的平台态 KC +6 依赖平台态本身的中央
   去极化（KC 被复发电流推到阈值附近），DAN 输入只在那个状态下
   越阈。**奖励通道不是随时可用的后备腿，而是平台态专属通道**——
   「变蝇人在平台态用价值系统回应世界」的机制收窄为：那个状态里
   这是唯一在阈值之上的通道。
3. **意外发现：DAN→MBON 直连重通道**。×16 下 MBON +12.3 Hz
   （KC=0 排除经 KC 介导）；布线：**DAN→MBON 1,404 行、100%
   兴奋性、均权 26**（PAM07/PPL103 子集 108 行、均权 47）——比
   DAN→KC（w 6.4）重 4 倍。这精化了 kcdrv1 的机制叙述：平台态
   MBON +60 增量主要走这条直连快道（DAN +6 × w26）。「奖励通道
   接管」实为两支：**DAN→MBON（重、随时可驱）+ DAN→KC（轻、
   平台态门控）**。
4. 条件化弧线的机制注脚：US（PAM07\*/PPL103\*）在训练窗内**直接
   驱动 MBON**（w 47）——US 同时表达为 V 反馈的一部分（comp 臂
   mod 饱和的成分之一）；探针窗无 US，学习读出不受污染。
5. US 通道扇入不对称：PPL103 广播型（1,978 行/2 细胞）vs PAM07
   窄带型（147 行/14 细胞）——两路 US 在 KC 层面的覆盖差 13×，
   对条件化的联结广度有直接含义（comp 系列的 B 联结可能主要靠
   PPL103 广播腿）。

诚实边界：单种子；「状态门控」由 naive 端阴性 + 平台端阳性
（kcdrv1）夹逼而成，未直接记录平台态 KC 膜电位；×4→×16 的 MBON
响应非线性（17×/4×）未拆机制；KC 增量分辨率受 4050 细胞均值
限制（单 KC 层面的亚阈效应不可见）。

## 用法

```bash
conda activate ffbm
python bci/kcdrv2/acquire.py                     # dark + 两路 US
python bci/kcdrv2/acquire.py --arms us_ppl103_x4,us_ppl103_x16

```
