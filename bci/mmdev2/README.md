# bci/mmdev2：等强度/等响应偏差——身份新异性是否存在？

mmdev 重审（2026-09-20）发现 STD=强度依赖增益控制、旧偏差脉冲
（DM2 600 pA = 4× 标准）自耗竭反转 deviance，预告需等强度设计。
本研究分两步执行，结论：**本系统无 MMN**——所有偏差比数字都是
强度伪影 + 分母塌缩 + 地板噪声；oddball 的真实主信号是一个
**−0.43 µV 全有全无 DC 状态开关**（意外主发现）。

## 三步设计

1. **等强度（chem `mmn_match`，DM2@150）**：偏差脉冲头皮完全
   不可见（devB −0.0008±0.0004 µV，devB/A1≈−0.01；三个条件同）。
   旧 2.74 偏差比全由 4× 强度承载——强度与响应通过 DM2 通路的
   低敏感度混杂，身份新异性在 150 pA 下根本没被测到。
2. **solo 剂量标定（`da1_solo`/`dm2_solo` + `--chem-amp-scale`）**：
   DM2 阈值崖在 466–492 pA——150/300 pA 不可见（+0.001/+0.015），
   466 pA 双峰（0.027/0.090，崖区不可靠），492 pA 稳定平台
   （+0.247±0.009 vs DA1@150 +0.197，**校准比 1.25**）。
3. **等响应（chem `mmn_matchr`，DM2@492）**：oddball 语境里同一
   脉冲只剩 devB +0.0095±0.0005——比 solo 标定低 **~25×**。
   预登记三向判读（devB/A1 vs 校准比 1.25：≈1.25 纯强度 / ≪1.25
   交叉适应 / ≫1.25 真偏差）落在**交叉适应**：标准列车的适应跨
   气味身份传递，共享下游底物把偏差响应一并压掉。

| 指标（µV，4 runs） | std_off | std_on U=0.05 |
|---|---|---|
| A1（首发净响应） | +0.151 | +0.173 |
| devB 净响应 | +0.0095±0.0005 | +0.0042±0.0040 |
| devB/A1 | 0.06 | 0.02 |
| solo 标定 devB/A1 | — | 1.25（两臂同一 DA1 列车、种子配对） |

## 意外主发现：DC 状态开关

窗口分解（mean/std 分离）发现所有 oddball net 量都骑在一个
持续平台上：暗态 mean −1.389 / std 0.100 → 列车后 mean −1.825 /
std 0.179（rms 1.393→1.834）。性质：

- **全有全无**：任何"打得穿"的单脉冲（DA1@150、DM2@466、
  DM2@492）触发同一满幅台阶 **−0.430±0.002** + std 翻倍；开关
  阈值远低于快响应阈值（DM2@466 快响应仅 +0.059 却满台阶；
  DM2@150 两者皆无）。
- **单脉冲即饱和，其后完全盲**：A5 / devB（150 与 492 pA 台阶
  逐位相同 +0.004 / +0.004）/ recA 的后续台阶 ≤0.004=地板。
  身份盲 + 幅度盲。
- **与快响应同走 ORN→CEN 通路**：U=0.05 对开关无影响；U=0.1
  连开关一起摧毁（A1 台阶 −0.107±0.188，种子双峰）。
- **8 s 零恢复**（chem `da1_dc8`，双种子 mean 全程 −1.820±0.002
  平坦）：τ_recovery > 8 s，准永久状态翻转，不是慢弛豫。
- **主导嗅觉头皮信号**：−0.43 µV = 3× A1 快响应净值的 DC 分量。

## 结论链

1. **无 MMN**（快增量无、DC 台阶无身份新异性）；mmdev README 的
   「身份偏差响应成立」一并撤回——该 3× 同样由 600 pA 强度承载。
2. 快响应层**交叉适应**：偏差响应比 solo 标定低 ~25×，适应跨
   身份传递（底物未定位——候选：共享 PN 下游 / 中央脑群体）。
3. **DC 开关是嗅觉头皮的主慢分量**：列车范式的 net-rms 度量必须
   先扣除/分层它；同时它是一个候选状态读出轴（气味触发的双稳
   基线翻转，BCI 相关）。
4. 诚实边界：DC 机制未定位（中央脑状态？读出端？）、交叉适应
   底物未定位、DC 衰减只界定了 τ>8 s——三者均为后续方向。

## 用法

```bash
conda activate ffbm
python bci/mmdev2/acquire.py                          # 等强度 3 条件 ×4
python bci/mmdev2/_pilot_dm2.py                       # DM2 剂量标定
python bci/mmdev2/acquire.py --chem mmn_matchr \
       --suffix _mr --only std_off,std_on_u0.05       # 等响应主臂
python bci/mmdev2/analyze.py [--meta meta_mr.json]
```

条目：`mmn_match` / `mmn_matchr` / `da1_solo` / `dm2_solo` /
`da1_dc8`（viz/data/chem_inputs.json）。汇总：
outputs/pilot_dm2.json（剂量 + DC 台阶 + 衰减全程）。
