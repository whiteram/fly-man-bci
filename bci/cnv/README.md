# bci/cnv：CNV 预期电位（S1→坡道→S2，2 类）

对齐 Walter 1964 双刺激结构：**S1 预警**（同侧腿 PRO 400 pA，
300–600 ms）→ **预期期**（同侧 LAL 阶梯坡道 300/600/900 pA
@900/1500/2100，PhotoCascade 适配后稳态爬升）→ **S2 命令**（同侧
PRO 600 pA，2400–3100 ms）。类别 = 侧别，6 重复。与 MRCP 的差别：
准备期由外部 S1 触发（外控预期），MRCP 是自发坡道。

## 结果（12 试次，干净信号）

| 解码 | 准确率 | perm-p | chance |
|---|---|---|---|
| 预期窗 L/R（1000–2300 ms，S2 之前） | **100%** | **0.0035** | 50%（perm95 83%）|

预期侧别在 S2 之前 1.3 s 可从头皮单试次解码——"外控预期"场景
成立，与 MRCP（自发准备）互为补充。

## 用法

```bash
python bci/cnv/acquire.py
python bci/cnv/analyze.py
```
