# bci/stereo：立体嗅觉——哪边在飘味（2 类）

ORN 化学组新增侧别限定（circuit4：`类型@rootSide`，类型-only 键
保留向后兼容；rootSide L 884 / R 1,344 / unknown 411）。每试次
3.6 s：**同一肾小球（DA1）只在一只触角上给 900 ms 气味脉冲**
（300–1200 ms），幅度按侧别群大小补偿（L 51 细胞 310 pA /
R 105 细胞 150 pA），类别 = 气味来向。

## 结果（12 试次，17 通道空间模式 LOO + 置换）

| 解码 | 准确率 | perm-p | chance |
|---|---|---|---|
| 气味来向 L/R | **100%** | **0.0035** | 50%（perm95 83%）|

**解读**：同一气味、同一肾小球类型的左右两份拷贝，在头皮上留下
完全可分的偏侧签名——嗅觉的空间来源成为第五个被验证的偏侧 BCI
通道（触觉/本体/听觉侧别 + 立体嗅觉）。对果蝇这是趋化定向的
感觉基础；对范式这是"气味方位"控制器的直接依据。
