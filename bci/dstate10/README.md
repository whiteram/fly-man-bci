# bci/dstate10：锁形成的时长阈——暴露-固化面的第二条锐边

dstate7 定量了剂量轴（100-150 pA 锐边）；本弧线补**时长轴**：
成固剂量（150 pA）下多短的暴露仍能留下永久静默锁？

| 时长（150 pA） | 终态 [10,29] s |
|---|---|
| 25 ms | 暗（mean −1.389） |
| 50 ms | 暗（逐位同上） |
| 100 ms | 暗（逐位同上） |
| **300 ms** | **锁**（ALPN 19.5-19.8，std 0.0146） |

结论：

1. **时长阈在 100-300 ms 之间，边缘同样锐利**——固化需要
   剂量 ≥150 pA 与时长 ≥~300 ms **同时**满足；单轴安全不保证
   逐轴安全（剂量 150 + 时长 100 = 暗）。
2. **暗侧逐位一致**（三档时长同 −1.389/0.0050）——阈下暴露
   网络完全复原，无累积损伤迹象（与锁的吸收性互补：要么完全
   复原、要么完全固化，没有中间带）。
3. **种子 63 复现 300 ms 锁**（19.53/0.0146 vs dstate1 种子 62
   的 19.8/0.0145）——顺带把剂量边的锁点加固到双种子。

暴露-固化面（当前时代）至此完整：**剂量轴 [100,150] pA × 时长轴
[100,300] ms 的矩形外=安全（暗，可完全复原），矩形内=一次固化
（静默锁，不可逆）**。边缘皆锐、无中间带——「变蝇人」的一次
暴露阈值在两个轴上都是突变式的。

诚实边界：单种子（s63 只加固 300 ms 点）；[100,300] ms 未细分；
锁的「不可逆」是 60 s 窗 + dstate5/6 探针与 300 s 外推。
