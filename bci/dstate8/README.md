# bci/dstate8：静默锁对 AL 群体大小的敏感性——脆弱、不可补偿

新手术 `--al-subsample F`（种子化、缓存确定性的 AL 细胞子集；
只保留两端都在子集内的 ALL 行，行数 ∝F²）× 锁形成检验。

## 结果

| 臂 | 有效环路增益 | 状态 |
|---|---|---|
| F=1.0（全群体，dstate1 参照） | 0.002 | **锁**（ALPN 20，std 0.0145） |
| F=0.7 / 0.5 / 0.3（中性增益） | 0.002 | 全暗（ALPN 0，mean −1.39） |
| F=0.5 + 增益 ±25%（0.0015/0.0025） | — | 全暗 |
| **F=0.7 + F⁻² 补偿（0.004）** | ~0.002 当量 | **跳过锁→强吸引子**（ALPN 113，std 0.062，mean −7.6） |
| **F=0.5 + F⁻² 补偿（0.008）** | ~0.002 当量 | **更强吸引子**（ALPN 165，ALON 468，std 0.109，mean −13.9） |

三个结论：

1. **锁对细胞丢失脆弱**：F=0.7（丢 30%）即失锁——中性增益下
   子采样把环路沿增益轴推离窗口（行数 ∝F²，F=0.7 → 等效
   0.00098，恰在 dstate2/3 窗下缘之下），固定增益无恢复。
2. **F⁻² 增益补偿不恢复锁——直接越过它**：按行数比例回补增益
   （0.004/0.008）后子采样环路不回到 20 Hz 锁，而是跳进更强的
   吸引子（ALPN 113-165 Hz、std 0.06-0.11）。**锁区不是随 F²
   可重标定的**——丢失细胞改变的是环路的 E/I 平衡结构本身，
   不是等效增益。锁窗在扰动下收缩为零的又一例（sign3 的窗宽
   收缩、sign4 的无模拟区——同一现象学第三次出现）。
3. **锁 = 全群体精确平衡的专属物**：20 Hz 静默锁依赖于完整
   AL 群体的分布性质（连接数分布、E/I 行的比例），任何随机
   丢失都不可由增益补偿。脆弱性等级：锁 ≫ 高锁/闩锁（后者在
   大得多的参数域存在）。

「变蝇人」语义：静默锁这个「一次暴露即半永久固化」的产物同时
是**脆弱的**——它的存在依赖神经元的全数在场；退化（细胞丢失）
不会得到「更弱的锁」而是「没有锁」或「更强的锁」。这与退行性
过程的临床直觉（功能渐变消失）相反：模型里是突变式的。

诚实边界：单种子；F∈{0.3,0.5,0.7} 三点、每点 1-2 个增益；
F=0.7 的 0.0025-0.004 之间与 F=0.5 的 0.008 附近存在未扫窄缝
（但 f070@0.004 已越过锁区直接强吸引子，窄缝存在概率低）；
补偿律取 F⁻²（行数当量），按细胞数 F⁻¹ 补偿未测。
