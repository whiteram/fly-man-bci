# bci/sign3：sign 下 ALL 增益扫描——「死或闩」，无中间带

sign2 判决「sign 下气味重标定 = AL 引擎再设计，非增益旋钮」后，
本弧线把最后一个便宜的增益候选扫掉：`--al-local-gain`（ALL 组
= AL 内部行整体增益，dstate3 的中性值 0.002）在 sign 下 2×~8×
扫描 + 细扫。mmn_match A1，种子 616，参照 base ALPN +11.3 Hz。

## 结果

| ALL 增益 | ALPN A1 | 脉冲尾段（3.2-3.6 s） | 判决 |
|---|---|---|---|
| 0.002（中性） | +0.17 | 0 | 死（复现 sign2） |
| 0.004 | +0.13 | 0 | 死 |
| 0.005 | +0.12 | **134** | **脉冲串积累闩锁** |
| 0.006 | +0.10 | 173 | 脉冲串闩锁 |
| 0.007 | **+90.3** | 210 | 首脉冲即闩 |
| 0.008 | +138 | 235 | 首脉冲即闩 |
| 0.016 | +265 | 391 | 首脉冲即闩（更强） |

三个结论：

1. **「死或闩」，无窄窗**：gain ≤0.004 时 A1 响应死（~0.1 Hz）；
   ≥0.005 出现的「响应」全是**自持闩锁**（尾段 134-391 Hz 不衰
   减），且闩锁随增益提前（0.005-0.006 需 5 个脉冲积累，0.007 起
   首脉冲即闩）。**不存在「有响应且会衰减」的中间点**——7 个
   增益点无一给出带分级响应的可用工作点。
2. **与 dstate2/3 的现象学同构**：sign-off 电路在 CEN_C 增益上
   也是窄窗（0.0016-0.0023）+ 两侧死/闩——AL 局部引擎在 sign 下
   保留了同一结构，只是窗移到了 ALL 增益轴上且**窗宽收缩为零**
   （本扫描分辨率内）。
3. **重标定路线最终收窄**：增益（全组）、化学幅度（sign2 C2）、
   闩锁窗（本弧）三个便宜候选全部排除。sign 版气味功能需要
   **逐腿再平衡手术**——ALL 组按边符号拆分、独立缩放兴奋腿与
   抑制腿（如 `--al-leg-balance E=1.0,I=0.3` 类旗标），扫描
   E:I 比找「分级响应且不闩」的工作区。这是 sign 重标定程序
   的第一个真手术（sign4）。

机制注脚：g008/g016 的闩锁是纯 AL 事件（MBON 尾段仅 6.9/3.3 Hz
——中央引擎未点火），是 dstate5「高锁」的 sign 版亲缘态；
sign-on AL 引擎的再生阈值在 0.004-0.005 之间，比 sign-off 工作点
（0.002 内含 40% 抑制当兴奋）的等效阈值高约 2-2.5×——抑制腿上线
吃掉了环路增益，需要更高驱动才再生，一旦再生就锁死。

诚实边界：单种子；7 个增益点（0.005-0.007 之间步长 0.001，更细
窗口不能完全排除但现象学强烈提示不存在）；闩锁判定窗 3.6 s
（更长时标的自然衰减未测，dstate5 示 AL 锁 ≥60 s 不衰减）。
