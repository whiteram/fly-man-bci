# bci/noise_robustness：逐范式传感器噪声稳健性表

**纯分析**（零采集）：对全部分类范式的已存试次输出重跑一个**统一
解码器**——各范式规范窗口的空间 rms（17 电极）特征 + z 评分 +
最近质心 LOO——同时在**原始信号**上叠加白高斯电极噪声，比例
r ∈ {0.3, 1, 3, 10} × 该范式自身中位信号 AC rms（相对刻度 → 跨范式
可比；ssvep 分支的临床传感器/信号比 1.5/3.79 ≈ 0.4 落在区间内），
每档 20 次噪声抽取。噪声在窗口内加在信号上再提特征（rms 特征的
正交偏置等物理后果都包含）。

统一解码器**刻意不用**各范式的定制分析器（模板/CCA/置换检验见各
README）——它是稳健性的下界，并使各列可比。

## 解读

- **空间签名范式极其稳健**：motor_imagery/stereo/visualfield/mrcp/
  cnv 到 r=10（信号 rms 的 10 倍白噪声）仍 100%——rms 特征在 ~3 s
  窗内积分，白噪声相对涨落按 1/√N 缩小；大空间模式是本项目最
  稳健的读出轴（与主线结论一致）；
- **剂量/触觉/癫痫**中 robust，r=3-10 间退化；
- **嗅觉**低噪反而略升（83.3→89.4%，噪声对退化特征方向的正则化）
  后正常退化；
- **gustatory**（本来 chance 水平）噪声下"提升"到 ~60% 是最近质心
  在无信息特征上的随机游走，非真实稳健性（诚实标注）；
- **cvep** 空间 rms 立即失效（17.5%→5%）：其类别信息在**时间码**里，
  统一空间解码器本就不适用——定制模板分析器（干净 100%）才是该
  范式的正确读出；
- direction/auditory/odormix 中等幅度空间签名，行为符合预期。

## 限制

- 统一解码器 ≠ 定制分析器（clean 列与各 README 的数字略有出入：
  olfactory 89%（定制）vs 83%（统一）等）；
- 白噪声模型，无 1/f 或相关噪声成分（假想设备下界）；
- p300（事件级分析）与学习类范式（condit 系列）不适用统一表。

## 用法

```bash
conda activate ffbm
python bci/noise_robustness/analyze.py    # ~2 min，纯本地分析
```
