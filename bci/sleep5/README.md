# bci/sleep5：再武装恢复曲线 R(t)

sleep4 发现再武装不完全（~5τ 时 p2 只有 p1 的 26–58%，单 τ 模型
预测 99%+）。本研究固定循环剂量（U=1.5e-4、τ=10s、种子 616），
把第二次点火延迟 D 扫过 {10, 20, 35, 50, 80} s，量化恢复的形状
（35 s 点复用 sleep3 sz_l2 同种子同剂量 trace——p1 逐位同 8.35 µV）。

## 结果：恢复在 ~42% 封顶，且不是第二慢 τ

| D (s) | 塌缩后 (s) | p2 峰 µV | R_scalp | R_mbon | 单 τ 预测 |
|---|---|---|---|---|---|
| 10 | 2 | 2.34 | 0.28* | **0.044** | 0.18 |
| 20 | 12 | 3.02 | 0.36 | 0.211 | 0.70 |
| 35 | 27 | 3.62 | 0.43 | 0.414 | 0.93 |
| 50 | 42 | 3.70 | 0.44 | 0.429 | 0.98 |
| 80 | 72 | 3.72 | 0.45 | 0.411 | 1.00 |

\* D=10 的 R_scalp 是平台地板伪影（p2 峰 2.34 ≈ 平台 2.30 µV，
真实瞬态≈0）；**R_mbon 是短延迟的诚实读出**（4%）。

三段结构：

1. **快分量按模型 τ 恢复**（2s→27s 塌缩后：0.04→0.41，形状与
   1−e^{−t/10s} 一致）——STD 资源恢复确实在工作。
2. **恢复在 ~42%（MBON）/ ~45%（头皮）封顶**：35→80 s 完全平坦。
   双指数拟合退化为 **45% 按 τ=10s 恢复 + 55% 在 80s 尺度上不
   恢复**（τ2→∞）——不是更慢的第二时间常数，是封顶。
3. **封顶的解释：点火后平台态的响应上限**。p1 从暗态出发
   （MBON 基线 ~43 Hz），p2 从平台态出发（MBON 3–5 Hz，深于
   基线 = 活动性压制持续存在，sleep4）。资源（d）按 τ 恢复，
   但**网络态不跟着恢复**：同一 d 下从被压制的平台态出发的
   级联只能达到暗态强度的 ~42–45%。

## 结论：真迟滞双稳（活性维持的下态）

把 sleep2–5 串起来：**上行态**=外部点火触发的 CEN_C 复归吸引子
（MBON ~400 Hz），被自身放电经慢 STD 在 2–8 s 内耗竭熄灭；
**下行态**=活动性维持的被压制态（MBON 3–5 Hz 深于基线、头皮
~2 µV 平台），稳定 ≥80 s、STD 资源按 τ 部分恢复但响应能力封顶
在 ~45%、噪声无法再闩锁。两态间的切换都是外部事件驱动的：
上→下自发的（STD 耗竭），下→上需要强点火。慢振荡的"循环"
由外部事件序列拼接——本系统实现的是**发作样迟滞对**，不是
内源振荡器。

诚实边界：单种子（确定性前缀使 p1 逐位同，p2 带噪声相位差）；
封顶的底物未定位（候选：平台态的抑制性张力、非 CEN_C 边的
慢适应、突触外状态）；"响应能力封顶 vs 资源恢复"的分离需
全状态读出（d dump + 速率）联测。

```bash
conda activate ffbm
python bci/sleep5/acquire.py
python bci/sleep5/analyze.py
```
