# Experiment 004 — 视网膜拓扑运动光栅：时间频率调谐与方向对称性

**科学问题**：R1-R6 + L1/L2/L3 板层回路对漂移光栅的响应——(a) 时间频率
调谐曲线长什么样（闪烁融合）？(b) 板层水平是否存在方向选择性？（文献
预期：无——方向选择性在髓质 T4/T5 才出现，这可量化检验）

**视网膜拓扑**：R 末梢（PreSyn 均值坐标）投影到垂直于眼轴的平面。由
神经叠加原理（每个 cartridge 汇聚 6 个共享同一视轴的 R），板层 cartridge
镶嵌本身就是视角坐标图——投影坐标是合法的视网膜拓扑代理。光栅轴 e1
取与双眼轴都垂直的方向。左眼 λ=137.8 μm（跨度 275.7）、右眼 λ=122.9 μm
（跨度 245.8），每眼 2 个周期。

**刺激与设计**：I(x,t) = I_g·(0.5+0.5cos(k·x − s·ωt))，I_g=700pA（均值
350 = exp002 的 1× 档），ω ∈ {1,2,5,10,20} Hz，s = ±1，6s/条件（2s 适应
后测 4s）；光转导为 exp002 对称级联（**逐 R 独立滤波态**——每个 R 有
自己的光栅相位）。同一放电流同时算三种前向核；测量 = 锁相（lock-in）
在驱动频率处的复调制幅值。

## 结果（2026-09-13）

见 `outputs/summary.json`、三张图。

### 1. 板层水平无方向选择性（文献预期证实，量化）

方向选择性指数 DSI = (A₊ − A₋)/(A₊ + A₋)：

| 信号 | 全频段 \|DSI\| 范围 |
|---|---|
| R 群体放电率 | ≤ 0.018 |
| phi（t-bar 核） | ≤ 0.011 |
| phi（mean 核） | 0.008 → 0.13（随频率增大，见下） |

放电与前向场都对方向近乎完美对称——R→L 前馈回路无方向结构，符合
"方向选择性在 T4/T5 才出现"。mean 核 phi 在 20Hz 的 |DSI|≈0.13 是
表观不对称：信号缩小后锁相噪声 + LIF 阈值非线性的二阶效应（rate 层
DSI 仍 ≈0，可排除回路机制）。

### 2. 时间频率衰减 = 光转导传递函数（定量验证）

phi 调制幅值（L 眼，t-bar 核，μV）：117.9 → 115.7 → 106.5 → 83.8 → 45.3
（1→20 Hz）。相对幅值 0.98 / 0.90 / 0.71 / 0.38，与双级联解析衰减
1/(1+(2πfτ)²) = 0.97 / 0.91 / 0.72 / 0.39 **逐点吻合**——眼表面电位的
频率响应就是光转导级联的传递函数（闪烁融合曲线的发生器）。

R 群体放电率调制（Hz）：8.93 / 8.97 / 8.18 / 6.09 / 3.28——同样压缩式
衰减，叠加了 LIF 增益压缩。

### 3. 相位 → 群延迟（第三个定量验证）

phi 相位（扣除光电偶极的 π 反相与双眼空间相位差后）对频率求导给出
群延迟：18.8 ms @1.5Hz → 10.2 ms @15Hz，与级联解析群延迟
2τ/(1+(2πfτ)²)（19.9 → 10.6 ms）吻合——低频极限 = 2τ = 20ms，正是
exp002 实测的光转导延迟。

### 附注

- 每眼独立波长（各自视网膜跨度/2），双眼共用 e1 轴与 ω——方向对比在
  眼内自洽
- 适应状态：光栅常亮（余弦非负），g 稳定在 1−sag=0.7；cos 过零点
  会造成 g 的 2ω 微纹波（τ_adapt=800ms 下幅度极小，±方向对称，不影响
  DSI）

## 局限

- 视网膜拓扑是 cartridge 镶嵌的几何代理（非真实角膜入射角标定）
- 2 个空间周期/眼——空间频率调谐（另一条经典曲线）未扫，只扫了
  时间频率；扫空间频率只需改 λ，是现成的下一步
- 无髓质反馈（回路截止在 L1/L2/L3）
