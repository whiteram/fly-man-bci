# Experiment 009 — 数据驱动递质符号：板层 ON/OFF 功能架构与正 Off 瞬变

**科学问题**：连接组自带的递质符号列（每条边标注递质与 +/-）显示
exp001–008 的板层接线极性是错的：R→L1/L2/L3 是组胺能**抑制**（−1），
L1→Mi1/Tm3 是谷氨酸能**抑制**（−1），L2/L3→Tm 系是 ACh **兴奋**（+1）。
配上经典的 LMC 暗态去极化（内源性基流），双重反转应拼出教科书式
ON/OFF 通路——全部由数据符号给出，不手写任何极性。

**实现**：左叶全级联（exp005 电路）；R→L 与 L→Mi/Tm 的权重乘以数据
sign 列；L 层加暗态基流 250pA（暗态 ~14Hz）、Mi/Tm 层加基流 220pA
（被 L1 抑制时静默、去抑制时发放）。闪光 500–3500ms × 1×/2× 强度，
均匀与密封头壳双核。

## 结果（2026-09-13）

见 `outputs/summary.json`、`outputs/fig1_polarity.png`。

### 1. 功能极性全部正确（1× 闪光，放电率 Hz）

| 细胞 | 暗 | 光中 | 光灭 | 生理预期 |
|---|---|---|---|---|
| R1-R6 | 0 | 55 | 0 | ✓ |
| L1/L2/L3 | 14.4 | **6.6（超极化）** | 15.0 | ✓ 经典 LMC 光响应 |
| Mi1 | 6.8 | **16.8（去抑制）** | 9.4 | ✓ ON |
| Tm3 | 0 | **8.9** | 0 | ✓ ON |
| Tm1/Tm2/Tm4 | 65–73 | **40–46（被抑制）** | 68–79 | ✓ OFF 通道（Tm4 光灭反冲 79>暗 73） |
| T4 | 48.9 | **70.5** | 58.5 | ✓ ON 通路 |
| T5 | 132.7 | **96.3** | 135.1 | ✓ OFF 通路 |

ON 通路（R→抑制 L1→解除对 Mi1/Tm3 的抑制→T4）与 OFF 通路
（R→抑制 L2→Tm1/2/4 失驱动；光灭恢复→T5）按解剖学分工成立。

### 2. 正 Off 瞬变出现（exp003 悬置问题闭合）

眼电极（均匀核，1×）：暗基线 +1266μV（暗态突触活动直流）→ 光中
负向偏转（平台 +244μV，On 谷 −352μV）→ **光灭过冲 +1455μV（高于
暗基线 +188μV）= 正 Off 瞬变**。机制正如 exp003 预测：Off 瞬变的
发生器是**暗态活跃、光中被抑制的细胞群在光灭时的主动恢复**——需要
正确的递质符号结构，而不是非对称光转导或几何假设。

## 局限

- 工作点未精调：T5 暗态 133Hz 偏高（真实 ~5–20Hz）、Tm 暗态偏热——
  GAIN_LM/基流需要按真实放电率逐一标定（下一步）
- LMC 光灭"反弹爆发"缺失（真实 LMC 有主动反弹电流；模型只是回到
  暗态率）
- 暗基线直流（+1.3mV）幅值依赖核模型，不可当真
