# Experiment 005 — 髓质级联：T4/T5 方向选择性的结构蓝图与 u 轴检验

**科学问题**：从视网膜→板层→髓质级联（R → L1/L2/L3 → Mi/Tm → T4a-d/T5a-d）
的连接组结构里，方向选择性的解剖基础长什么样？给它配上按文献差异化的
输入动力学后，方向选择性会涌现吗？（exp004 已证明板层水平 DSI≈0；
文献中 T4/T5 是方向选择性首站）

**左叶电路**（hex1/hex2 是六角网格的两条坐标轴，**不是**左右叶标记——两叶
的 u 轴在物理空间镜像，corr(hex1,x) = −0.78 vs +0.72；侧选择用全体细胞
x 坐标统一 2-means 中线）：

| 层 | 细胞 | 边 | 突触 |
|---|---|---|---|
| R1-R6 | 2,265 | R→L: 6,351 | 共计 |
| L1/L2/L3 | 2,677 | L→Mi/Tm: 25,669 | 1,666,962 |
| Mi1/Tm3/Mi4/Mi9/Tm1/Tm2/Tm4/Tm9 | 7,195 | Mi/Tm→T4/T5: 154,038 | |
| T4a-d + T5a-d | 6,793 | | |

递质符号直接用边表 `sign` 列：Mi1/Tm3/Tm1/Tm2/Tm4/Tm9 = ACh(+)，
Mi4 = GABA(−)，Mi9 = Glu(−)（与文献一致；Tm9 数据判定为 ACh，与部分
文献说法不同，记为数据驱动发现）。

## Part A：结构蓝图（structure.py）

T4/T5 无 hex 标注，柱位由主输入伙伴多数票推断（T4←Mi1、T5←Tm9；每柱
4 个亚型细胞，与解剖一致；投票一致性中位数 0.43）。Tm3（0% hex 覆盖）
与 Tm4（50%）的柱位由其突触前主伙伴（L1/L2）投票补齐。

1. **分叶一致性**：两叶在各自局部 hex 框架内偏移结构相同（slow−fast
   差分两叶相差 ≤0.05），汇总合法
2. **1D（u 轴）**：全部亚型 slow−fast 差分为负（慢输入在上游柱），
   量级 0.0–0.4 hex 单位；T4: b/c > a > d≈0，T5: b/c > a > d
3. **2D（u,v）——关键**：偏移向量大部分**不在 u 轴上**（角度 −133°/
   −86°/+39°/+152° 等各异）；**抑制性输入偏移最大**（Mi4→T4c 达
   1.28、Mi9→T4d 达 1.63 hex 单位，均为兴奋输入的 2–5 倍）——检测器
   的"消隐侧"空间结构最强；亚型间模式不同（T4a 的 Mi4/Mi9 方向相反
   = push-pull；T4d 的 Mi1/Mi4/Mi9 同向 ~−125° 对齐）

见 `outputs/structure_offsets.json`、`outputs/fig_offsets.png`。

## Part B：u 轴光栅检验（run.py）

左叶全级联仿真（LIF + 指数突触，突触组按 Mi/Tm 前类型分动力学；符号
来自数据；增益 12/8/5 pA 每突触逐层递减）。光栅沿 Mi1 hex 回归轴
（R²=0.63）漂移，{2,5} Hz × ±方向 × 动力学两档（uniform: 全 τs=5ms；
differentiated: Mi1=25/Tm3=8/Mi4=10/Mi9=15，Tm1=20/Tm2=8/Tm4=10/Tm9=20，
按 Behnia 2014 / Arenz 2017 的快慢分工）。另放一个 T4/T5 云旁 50μm 的
髓质电极记录场电位。

**结果**（`outputs/summary.json`、fig_dsi/fig_traces）：

| 条件 | T4/T5 DSI（u 轴） | 含义 |
|---|---|---|
| uniform | \|DSI\| ≤ 0.05 | 无结构 DS（对称滤波下预期为 0）✓ |
| differentiated | \|DSI\| ≤ 0.05，无亚型排序 | **u 轴上 DS 不涌现** |

- 差异化动力学显著放大响应（T5a 调制 0.76→1.33 Hz；髓质场 293→657 μV）
  但不产生方向不对称
- 放电率健康（R 46 / L 22 / Mi/Tm 3.5–4.8 / T4/T5 5.5–7.6 Hz），非
  饱和所致
- **轴伪影诊断**：Part A 的 2D 蓝图显示偏移向量大多偏离 u 轴
  （投影后平均只剩 ~1/2–1/3 幅值），且 u 轴探测对各亚型的实际偏移
  方向不敏感——负结果的正确读法是"**排除了大 u 轴分量 DS**"，而非
  "结构不支撑 DS"

## 结论与下一步

1. **结构蓝图是本实验的主产出**：亚型特异的 2D 输入偏移 + 数据驱动的
   递质符号 + 抑制输入的最大偏移——这是后续一切 DS 仿真的解剖约束
2. u 轴 + 文献量级动力学 (Δτ≤17ms) 不足以涌现 DS（定量排除）
3. **exp006 的精确设计**（由本实验直接导出）：2D 方向扫描（六角网格
   6 个邻轴方向 × ±）× 空间波长匹配（λ ≈ 4–8 hex 单位，匹配 1–2 单位
   偏移；本轮 λ=15 单位过长）× 动力学扫描；预期 DS 沿各亚型的
   slow−fast 偏移方向涌现，幅度按 \|offset\|×Δτ 排序
