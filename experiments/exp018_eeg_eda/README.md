# Experiment 018 — 模拟头皮脑电的探索性数据分析（EDA）

**问题**（用户）：对当前基线导出的模拟脑电做 EDA——数据分布什么样、
通道之间有什么差异、**能否从中提取刺激相关的信息**？频带能量分布
与正常人脑电有什么区别？

**输入**：`viz/data/viz_data.json`（每眼整幅映射后的 demo_bounce 基线：
全 CNS、45 导、10.5 s @ 1 kHz）。干净蝇信号 `phi_scalp_all_uV`
(45×10500)、同形模拟背景 `phi_scalp_bg_uV`（α 10 Hz 30 µV + 1/f 3 µV +
传感器 1.5 µV）、五群放电率、刺激亮度曲线。弹跳球事件时刻由生成器
（确定性）精确重算，作为 ERP 锁时。

**运行**：conda ffbm 环境，`pip install scikit-learn` 后
`python experiments/exp018_eeg_eda/run.py`；图表在 `outputs/`（f01–f14），
完整数值日志 `outputs/run_log.txt`。运行约 1 分钟。

## 结果（2026-09-13，同日两次修订——见文末"修正记录"）

### 1. 幅度分布与通道差异
- **原始幅度由"紧张性 DC 偏置"主导**：每通道时间均值中位
  0.23 µV（0.34 µV 中位原始 rms 里大部分是它）；去掉 DC 后真正的
  **交流信号只有 ~0.029 µV rms**
- 通道差异主要是幅度与极性：DC 后通道 rms 相差数十倍，最强在
  CP5/CP6/CP3（左中央-顶区），与导出时独立 SNR 扫描的最佳电极一致
- 全样本分布对称重尾（f01）

### 2. 空间结构：本质上是两个模式
- PCA：PC1 65.9% / PC2 20.1% / PC3 9.9%，**参与秩 2.1**/45——45 个
  通道主要是两个主导偶极层的幅度与极性缩放（f02/f03）
- 通道对 |r|>0.5 占 50%，>0.9 占 8%，符号混合（极性翻转地形）

### 3. 频带能量分布：与正常人脑电的对比（f14，Parseval 严格周期图）

交流功率占比（0.095–500 Hz，多通道平均）：

| 频带 | 果蝇信号 | 人脑背景（文献参数） |
|---|---|---|
| <0.1 Hz | 1.7% | 5.8% |
| 0.1–0.5 Hz | 20.7% | 8.4% |
| 0.5–4 Hz（δ） | **50.8%** | 14.0% |
| 4–8 Hz（θ） | 6.1% | 5.0% |
| 8–13 Hz（α） | 4.5% | **25.1%** |
| 13–30 Hz（β） | 7.4% | 6.6% |
| 30–80 Hz（γ） | 4.8% | 8.6% |
| 80–500 Hz | 4.0% | 26.4%（白噪传感器地板） |

- **果蝇：δ 主导（0.1–4 Hz 合计 72%）**，主谱峰 0.67 Hz——是刺激
  跟踪（暗条 0.27 Hz 扫掠 + 球轨迹 ~1 Hz）与级联时间常数造出的
  连续谱，**没有任何振荡器峰**
- **人脑：α 主导**（8–13 Hz 占 25%，闭眼枕区优势，峰值突出度
  ~5×；来自丘脑-皮层回路），外加 1/f 无周期分量（斜率 −0.92）
- 两者 2–40 Hz 的谱斜率其实接近（蝇 −1.02 vs 人 −0.92），**真正的
  区别是有无 α 峰 + 绝对幅度（AC rms 0.029 µV vs 3.8 µV，~130×）**
- 直流成分：蝇 0.34 µV（紧张性放电的真实场），人脑背景无——但实际
  头皮记录 DC 受电极漂移污染不可用，实用信号就是那份 0.03 µV 的 AC

### 4. 级联滞后
- stim→R 峰值 |r|=0.89 @ **23 ms**；R→L 0.98 @ **17 ms**；L→MID 0.18；
  更深层与平均亮度几乎不相关（T4/T5 是运动检测器，对亮度的时间导数
  而非亮度本身响应——符合预期）
- stim→EEG 单通道 |r| 中位 0.52、最大 0.89（A2），最佳滞后中位
  **29 ms**（f05）

### 5. 弹跳事件 ERP：不显著（诚实零结果）
- 19 次弹跳；最佳通道 CP5 的 grand-mean ERP 峰峰 0.047 µV；循环平移
  零检验 z=0.3，p=0.33
- 原因：弹跳对平均亮度的扰动太小；该刺激的信息形式是**连续跟踪**，
  不是事件锁定瞬变（强事件如全屏闪光，exp011 已证明可测）

### 6. 解码（岭回归，8 PC × 150 ms 抽头，TimeSeriesSplit 6 折）

| 条件 | CV R² |
|---|---|
| 干净（宽带）→ 刺激亮度 | 0.868 ± 0.016 |
| 干净 0.5–6 Hz（特征与目标均带通，**掐头去尾 2.5 s**） | 0.839 ± 0.148 |
| 干净 → R 群放电率 | 0.722 |
| 加背景 → 刺激 | −1.9（失败） |
| 零假设（刺激循环平移 3.5 s） | −1.8（≈加背景水平） |

双方带通并**剔除滤波边缘瞬态后** R² 仍 0.84——刺激信息是频段内
真实的时变结构，不是慢趋势或边缘伪影（早期未去边缘的 0.90 略有
虚高，已修正）。

### 7. 背景强度 × 频段扫描：前提问题（§8–§9，周期图法严格计算）

**前提**：本项目的思想实验是**替代**——果蝇网络放进人脑壳、替代其中
的神经网络；不存在"仍在的人脑皮层"。**项目默认前提 = k=0**：背景只剩
设备白噪 1.5 µV（宽带指标；**带内才是公平比较**：0.1–1 Hz 内白噪
只有 0.064 µV rms）。果蝇网络自身的自发活动已在"干净"信号里（内噪声）。
k=1（α 30 µV + 1/f 3 µV + 传感器）是"与完好人脑共存"的反事实上界。

单段 10.5 s、干净信号主成分空间滤波（模型知情）下的带内 SNR 与
达到 SNR=2 所需的同刺激段平均数：

| 前提 k | 频段 | 通道级带内信噪比 | PC 投影后 SNR | SNR→2 所需段数 |
|---|---|---|---|---|
| **k=0（项目默认：仅设备噪声）** | 0.1–1 Hz | 0.72 | **1.17** | **~3** |
| k=0 | 0.5–6 Hz | 0.39 | 0.66 | ~10 |
| k=0.03 | 0.1–1 Hz | 1.14 | 1.88 | ~2 |
| k=0.1 | 0.1–1 Hz | 0.34 | 0.56 | ~13 |
| k=0.3 | 0.1–1 Hz | 0.11 | 0.19 | ~114 |
| k=1（反事实上界） | 0.1–1 Hz | 0.03 | 0.06 | ~1250 |
| k=1 | 0.5–6 Hz | 0.04 | 0.07 | ~940 |

- **项目前提（替代）下的结论**：0.1–1 Hz + 主成分空间滤波后单段
  SNR≈1.2，**约 3 段（半分钟）同刺激平均即可到 SNR 2**——不需要
  "缩小背景"，本来就没有神经背景；k=0.1（≈人类 VEP 实验信噪比例）
  需 ~10–13 段，与人类 ERP 实验几十次试次平均的实践量级自洽
- 单段 10.5 s 的单试次解码在所有 k×频段格都失败（时间序列 CV 前几折
  只有 ~2 s 训练数据 + 信号强自相关）——是数据量问题，不是信息不在
- 与 exp011 自洽：k=1 反事实需 ~1000 段，exp011 单通道无空间滤波
  估 ~6800 试次——空间滤波增益 ~5×，量级一致

### 8. 对未来"脑电采集"的实践含义（§8.1）

- **有用频段在低位**：AC 能量 72% 在 0.1–4 Hz——常规临床 0.5 Hz
  高通会切掉相当能量，采集需 DC/低频能力（截止 ≤0.1 Hz）+ 电极
  漂移控制；紧张性 DC 分量虽大（0.34 µV）但实际记录不可用
- **带通滤波的边缘瞬态是真实陷阱**：0.1 Hz 高通极点在 10.5 s 记录
  两端振铃数秒，会把带内 rms 虚增 3–5×（本实验实测）——短数据
  频谱一律用周期图法或对滤波结果掐头去尾
- 三件必用的武器：**低频段保留**、**多导空间滤波**（秩≈2，对白噪
  √N 导增益）、**分段平均**（√k 增益）

## 结论

1. **干净信号里刺激信息强且可解码**（带通去边后 CV R²≈0.84）；滞后
   结构符合生物学（光转导 23 ms、stim→EEG 29 ms）；空间秩≈2、
   CP5 为中心
2. **替代前提下（项目默认）可提取性好**：0.1–1 Hz + 主成分空间滤波
   单段 SNR≈1.2，~3 段平均到 SNR 2；限制全在工程侧（低频采集、
   漂移控制、平均）
3. **频带分布与人脑本质不同**：蝇=δ 主导连续谱（刺激跟踪，无振荡
   峰），人=α 主导+1/f；AC 幅度差 ~130×；实操中把 0.1–4 Hz 保住、
   去掉不可用的 DC、空间滤波+平均
4. 通道差异是地形（幅度×极性），不是独立信息源

## 诚实的注意事项

- 单条 10.5 s 片段、单一刺激；ERP 零结果只针对"弹跳"这类弱事件
- PCA 空间滤波取自同一干净信号（模型知情；真实场景可从无刺激基线
  估空间模式）
- "所需段数"是 SNR→2 的 √k 换算，未计入重复刺激的神经适应
- 传感器噪声 1.5 µV 是宽带上限假设；优质 DC 放大器可更低（更有利）
- 背景为仿真，绝对 µV 继承模型未标定增益
