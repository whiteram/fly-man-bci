# Experiment 018 — 模拟头皮脑电的探索性数据分析（EDA）

**问题**（用户）：对当前基线导出的模拟脑电做 EDA——数据分布什么样、
通道之间有什么差异、**能否从中提取刺激相关的信息**？

**输入**：`viz/data/viz_data.json`（每眼整幅映射后的 demo_bounce 基线：
全 CNS、45 导、10.5 s @ 1 kHz）。干净蝇信号 `phi_scalp_all_uV`
(45×10500)、同形模拟背景 `phi_scalp_bg_uV`（α 10 Hz 30 µV + 1/f 3 µV +
传感器 1.5 µV）、五群放电率、刺激亮度曲线。弹跳球事件时刻由生成器
（确定性）精确重算，作为 ERP 锁时。

**运行**：conda ffbm 环境，`pip install scikit-learn` 后
`python experiments/exp018_eeg_eda/run.py`；图表在 `outputs/`（f01–f08），
完整数值日志 `outputs/run_log.txt`。运行约 1 分钟。

## 结果（2026-09-13）

### 1. 幅度分布与通道差异
- 通道 RMS 0.023–1.04 µV（**50 倍动态范围**），中位 0.34 µV；背景
  RMS 中位 3.35 µV（≈10×）
- 最强 CP5(1.04)/CP6(0.80)/CP3(0.80)/P7(0.68)/C3(0.66)——左侧中央-
  顶区；最弱 FCz(0.023)/F7(0.038)。与导出时独立 SNR 扫描的最佳电极
  （CP5）一致
- 全样本分布对称重尾（f01）

### 2. 空间结构：本质上是两个模式
- PCA：PC1 65.9% / PC2 20.1% / PC3 9.9%，**参与秩 2.1**/45——45 个
  通道主要是两个主导偶极层的幅度与极性缩放（f02/f03）
- 通道对 |r|>0.5 占 50%，>0.9 占 8%，符号混合（极性翻转地形）

### 3. 频谱
- 蝇信号能量集中于 **<4 Hz**（比其他频段高 50–100 倍）；背景峰值在
  α（8–13 Hz，7.2 µV²）——频域可分性是可利用的轴（f04）

### 4. 级联滞后
- stim→R 峰值 |r|=0.89 @ **23 ms**；R→L 0.98 @ **17 ms**；L→MID 0.18；
  更深层与平均亮度几乎不相关（T4/T5 是运动检测器，对亮度的时间导数
  而非亮度本身响应——符合预期）
- stim→EEG 单通道 |r| 中位 0.52、最大 0.89（A2），最佳滞后中位
  **29 ms**（f05）

### 5. 弹跳事件 ERP：不显著（诚实零结果）
- 19 次弹跳；最佳通道 CP5 的 grand-mean ERP 峰峰 0.047 µV；循环平移
  零检验 z=0.3，p=0.33
- 加背景后单事件 SNR 0.013，19 次平均也只到 0.05σ
- 原因：弹跳对平均亮度的扰动太小；该刺激的信息形式是**连续跟踪**，
  不是事件锁定瞬变（强事件如全屏闪光，exp011 已证明可测）

### 6. 解码（岭回归，8 PC × 150 ms 抽头，TimeSeriesSplit 6 折）

| 条件 | CV R² |
|---|---|
| 干净 → 刺激亮度 | 0.868 ± 0.016 |
| **干净 0.5–6 Hz（特征与目标均带通）→ 刺激** | **0.901 ± 0.090** |
| 干净 → R 群放电率 | 0.722 |
| 加背景 → 刺激 | −1.9（失败） |
| 加背景 0.5–6 Hz | −1.96（失败） |
| 零假设（刺激循环平移 3.5 s） | −1.8（≈加背景水平） |

关键稳健性检验：双方带通后 R² 不降反升（0.87→0.90）——刺激信息是
频段内真实的时变结构，**不是** 10.5 s 片段 <0.1 Hz 慢趋势共变的伪影
（短片段宽带相关必须做这个控制）。

### 7. 真实噪声下的最优单试次提取：本片段内不可行
- 频段（0.1–6 / 0.5–6 / 1–6 / 0.5–4 Hz）× 空间滤波（干净信号
  PC1–4 投影 / 最佳单通道）扫描：混合信号与刺激的最佳 |r| 全部 ≈
  背景对照（f08），循环平移置换 p 全部 >0.2
- 低频是双刃剑：蝇能量在低频，背景 1/f 也在低频

## 结论

1. **干净信号里刺激信息强且可解码**（带通后 CV R²≈0.90）；滞后结构
   符合生物学（光转导 ~23 ms，stim→EEG ~29 ms）；空间集中在 CP5
   为中心的两个模式上
2. **加真实背景（≈10×）后单试次不可提取**——与 exp011 的检测理论
   自洽（导出内置 SNR 分析：d′=2 需 ~6.8k 试次）。信息存在但被埋没，
   恢复路径是试次平均 / 更长数据 / 空间匹配滤波
3. **通道差异主要是幅度（50×）与极性，不是独立信息源**（参与秩≈2）
   ——多导联的价值在空间滤波与地形定位，不在独立通道数

## 诚实的注意事项

- 单条 10.5 s 片段、单一刺激；ERP 零结果只针对"弹跳"这类弱事件
- 解码用的 PCA 空间滤波取自同一信号（无标签泄漏，但属"模型知情"；
  真实场景可从无刺激基线段估计空间模式）
- 背景为仿真（α+1/f+传感器噪声），非真实人体记录；绝对 µV 值继承
  模型未标定增益
