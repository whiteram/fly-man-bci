# Experiment 006 — 2D 方向扫描：方向选择性从结构中涌现

**科学问题**：exp005 排除了 u 轴 DS（波长失配 + 偏移大多离轴）。波长
匹配（λ=6 hex 单位 ≈ 22 μm，exp005 是 ~15 单位）+ 六方向扫描后，
T4/T5 的方向选择性会涌现吗？涌现方向与结构蓝图的 HR 线性化预测一致吗？

**设计**：电路/增益/动力学完全同 exp005 差异化档（左叶 1.9 万神经元/
167 万突触）；光栅沿六角网格 6 轴（0°–300°，间隔 60°，u/v 轴由
Mi1 的 hex1/hex2 双回归定义，R²=0.63/0.73）× ± 漂移，f=5Hz，
12 次仿真。每亚型测 **DS 向量** = Σ_axis DSI(axis)·e_axis，与结构预测

    P = Σ_t w_t · sign_t · (τ_t − τ̄) · offset_t

（每亚型突触份额 × 数据递质符号 × 动力学延迟差 × 2D 偏移向量，
全部来自 exp005 蓝图）对比。

## 结果（2026-09-13）

见 `outputs/summary.json`、`outputs/fig_ds_polar.png`、
`outputs/fig_pred_vs_meas.png`。

### 1. 方向选择性涌现，方向与结构预测定量一致

| 亚型 | 实测方向 | 预测方向 | 偏差 | 实测强度 |
|---|---|---|---|---|
| T4b | −135.1° | −135.5° | **0.4°** | **0.344（最强）** |
| T4c | −135.5° | −135.2° | **0.3°** | 0.280 |
| T4a | −133.5° | −134.2° | **0.7°** | 0.109 |
| T5c | −133.8° | +45.0° | 179°（失败） | 0.323 |
| T5d | −139.3° | −134.9° | **4.4°** | 0.118 |
| T5a | −136.3° | −171.7° | 35.4° | 0.232 |
| T5b | −147.4° | −130.9° | 16.5° | 0.037（弱） |
| T4d | 50.4° | −134.1° | — | 0.026（噪声级） |

- 4/8 亚型预测偏差 ≤5°，5/8 ≤36°；最强响应的 T4b/c 精确命中
- 全部实测方向聚集在 **−135° 附近**——正是蓝图里主导偏移向量的方向
  （Mi1@−133°、Tm9@−130° 等），结构→功能链条闭合
- **T5c 是诚实的预测失败**：其 Tm9/Tm1/Tm2 偏移大且多向（−152°/+171°/
  −130°），线性叠加失灵——提示真实检测器是非线性整合（顺方向：
  含阈值的非线性 HR 模型）
- **髓质场电位本身方向选择性**（DS 向量幅值 0.166）——这是本项目第一个
  "功能性脑场信号"：方向信息不只在放电率里，也写在细胞外场里

### 2. 波长匹配是被 exp005 卡住的原因

u 轴 DSI 从 exp005 的 ~0.00 升到本轮的 −0.086（0°/180° 轴）——偏移
量级 ~1 hex 单位需要 λ≈6 单位才能让空间相位差匹配动力学延迟差
（ω·Δτ ≈ k·δ）。exp005 的负结果定性正确（排除该波长下的 u 轴 DS），
定量由本轮翻转。

### 3. 注意事项

- 调制幅值有强轴各向异性（120° 轴 ~1.0 Hz vs 0°/60° ~0.2–0.3 Hz）——
  λ=22μm 时 R 末梢云沿不同轴向的光栅采样密度不同，DSI 幅值受采样
  各向异性影响；**方向结论不受影响**（DSI 是轴内归一化的）
- u/v 轴由回归定义、非严格正交，角度报告在同一定义下自洽（实测与
  预测用同一 angle_of，对比有效）
- 增益/动力学未标定，强度数值只有相对意义

## 结论

**连接组结构（2D 偏移 + 递质符号）+ 文献量级的输入动力学分化 →
T4/T5 方向选择性自发涌现，且偏好方向可用蓝图线性预测（4/8 亚型
偏差 ≤5°）。** 这是 flyvis 用任务训练才得到的性质，此处由纯前向
物理管线给出。项目主线"结构→放电→细胞外场"至此在功能层面闭环：
方向选择性同时出现在放电率与髓质场电位中。
