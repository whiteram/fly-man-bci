# exp015 — 双侧视叶接入（bilateral lobes）

**问题**：主管线只模拟左视叶。接入双叶（保持原生几何、每叶独立接线）
需要什么代价？头皮信号会变大多少？

## 结论（详见 outputs/exp015_summary.json）

1. **×400 装不下（本次最重要发现）**：双叶原生跨度 692 μm
   （两叶呈 ~90° V 形），×400 = 277 mm，超过人脑球直径 156 mm
   ——垂直方向就有 117 mm > 76.4 mm 安全边界，任何平移都救不了。
   "×400 放进人脑"的前提只对单叶（~180 μm ×400 ≈ 72 mm）成立。
   处理：`vizprep.fit_scale_shift` 自适应尺度 = 最大可行值，
   细长网络钉极（单叶 ×400，枕极锚定），宽体网络居中
   （双叶 ×202，两眼轴沿头球直径）。原生相对几何不动。

2. **工作点零成本迁移**：每细胞接线镜像对称（受支配 L1/2 突触质量
   中位数左 148 / 右 153；跨叶边实测 0 条），round-5 参数原样可用：
   受支配 L1/2 暗电位左 −35.1 / 右 −35.3 mV（窗口 −38.4±3.2 的边界，
   与单叶主线一致），光深 20.6 mV ✓，MID 16.7 / T4 6.9 Hz ✓，
   flash T4 7.0 Hz ✓。唯一不过窗的是 T5 暗率 1.1 Hz（窗口 2–15；
   round-5 即如此，非双叶引入）。注意右眼 R1-6 追踪不完整
   （1,112 vs 左 2,265），但受支配亚群质量对称，不影响上述结论。

3. **信号不升反降（对"双叶增益 ×2"预期的修正）**：同种子、同闪光
   协议、各自最优放置下，双叶 ×202 最佳电极 0.035 μV = 单叶 ×400
   （0.051 μV）的 **0.69 倍**。偶极矩 ∝ 尺度，倍增的源恰好被尺度
   收缩抵消还有余（居中放置也比贴极深）。拓扑也变了：单叶信号在
   眼轴（0°）与 147° 枕区电极，双叶信号转移到 90° 侧向电极
   （V 形双臂向两侧展开）——旋转近对称从"绕眼轴"变成"绕长轴"。
