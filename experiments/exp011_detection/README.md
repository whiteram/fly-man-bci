# Experiment 011 — 单份放大网络的检测极限：脑电采集能否成立？

**问题**（用户思想实验）：不复制多份，只用**一份放大 400 倍**的果蝇
视觉网络放进人脑壳。信号弱，但假设背景噪声相对降低、采集精度提高
——脑电采集能否成立？

**关键区分**：exp010 报的 0.24μV 是窗口内**波动**幅度（RMS）；本实验
测的是闪光对信号**均值**的调制（DC 偏移 + 时间锁定瞬变）——这才是
检测统计量。方法：17s 闪光串（12 个 600ms 暗/600ms 亮循环），S=400
头皮电极信号；叠加三档白噪声（1μV 临床 / 0.3μV 研究级 / 0.1μV 优质）；
按 epoch 平均 + 窗口统计做检测（d' 准则，d'=2 为检测阈值）。

## 结果（2026-09-13）

| 噪声水平 | 单次试验 d' | 12 次平均 d' | d'=2 所需试验数 |
|---|---|---|---|
| 1.0 μV（临床 EEG） | **28.3** | 98.2 | **1** |
| 0.3 μV | 70.3 | 243 | 1 |
| 0.1 μV | 95.0 | 329 | 1 |

- 闪光调制 **−2.96μV**（暗态活动被光抑制，均值级），epoch 自噪声
  （窗口均值涨落）仅 **0.021μV**——窗口平均把慢变信号的噪声压掉两个
  数量级
- **结论：成立**。即使在临床级噪声下单次试验就远超检测阈（d'≈28）；
  保守考虑真实噪声（1/f 漂移、肌电、工频——非白），几十次试验平均
  （人类 ERP 的标准操作）也绰绰有余
- **物理硬地板**：1kΩ 电极接口 50Hz 带宽的约翰逊热噪声 ≈ 0.03μV，
  低于信号一个数量级——没有物理障碍，剩下是工程问题

## 与"果蝇头壳外采集"的本质区别

绝缘壳外的场是**严格为零**（物理禁止，任何工程无解）；单份放大网络
在人脑壳内是**弱但确定非零**——可测性由信噪比决定，可由带宽控制、
低阻抗接口、试验平均（√k 增益）三项标准手段解决。

## 诚实的注意事项

- 白噪声假设是乐观界：真实 EEG 噪声含慢漂移（损害 DC 测量）——但闪光
  反应的时间锁定瞬变分量（On/Off）不受漂移影响，AC 耦合 + 平均可测
- 绝对 μV 值继承模型未标定增益（±10–100×）；检测**逻辑**（信号 ≫
  自噪声与热噪声地板）对标度不敏感
