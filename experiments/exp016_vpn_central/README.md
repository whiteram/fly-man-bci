# exp016 — 视觉下游 VPN→中央脑通路（exp014 计划的阶段 1+2）

**问题**：视觉信息从视叶经 VPN（视觉投射神经元：LC/LPLC 等大切向
类）进入中央脑（PVLP/AOTU 等）。把这条下游通路接进 ×倍人脑思想实验，
对头皮 EEG 有多大影响？

## 阶段 1 盘点（`inventory.py` → `outputs/inventory.json`）

- 电路 → VPN 突触：**176 万**（Mi/Tm 58 万 + T4/T5 118 万）——与
  级联内部（298 万）同量级，视觉流的主要出口。
- VPN→中央脑（w≥5）：18.9 万对 / 317 万突触。
- 主力 VPN 类（按 CB 突触量）：LC17（353 细胞/33 万突触）、LC12
  （498/33 万）、LC10a（275/18 万）、LC10d、LC11、LC18、LPLC2、
  LLPC1、LC9、LC16——全部胆碱能、跨度 326–561 μm 的大切向细胞。
- 顶级中央脑目标：PVLP097/007/011/061、AOTU041/008 等——大扇入
  细胞（如 PVLP011 仅 2 个细胞收 7.3 万突触）。

## 阶段 2 电路与判决（`circuit2.py` + `experiment.py` → `outputs/exp016_summary.json`）

电路 = exp015 双叶级联 + 前 10 VPN 类（2,557 细胞）+ 按接收量取
前 250 个中央脑目标（PVLP097×14、PVLP007×11…AOTU008×8）；
MID,T45→VPN 22,402 对 / 18.1 万突触（数据集符号），VPN→CB
46,415 对 / 118 万突触（ACh）。VPN/CB 位置用胞体（与突触位点同
坐标系，site–soma 实测 16–90 μm；bodyId 重映射到紧凑空间避免
GB 级索引表）。工作点：I_V=120 / I_C=60 pA（暗率 VPN 1.6 /
CB 1.1 Hz，3×3 网格）。

**判决：影响可忽略**。同尺度（×202）、同种子、同闪光协议下，
加 VPN+CB 后三电极闪光信号比 = **0.91 / 1.05 / 1.01**——
与 exp014 的 VS 判决一致：视觉下游（更深、更靠中央、活动弱且
不锁相）对头皮信号没有可测贡献。突触电流主要产生在浅层大群体
（光转导偶极 + 板层 + 髓质），切向单细胞再大也补不回数量级。

## 与主管线的关系

未接入主线导出（判决支持不加）。管线保留了可选层机制：电路
dict 带 `vpn_ids`/`cb_ids` 键时 `ffbm.pipeline` 自动构建
VPN/CB（参数注册表 `vpn_central` 小节），供后续扩展复用。
