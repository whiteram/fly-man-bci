# Experiment 010（思想实验，实算）— 把果蝇视觉网络放进人脑壳，按人脑方式采头皮 EEG

**问题**：把果蝇视觉级联放大到人脑尺度、放进标准人脑三球头模型
（脑 80mm σ=0.33 / 颅骨 85mm σ=0.013 / 头皮 92mm，电极贴头皮），
按人脑方式采集，会测到什么？

**方法**：`ffbm.forward.ScalpPairField`（人脑 EEG 经典三球模型的勒让德
级数实现，电极在头皮层；远极限对均匀核收敛 8×10⁻⁷；两个边界条件符号
bug 由解析单对检验抓出）。一次闪光仿真（exp009 数据符号工作点），
同一套突触电流并行求值两种几何：S=1（网络原尺寸 200μm 置于脑心）与
S=400（全部源汇坐标 ×400，铺满 72mm 脑半径）；电流不变。同时直接
计算网络净偶极矩 P(t)=Σ y·d（人脑 EEG 源分析的通用量）。

## 结果（2026-09-13）

见 `outputs/summary.json`、`outputs/fig1_human_scale.png`。

| 情形 | 头皮信号（RMS） | 与人类 EEG 对比 |
|---|---|---|
| S=1（原尺寸果蝇在人脑里） | **0.6–3 nV** | 低于噪声底（~1.5μV）**1000 倍，完全不可见** |
| S=400（纯几何放大 400×） | 暗 0.95μV / 光中 0.24μV | 暗态活动**恰在检测极限边缘**；闪光响应略低于底 |
| S=400 × 10³ 独立拷贝 | **7.7μV** | **与人类视觉诱发电位同量级（1–20μV）** |
| S=400 × 10⁶ 独立拷贝（人脑细胞数） | 243μV | 超过人类 α 节律（~50μV） |
| S=400 × 10⁶ 完全同步（不物理） | 0.24 V | 荒谬——全同步从不发生 |

1. **纯几何放大不够**：单份放大网络的光反应仍低于 EEG 噪声底。人脑
   EEG 可测的真正来源是"大数量神经元的部分同步"：~10³ 份独立拷贝
   （√N 相干叠加 ≈ 10⁸ 神经元）才到人类视觉诱发电位的量级——与文献
   "一个 EEG 等效源需要 10⁶–10⁸ 同步神经元"自洽
2. **净偶极矩交叉验证**：果蝇网络 0.05–0.19 nA·m vs 人类 EEG 等效源
   10–100 nA·m——差 100–1000 倍，正是拷贝数差距 ✓
3. **意外平行（涌现）**：闪光响应对头皮信号是**负向调制**（暗态活动
   0.95μV 被光抑制到 0.24μV）——因为 exp009 的符号结构下板层网络
   暗态活跃、光中受抑制。这与人类 EEG 的"α 阻断/事件相关去同步"
   （ERD）现象形态相同：刺激不是增加信号，而是压制背景节律

## 诚实的注意事项

- 绝对幅值继承模型的未标定增益（exp002 回流位置问题，可能差 10–100×）
- 放大假设果蝇网络的取向相干性保持不变——对人脑有利的一面是皮层
  柱状排列（开放场）恰好是果蝇神经毡缺乏的，本估计偏乐观
- 人脑三球参数为文献标准值；深源下颅骨衰减 ~0.89（浅源才是经典 0.3–0.5）

## 结论

**"果蝇式网络 + 人脑式采集"需要约一千份独立的果蝇视觉系统才有人类
EEG 的读数**；单份放大 400 倍只在最强同步情形勉强擦到检测极限。人脑
EEG 的可测性来自尺寸 × 单元电流 × 排列整齐 × 部分同步的乘积，其中
果蝇网络只贡献了前一项的一半。
