# exp012：回流电流位置假设的 ERG 约束

## 问题

本项目所有细胞外电位的**绝对幅值**都依赖一个未定假设：每个突触的回流
电流从哪里出来。三种候选几何（exp002 建立的）：

| 变体 | 源位置 | 汇位置 | 偶极长度 |
|---|---|---|---|
| A `tbar` | 突触前 t-bar | 匹配的 PSD | ~0.2 μm |
| B `neurite` | L 细胞远端 PreSyn 云（髓质侧） | PSD | ~10–30 μm |
| C `meanpos` | R 位点质心 | L 位点质心 |（viz/exp005+ 管线所用）|

exp002 量化了核范数差异（A ≈ 0.004×C，B ≈ 1.7×C——400 倍杠杆），但那是
在 exp009 之前的兴奋性接线 + 无 LMC 基流的动力学下跑的。

## 方法

在**当前**模型下（组胺抑制性 R→L、LMC 暗去极化基流 250pA、校准增益
GAIN_RL=12）重跑 3s 闪光 ERG（双眼角膜电极），三个变体共享同一放电
序列（同随机种子），只有前向核不同。每个变体算四个指标并对照经典
果蝇 ERG 锚点：

1. `on_transient_over_plateau` ∈ [1, 3] —— 负 on-瞬变与维持平台同量级或更大
2. `off_over_on_transient` ∈ [0.3, 1] —— off-瞬变正偏转约为 on 的 0.3–1 倍
3. `lmc_fraction_of_on_transient` ∈ [0.5, 1] —— on-瞬变主要由 LMC 电流驱动
   （细胞内记录的经典归因）
4. `lmc_fraction_of_plateau` ∈ [0.0, 0.5] —— 平台含大比例感受器电流分量

锚点是经典细胞内/角膜 ERG 记录的近似范围，目的是约束而非精确拟合；
真实约束力来自四个指标要**同时**满足。

## 判读

- 若只有一个变体通过全部锚点 → 它成为管线的默认回流假设，绝对幅值
  标定到该几何；
- 若多个通过 → 幅值给出区间，判别留给后续（如强度系列、L1/L2/L3
  分离记录）；
- 若全部失败 → 说明三几何族外还需要新变体（如分布式膜回流）。

运行：`python experiments/exp012_return_constraint/run.py`（~8 min，
复用 exp002 的 t-bar↔PSD 配对与站点缓存）。

## 结果（2026-09-13，outputs/summary.json）

**结论：现有三几何族不能被这组锚点判别——锚点 2（off 瞬变）在当前
动力学下对所有变体都失败，失败原因是动力学缺失而非几何错误。**

| 变体 | on/平台 | off/on | LMC@on | LMC@平台 | 通过 |
|---|---|---|---|---|---|
| tbar | 1.32 ✓ | 0.0 ✗ | 0.44 ✗ | 0.58 ✗ | 1/4 |
| neurite | 0.17 ✗ | 6.2 ✗ | 11.8 ✗ | 1.8 ✗ | 0/4 |
| meanpos | 1.53 ✓ | 0.0 ✗ | 0.25 ✗ | 0.32 ✓ | 2/4 |

三点判读：

1. **off/on = 0 不是几何问题**：R/L 级联里 off 响应只是 on 响应的指数
   衰减（R 黑暗期 0 放电 → y 衰减），正相 off 瞬变需要 L2 反弹动力学
   （exp003 的非对称 Off），本实验的电路没有包含。锚点 2 在补上该
   动力学之前不具判别力。
2. **neurite 变体行为病理**：其 L 偶极与光感受器偶极在角膜电极处
   部分抵消（LMC@on 分数 11.8>1 说明分母被抵消缩小），波形特征与
   锚点全面不符——它是最可疑的几何。
3. **绝对幅值杠杆仍开放**：on 瞬变幅度 tbar 474 μV、meanpos 1285 μV、
   neurite 118 μV（~10 倍范围）——头皮脑电的绝对幅值要等判别闭合
   后才能标定。相对量（时间过程、拓扑、相位）不受此影响。

下一步（如需闭合判别）：给 R/L 级联加 exp003 非对称 Off 动力学后
重跑本实验；或改用强度系列锚点（V-log(I) 斜率对几何不敏感、对
动力学敏感，可与波形锚点正交互补）。
