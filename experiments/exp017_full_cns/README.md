# exp017 — 全 CNS 接入（扩脑区终点站）

**问题**：把其余视叶、中央脑、腹索全部接入思想实验电路，形成
"整只果蝇中枢神经系统" 的仿真（凡有位置且可分类的细胞）。

## 电路（`circuit3.py` → `outputs/circuit3_report.json`）

在 exp015 双视叶级联 + exp016 VPN 层之上新增三个可开关区域：

| 区域 | 细胞数 | 内容 |
|---|---|---|
| `ol_rest` | 62,305 | 视叶其余细胞（级联五层之外的 VIS 超类，含 VPN 全集） |
| `central_brain` | 33,480 | cb_*（蘑菇体/中央复合体/侧角/触角叶…）+ 下行神经元 |
| `vnc` | 15,367 | 腹索 + 上行类（**参与仿真、不进头壳前向核**） |

边组（w≥5，符号取 consensus 神经递质：ACh→+1、GABA/Glu→−1、
调质/未知→+1 文档化为假设；每组突触前 ID 单一空间，区域 ID
紧凑重映射不冲突）：

| 组 | 对数 | 突触 | 说明 |
|---|---|---|---|
| OLR_V 核心→其余视叶 | 774,192 | 9,547,642 | 前向 |
| CEN_V 核心→中央脑 | 152 | 1,210 | 几乎为零——视觉信息全部经 VPN |
| CEN_R 其余视叶→中央脑 | 208,073 | 3,513,865 | 前向 |
| CEN_C 中央脑复发 | 1,715,321 | 29,007,814 | 前向；最大块 |
| VNC_C 中央→腹索 | 116,099 | 2,106,815 | 仿真 only |
| VNC_R 腹索复发 | 720,558 | 13,563,722 | 仿真 only |
| ASC_R 腹索→上传 | 105,157 | 2,168,302 | 仿真 only |

合计 364 万对 / 5,991 万突触，加级联内部 298 万 ≈ **6,300 万突触**
的整只 CNS 仿真（~16 万细胞）。

## 工作点与判决（`run.py` → `outputs/exp017_summary.json`）

坐标下降网格（G_UNIT_CX=2 mNS 一档即稳定）选定：
**I_OLR=150 / I_CEN=150 / I_VNC=120 pA**，6 s 暗态稳定性通过：
OLR 1.9 / CEN 11.5 / VNC 3.4 Hz（窗口 1–10 的边缘），且核心视叶级联
暗率完全不受下游接入影响（MID 16.6 / T4 6.9 / T5 1.1 Hz——与
exp016 双叶基准逐位一致，下游不反哺上游的预期成立）。
**判决（相对 exp016 双叶基准，同种子同机械，×203 同尺度）**：
三电极闪光信号比 **2.03 / 1.08 / 0.88**——0° 电极翻倍，但闪光期
OLR/CEN 速率几乎不变（1.9→1.7 / 11.4→11.4 Hz），即增量是**不与
刺激锁相的自发突触活动方差**（方向依赖），不是视觉信号增强。
核心结论不变；"背景更真实"的价值被定量到 ±2× 方差层面。
端到端 61 分钟（其中前向核 47 分钟；导出用分层抽样核规避）。

## 与主管线的关系

`--regions visual_bilateral,vpn_central,ol_rest,central_brain,vnc`
即可让导出/仿真运行全 CNS；VNC 自动排除在头皮核与可视化点云外
（×N 下位于头球之外）。默认配置仍是双视叶（性能与既有结论）。
