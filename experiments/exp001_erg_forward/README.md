# Experiment 001 — ERG forward model

**科学问题**：光感受器（R1-R6）+ 板层神经元（L1/L2/L3）的群体放电活动，能否在
眼表面前向生成 ERG（视网膜电图）样电位波形？

这是「群体活动 → 细胞外场电位前向建模」的第一步 demo：只取视网膜→板层这第一级
突触（约 20 万条连接、约 8000 个神经元），验证整条建模管线的物理合理性。

## 管线

```
MaleCNS v1.0 连接组 (R1-R6 -> L1/L2/L3 边 + 突触位点坐标)
        │
闪光刺激 (500-1500 ms) ──> 光电流 ──> R 群体 LIF 放电
        │                                │ 指数突触
        │                                v
        └──> 光电流偶极（远端感受器部位为汇）   L 群体 LIF 放电
                                         │
                    点源-汇对前向核（准静态，σ=0.33 S/m）
                                         v
                    眼表面虚拟电极电位 φ(t)  ← 对比经典 ERG 波形
```

回路规模（从连接组实测）：约 3,377 个光感受器，每个发出约 6 条真实边（四联体
结构，巨型多突触 bouton，平均 ~24 个突触/边），共 9,636 条 R→板层边、
约 23 万个突触。光感受器位置用其突触末梢（t-bar）坐标，板层神经元用其
突触后位点（PSD）坐标（`somaLocation` 在视网膜区域覆盖极差，见下）。

## 与真实 ERG 的对应（定性预期）

经典果蝇 ERG 在闪光下呈：On 瞬变（负）、持续负平台（光感受器感受器电位，
角膜侧为负）、Off 瞬变（正）。本模型中：

- 持续成分 ← 光电流偶极（汇在远端感受器部位、源在胞体，方向朝眼表面）
- On/Off 瞬变 ← R 突发放电驱动 L 群体突触电流（源在 R、汇在 L，径向排列）

## 简化与局限（诚实清单）

- 突触电流位置用每位点突触坐标的均值（逐突触动力学是下一步升级）
- 光感受器胞体/感光部位位置不在连接组里（无突触标注），用末梢坐标 + 视轴
  方向外推 ~20 μm 近似
- 均匀无限电导介质（无头壳分层、无非均匀 σ）
- LIF 点神经元、光转导用矩形光电流近似（真实光转导有 ~20 ms 动力学）
- 电极位置由神经元云几何外推（非真实头壳曲面）
- 幅值数量级有意义，绝对值不可当真

## 数据备忘：为什么不用 somaLocation

`somaLocation`（胞体坐标）在注释表中对视网膜区域覆盖极差：R1-R6 仅 13/3,377
有胞体坐标，板层 L1/L2/L3 仅 797/5,327。因此本实验改用 syn-points
（12.7 GB，全部 ~1.25 亿突触的坐标）聚合出的位点坐标，由
`scripts/build_neuron_sites.py` 生成 `data/derived/neuron_sites.parquet`。

## 结果（2026-09-13）

见 `outputs/summary.json`、`outputs/fig1_rates.png`、`outputs/fig2_erg.png`。

- 放电：闪光下 R 群体 0→130 Hz；板层 L1 68 / L2 69 / L3 14 Hz（L3 输入突触
  权重总量低，欠驱动，符合其真实连接规模）
- 波形：双眼均出现 ERG 三段结构——**负 On 瞬变 → 持续负平台（光感受器
  电极 -0.7 mV 量级）→ 正 Off 瞬变**，与经典果蝇 ERG 极性一致
- **意外发现（左右眼不对称）**：左眼平台 -119 μV vs 右眼 -675 μV。根源是
  两个机制叠加：(a) 该样本左右视叶重建规模不对称（2,265 vs 1,112 个
  光感受器末梢，右眼板层沿视轴薄约一半）；(b) 突触偶极（源=R 末梢、汇=
  更深的板层 PSD）贡献正电位，部分抵消光电流的负平台——左眼抵消更强。
  这正是真实 ERG 各成分"发生器层竞争"的行为，后续实验可定量利用。
