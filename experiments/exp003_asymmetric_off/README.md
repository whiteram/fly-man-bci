# Experiment 003 — 非对称光转导：正 Off 瞬变能否再生？

**科学问题**：exp002 发现对称级联光转导下，任何回流假设都不产生正 Off
过冲（波形单调回到暗基线）。真实光转导是非对称的——关断快于激活
（Hardie & Raghu 2001）——这能否分离光电偶极与突触成分的时间尺度、
再生出真实 ERG 的正 Off 瞬变？

**设计**：exp002 的回路 / 配对 / 三种前向核原样保留（SEED=42；τ_fall=10
档位与 exp002 逐位复现，作为回归断言）。唯一改动：级联滤波每级按方向
取时间常数（输入高于状态用 τ_rise=10ms，低于用 τ_fall），扫
τ_fall ∈ {10, 5, 2.5} ms × 强度 {0.25×, 1×, 2×}。主指标：
**Off 过冲 = peak_off − 暗基线**（>0 即正 Off 瞬变）。

### 1. 正 Off 瞬变再生需要两个条件同时成立

| 核 | 突触贡献符号（平台，1×，L 眼） | Off 过冲（1×，L 眼）τ_fall=10/5/2.5 |
|---|---|---|
| t-bar 回流 | ≈ 0（-0.4% 范数） | 0 / 0 / 0 μV |
| 神经突回流 | **负**（≈ -1156 μV，源在髓质深处） | 0 / 0 / 0 μV |
| 均值位置 | **正**（≈ +526 μV，源在 R 末梢、更靠角膜） | **+151 / +175 / +198 μV** |

- **条件 (a) 时间尺度分离**：非对称光转导让光电偶极先塌、突触成分
  （R 膜 τ=10ms + 突触 τ_s=5ms 额外滞后）后消——mean 核过冲随 τ_fall
  减小与强度增大单调增长（2× 档 +179→+213→+253 μV）
- **条件 (b) 突触场符号为正**：过冲方向由突触贡献在电极处的符号决定。
  神经突回流核的突触贡献为负，关断加速只会让恢复更快（t50_off
  21→11→7 ms），波形仍单调回基线——时间尺度分离放大符号、不能翻转符号

### 2. 与 exp002 结论的拼接（本项目当前的主线故事）

真实 ERG 有正 Off 瞬变 ⟹ 在本模型族内要求板层突触电流环在角膜方向
产生**正**场，即回流电流相对 PSD 位于更靠角膜一侧——这与"回流沿 L
突起到髓质"的假设（负场）相反，而真实 L1/L2 是 Off 细胞（光灭时主动
发放）。**结论：真实 Off 瞬变的发生器大概率是 Off 通路的活动性关断
响应，而非单纯的时间尺度分离。** 把 L2 的 Off 动力学（整流/超极化
去抑制）加进电路是直接检验（即 HANDOFF 的扩电路方向）。

### 3. 不变性 / 回归检查（全过）

- τ_fall=10 与 exp002 逐位一致（plateau_late -556370.1 nV，断言 <1 nV）
- 平台幅值对 τ_fall 完全不变（-296251/-556370/-903277，三档全同）——
  稳态与瞬态时间常数无关，模型自洽
- 配对数 234,561、中位距离 0.159 μm 与 exp002 一致
