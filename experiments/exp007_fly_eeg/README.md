# Experiment 007（旗舰）— fly EEG：自然刺激 → 连接组级联 → 多电极场电位

**这是项目主线"从神经脉冲生成脑电的过程"的端到端交付**：真实连接组
电路（左叶 R → L1/L2/L3 → Mi/Tm → T4/T5，约 1.9 万神经元 / 167 万突触）
被自然刺激驱动，细胞外场电位由网络的瞬时突触电流经准静电前向核
（exp001–006 逐项建成并验证）在三个虚拟电极同步生成。每一毫秒的
"脑电"信号都完全由该毫秒的群体放电与突触电流计算而来。

## 刺激（11 s）

| 时段 | 内容 |
|---|---|
| 0–2 s | 黑暗（基线；所有层放电 0 Hz ✓） |
| 2–5 s | 空间均匀 1/f 闪烁（环境亮度波动） |
| 5–6.5 s | 1/f 空间纹理沿 exp006 偏好方向（−135°）漂移，100 μm/s |
| 6.5–8 s | 同一影片的**精确时间反演**（同边际分布、反方向） |
| 8–9.5 s | 带通纹理（15–45 μm 波长 = exp006 的 DS 最优空间尺度）正向漂移 |
| 9.5–11 s | 其时间反演 |

亮度恒非负（半波整流即真实光感受器所见），对比度 2，光电流
150 pA/亮度单位。

## 结果（2026-09-13）

见 `outputs/summary.json`、`outputs/fig1_fly_eeg.png`（主图：刺激 →
R/L/Mi/Tm/T4/T5 五层群体放电 → 眼表面/板层/髓质三通道场电位，9 联
时序）、`outputs/fig2_spectra_ds.png`（场谱 + 方向对比）。

### 1. 三通道"fly EEG"完整生成

| 通道 | 黑暗 | 闪烁 | 漂移+ |
|---|---|---|---|
| 眼表面 | −184 μV | +356 μV | +354 μV |
| 板层 | +131 μV | +680 μV | +628 μV |
| 髓质 | +44 μV | −2017 μV | −1957 μV |

三通道极性与幅值结构各不相同（眼通道由光电偶极主导、髓质通道由
Mi/Tm→T4/T5 突触电流主导且反号）——**空间分辨的多通道记录，全部由
突触电流前向生成**。层间放电增益清晰（闪烁期 R 24 → T4 32 Hz）。

### 2. 自然刺激下的方向对比：被适应非线性主导（诚实负结果）

时间反演对照下，**输入层 R 自身**的响应比就达宽带 1.22 / 带通 1.49——
不是 DS（R 无方向结构），而是光适应（τ=800ms 增益）与 1/f 刺激的
长相关共同作用：正放/反放中长亮/暗时段与适应历史的配对不同，
g·y2 的联合分布随播放方向改变。归一化后 T4/T5 的额外方向调制
≈0.85–0.87，弱于 exp006 相干光栅下的清晰 DS（DSI 0.34）。

**结论**：(a) 干净的方向信号需要相干单频光栅（exp006 已证）；自然
宽带刺激下，级联响应被适应历史与低频亮度结构主导——这与"自然场景
下 DS 对比度下降"的文献观察一致；(b) 时间反演对照在含慢适应的系统
里不是 DS 的充分对照，必须以输入层（R）为基线归一化——方法论教训。

## 局限

- 场由均值位置偶极生成（exp002 证明的回流位置敏感性在此同样适用，
  绝对幅值不可当真；眼通道含 23.5μm 外推的光电偶极）
- 均匀无限介质、点电极、无自发背景活动
- 电路止于 T4/T5（无 lobula plate/中央脑）

## 运行

```bash
python experiments/exp007_fly_eeg/run.py   # ~7 min（单次 11s 仿真）
```

依赖 exp005 的电路构建与 exp006 的偏好方向（hex 双回归内重算）。
