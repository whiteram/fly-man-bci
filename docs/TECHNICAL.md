# 核心技术文档 — 从神经脉冲到头皮脑电的前向仿真

适用范围：`src/ffbm/`、`experiments/exp001–012`、`scripts/`。不含可视化
页面（`viz/index.html`，另有 README）。直接使用的第三方库（numpy /
scipy / pandas / pyarrow）只说明用途；教科书公式（LIF、指数突触、
经典球壳模型）给出出处与本项目的参数，**自研部分**（电路推断、数值
实现细节、校准方法学、思想实验几何、背景 EEG 模型）详细展开。

---

## 1. 系统总览

一条单向数据流，全部在仓库内自实现（无 EEG/神经仿真第三方库）：

```
MaleCNS v1.0 连接组（官方数据集，§3）
        │  电路构建（左叶五层级联，§4）
        ▼
自然刺激协议（黑暗/1f 闪烁/正反漂移，§5.6）
        │
        ▼
逐 0.5ms 仿真：光转导 → LIF 放电 → 指数突触（RL/LM 电流基，
MT 电导基 + 逐边延迟，OU 背景噪声）（§5）
        │  每步产出：每条突触边的跨膜电流 y 或 g·y·(E−v)  [pA]
        ▼
准静电前向核（偶极对 × 体积导体 Green 函数）（§7）
        ├─ 均匀无限介质核 StaticPairField
        ├─ 密封二球核 SealedHeadPairField（果蝇头内电极）
        └─ 四球壳核 FourSpherePairField（人脑头皮 17 电极，§8）
        ▼
头皮电位 [μV] ──(可选)── 叠加背景人脑 EEG（§9）→ SNR / 检测论
```

核心思想：**头皮电位是突触电流状态的线性泛函**。对每组连接预先算好
`coef`（每电极 × 每边，V/A），运行时每毫秒的电位 = 一次矩阵乘法
`coef @ y`。线性性使叠加、通道扩展、事后换核都是廉价的。

## 4. 电路构建（自研，详细）

代码：`experiments/exp005_medulla_ds/run.py::build_circuit()`，被
exp006–011 与 viz 导出复用。

**五层级联（左叶）**：R1-R6（2,265）→ L1/L2/L3（2,677）→
8 种 Mi/Tm（7,195）→ T4a-d/T5a-d（6,793）；边 6,351 / 25,669 /
154,038，突触 1,666,962。权重 = 连接组给出的**突触计数**。

**4.1 左叶选择——池化 x 轴 2-means 中线**。数据集的 `hex1` 不是叶
标签而是六角网格 u 轴坐标（corr(hex1, x)=−0.78），直接按 hex 选叶是
错的（exp005 早期 bug）。正确做法：对每层的 x 坐标做 2-means
（20 轮迭代收敛），两侧各得一个聚类中心，**取 Mi1 有 hex1 注释最多
的那侧为左叶**，中线 = 两簇边界中点，各层独立按 x < 中线截取。这使
R/L/Mi/Tm/T4/T5 六层在同侧一致。

**4.2 漂移方向轴——hex 回归**。刺激漂移方向不是任选的：把 Mi1 的
三维位置投影到与眼轴 u_eye 正交的平面基 (a1,b1)，对 hex1 / hex2 做
最小二乘回归得 u_dir / v_dir（六角网格的两个基向量在物理空间的方
向），偏好方向 = −135° 处的六角合成。这保证"沿偏好方向漂移"与解剖
的延迟线轴一致（exp006 的波长匹配依赖于此）。

**4.3 T4/T5 列推断——主导伙伴投票**。T4/T5 各亚型 (a-d) 对应哪个
六角列在数据里没有直接注释。推断：对每只 T4（或 T5），取其最大的
突触前伙伴类型（Mi1 → T4，Tm9 → T5）中最常见伙伴的 hex 坐标作为
该细胞的列。列对齐质量决定延迟线 DS 能否涌现（exp006 验证过）。

**4.4 符号注入**。exp009 起，每条边的符号来自数据集递质注释：
R→L 组胺 −1；L1→Mi1/Tm3/Mi4 谷氨酸 −1；L2/L3→Tm 系 乙酰胆碱 +1；
M→T 各边按注释。LMC 暗去极化基流（§6）与双重反号共同产生
ON/OFF 架构（光→R 放电→抑制 L1→解除对 Mi1 的抑制→T4 = ON；
L2 暗态活跃→驱动 Tm→T5 = OFF）——无任何手写极性。

## 5. 神经元与突触模型

代码：`src/ffbm/simulation.py`。测试 `tests/test_simulation_extensions.py` 等（16 项全过）。

**5.1 LIF 神经元**（Lapicque 1907，教科书模型）。参数按层：

| 层 | τ_m | 不应期 | 说明 |
|---|---|---|---|
| R1-6 | 10 ms | 3 ms | |
| L1-3 | 20 ms | 2 ms | （真实为分级电位神经元，用户暂缓改） |
| Mi/Tm | 10 ms | 2 ms | |
| T4/T5 | 10 ms | 2 ms | |

V_rest=−70，V_th=−50，V_reset=−70 mV，R_m=0.1 GΩ（全层）。
无 g_tot 时为显式欧拉（旧行为逐字节保留）；有电导输入时半隐式
（§5.3）。阈值、τ 量级取自果蝇文献，未逐细胞拟合——放电率的可信度
由 §6 的工作点校准兜底。

**5.2 指数突触基础形态**（标准）。边状态 y_e 遇突触前脉冲加
`gain·weight_e`，按 exp(−dt/τ_s) 衰减；CSR 稀疏矩阵一次 matvec
聚合到突触后神经元。关键实现：y 按 (post,pre) 排序存储，前向核的
coef 矩阵用**同一排序**（`lexsort((pre,post))`）构建——这是仿真态
与场核对齐的契约，exp001 曾因错序翻车。

**5.3 电导模式（自研扩展）**。仅用于 M→T4/T5（RL/LM 仍电流基，见
§11）。y_e 变为无量纲门控（kick = weight），每边电流

    I_e = g_unit · y_e · (E_rev,e − v_post)，  E_rev = 0（sign>0）/ −80 mV（sign<0）

g_unit = 0.02 nS（校准，§6）。单位链：nS·mV = pA。

积分必须半隐式：把输入写成 i(v) = i_indep − g_tot·v（i_indep =
base + Σ g·E_rev，g_tot = Σ g），则

    v_new = (v + (dt/τ)(V_rest + R·i_indep)) / (1 + (dt/τ)(1 + R·g_tot))

无条件稳定。**教训记录**：先用了显式欧拉，自然刺激下 Mi/Tm 峰值
放电率比校准闪光高数倍、总电导使 R·g·dt → τ 时数值发散（φ→NaN），
导出崩溃两次后定位并修复；现有测试用 R·g=50 的极端电导验证 v 有界
且钳制在翻转电位。实现：`to_neuron_drive() → (i_indep, g_tot)` +
`LIFPopulation.step(i, g_tot=...)`；场核消费 `edge_currents(v)`
（电导模式下返回真实电流而非门控）。

**5.4 逐边传输延迟（自研扩展）**。每边 delay = 1 ms（化学突触）+
|pre−post 位点距离| / 300 μm/ms（0.3 m/s，小轴突）+ ±0.5 ms 均匀抖动。
实现为环形缓冲（n_bins × n_edges float32，每步冲刷一行）；delay=0
保持旧的同步投递。诚实结论：果蝇尺度延迟 1.0–1.3 ms/级，对波形影响
微小（校准点复验不变）——保留是为未来相位分析与几何敏感性。

**5.5 OU 背景噪声（自研，现为全群体）**。`ColoredCurrentNoise`：精确
离散 Ornstein-Uhlenbeck 过程 x←a·x+k·w，k=σ√(1−a²)，平稳std=σ 与 dt
无关。τ_n=8 ms；σ：R 50 / L 40 / Mi/Tm 40 / T4/T5 60 pA，对应膜电压
波动 std_V ≈ σ·R·√(τ_n/(τ_n+τ_m)) ≈ 2.7–4 mV（白噪声 20 pA 只给
0.3 mV）。**动机**：低噪声 LIF 的 f-I 是刀锋（5↔50 Hz 只差 200→250
pA），T4 黑暗期数学上不可能放电；真实自发活动来自数以千计未采样
突触的轰击（时间相关、幅度真实），OU 是它的最小可信替身。第 4 轮
校准后全部四层都用 OU（R 黑暗期从 0 抬到 2.7 Hz，更接近真实暗紧张
发放；Mi/Tm 自发从"基流刀锋上"变为噪声驱动）。

**5.6 光转导级联（自研现象学模型）**。`PhotoCascadeVector`：两级
一阶低通（τ=10 ms ×2，≈20 ms 感受器潜伏期）+ 慢光适应
（τ=800 ms，平台下垂 30%）。输入光强增量（pA 语义），输出适应后的
电流增量。形状参数与 exp002 强度系列 / exp004 闪烁融合对过；每 R
细胞共享参数（无异质性，§12）。

## 6. 工作点校准方法学（自研，三轮）

代码：`scripts/calibrate_working_point.py`；结果
`scripts/outputs/working_point_calibration{,_r3}.json`。

**方法**：短仿真（4 s = 2 s 黑暗 + 2 s 350 pA 闪光，只测放电率，
不建场核），网格扫描自由参数，目标 = 文献自发放电窗（Hz）：
Mi/Tm 5–20、T4 2–12、T5 2–15；罚分 = 窗外距离平方和（黑暗窗权重
1.0、闪光窗 0.35）+ T4 闪光响应 <5 Hz 罚 400。

**四轮演进**（每轮都因新机制重做；第 4 轮起校准与导出走同一
`ffbm.pipeline` 代码路径，不再各自维护循环）：

| 轮 | 机制背景 | 结果（黑暗期 R/MID/T4/T5 Hz） | 评分 |
|---|---|---|---|
| 1 | 白噪声 | 0 / 22.4 / 0 / 11.7（T4 死寂） | 411 |
| 2 | +T4 手调基流 195 pA 刀锋 | 0 / 22.4 / 2.1 / 11.7（脆弱） | 5.8 |
| 3 | +OU(T45) + 电导 MT + 延迟 | 0 / 21.7 / 5.8 / 5.0 | 5.8 |
| 4 | 全群体 OU（R50/L40/MID40/T4560） | **2.7 / 19.0 / 7.0 / 3.0** | **0.0** |

第 4 轮 score 0.0 = 黑暗期与闪光期全部指标（含 R/L）同时落在文献窗
内。**结构发现**：T4 的 Mi1 输入在黑暗期被 L1 完全抑制，任何增益下
都是 0——其真实自发活动只能来自**未接线的伙伴**。处理：显式承认并
给 T4 群体加"未建模输入背景"（I_T4_BASE=175 pA + OU 噪声），这是
连接组仿真的标准做法（对未采样输入注入基线），参数在 meta 与
HANDOFF 中透明记录。

**最终参数**（viz 导出 CAL）：I_MID_BASE=90，I_T4_BASE=175，
OU σ=60 pA τ=8 ms，g_unit=0.02 nS，E_inh=−80 mV；I_L_BASE=250
（LMC 暗去极化，exp009），GAIN_RL=12、GAIN_LM=20 pA/突触，
τ_RL=τ_LM=5 ms；MT 分化动力学 τ_s（ms）：Mi1 25 / Tm3 8 / Mi4 10 /
Mi9 15 / Tm1 20 / Tm2 8 / Tm4 10 / Tm9 20（exp005 KINETICS，
为 DS 涌现设计）。

**诚实边界**：校准只匹配平均放电率，未匹配 ISI 变异性（Fano/
CV）；工作点对参数仍敏感（OU 已把敏感度从"5 pA 换几十 Hz"降到平
滑梯度）。

## 7. 细胞外场前向模型

代码：`src/ffbm/forward.py`。审计：`scripts/audit_scalp_forward.py`、
`tests/test_*_kernel.py`。

**7.1 偶极对近似与符号约定（自研设计决策）——回流几何已闭合
（exp013，2026-09-14）**：判定为 **neurite**（源在 L 细胞远端突起），
绝对幅值标定 = 管线值 ×1.7（neurite/meanpos 核范数比）。
准静电近似（<1 kHz 电容/电感可忽略，EEG 标准）：每条突触边近似为
等值反号电流对——**源在突触前位点、汇在突触后位点**：

    φ(electrode) = Σ_e  y_e · (1/4πσ) · (1/|r−r_pre,e| − 1/|r−r_post,e|)

符号经 exp001–002 与 ERG 形态（角膜负向）校验。**回流问题**：真实
回流电流沿突触后细胞膜分布，"源在 pre 位点"是假设之一；exp002 量
化三种几何的核范数差 ~400×；exp012（§10）尝试用 ERG 锚点判别——
暂未闭合，绝对幅值因此未标定（相对量：波形、拓扑、相位不受影响）。
另：光感受器电流建模为 rhabdomere→胞体偶极（23.5 μm 外推，exp002
标定）。

**7.2 均匀无限介质核 `StaticPairField`**（教科书 Green 函数）。
coef = (1/|r−pre| − 1/|r−post|)/(4πσ)，上面公式的直接实现。

**7.3 密封二球核 `SealedHeadPairField`**。内球（CNS）+ 壳 + 最外
法向电流为零（昆虫角质层绝缘）。每阶 Legendre 系数解 3×3 边界系
统（V 连续、σ∂V/∂r 连续、密封）。**物理结论**（exp008）：密封壳
外场严格为零——果蝇头外测不到任何 EEG，这是转人脑思想实验的动因。

**7.4 四球壳核 `FourSpherePairField`**（经典 4-sphere 模型的自实
现，详细）。几何：脑 78 / CSF 80 / 颅骨 85 / 头皮 92 mm；σ =
0.33 / 1.79 / 0.013 / 0.33 S/m（人脑文献值）。每阶 n 的解：

    V1 = a·r^n + src·r^−(n+1)        （脑内，源项已知）
    V2 = b·r^n + c·r^−(n+1)          （CSF）
    V3 = d·r^n + e·r^−(n+1)          （颅骨）
    V4 = f·r^n + g·r^−(n+1)          （头皮）

边界条件 7 条：r1/r2/r3 各 2 条（V 连续 + σ∂V/∂r 连续）+ r4 密封
（∂V/∂r=0）→ 7×7 线性方程组，逐阶求解取 (f_n, g_n)，头皮电极电位
= Σ_n P_n(cosθ)[f_n r0^n r^n + g_n r0^n r^−(n+1)]/(4πσ1 r1)。

数值细节（自研，全部为稳定性所需）：半径按 r1 归一（原始量纲矩阵
病态）；每行按最大元素均衡（equilibration）再求解；**n=0 返回 0**
（密封头内单极不可解；对电流对恰好严格相消，同时固定了规范——电
位是"球面平均为零"意义上的相对值）；勒让德多项式用三项递推逐阶
累积。级数 60 阶（导出默认）：网络深度 r0/r1≤0.75 时截断误差
2.5×10⁻¹⁰。

**7.5 验证与审计结果**（可全部复跑）：

| 检验 | 结果 | 意义 |
|---|---|---|
| 双解交叉验证（σ_CSF=σ_脑 时四球≡三球，两套独立实现） | 一致到 3.9×10⁻⁷ | 最强证据：两套不同代码同一物理 |
| 偶极反对称（翻偶极矩→电位反号） | 误差 0.0 | 精确 |
| 级数收敛 S=60 vs 200 | 2.5×10⁻¹⁰ | 截断可忽略 |
| 颅骨衰减（浅表/深部） | 0.29 / 0.87 | 文献 0.3–0.5 / 0.7–0.9 ✓ |
| CSF 分流效应（浅表径向偶极） | ×0.7 | 高电导 CSF 使电流沿层环流、减少穿颅份额（方向与直觉相反，文献一致） |

## 8. 人脑壳思想实验设置（自研几何，详细）

exp010/011 建立，viz 导出实现。断言：**假设放电模式不因放大而改变**
（纯几何/检测论实验；×400 的真实神经元按电缆理论无法工作，见 §11）。

**8.1 缩放**：网络全部位点 (p−center)×400；头球心 = 网络质心。

**8.2 枕极放置**（二次约束求最大偏移，自研）。真实视觉皮层贴枕极
内侧颅骨，不在头心。把 T4/T5 端（输出/"皮层"端，−u_eye 方向）推向
球壁：目标 = T4/T5 侧极值达 0.90·R_brain；约束 = 所有点
|p−center| ≤ 0.98·R_brain，每点给一个关于偏移量 d 的一元二次不等
式，取正根的最小值为可行上界。结果：偏移 31.1 mm，最小边缘余量
1.5 mm。**效果**：最强头皮信号从 0°（眼轴）移到 141–162°（枕侧），
与真实视觉诱发电位枕区（Oz/O1/O2）拓扑一致；两极反相关
corr(0°,162°) ≈ −0.98（偶极拓扑的标准特征）。

**8.3 电极阵列**：17 个点电极，位于头皮层内 0.985·R_scalp。布局 =
眼轴锚定 1 个 + 斐波那契球面 17 点删去最近者；通道按与眼轴夹角排序
（0°→162°），热图因此呈清晰的空间梯度。

## 9. 背景人脑 EEG 与检测论（自研模型）

**动机**：思想实验的完备形式必须回答"信号在真实记录里能否读出"，
而非只有干净信号。

**生成**（`viz/export_data.py`，种子 2026）：每电极三成分叠加——
(i) 闭眼 α 波：10 Hz 正弦 × 振幅包络（0.55+0.45·sin，~1.4 s 涨落
周期）× 空间权重 cos²(与枕极夹角)（α 波枕区主导，与我们的网络同侧
——最不利情形）；峰值 ~30 μV。(ii) 1/f 非周期活动 3 μV（FFT 法
合成，谱指数 1）。(iii) 传感器白噪声 1.5 μV。不含肌电/漂移/电极
脱落伪迹（§12）。

**检测论**：信号幅度 = 最强电极在闪烁窗（1.5–4.5 s）的 std；背景
= 同电极同窗 std；k 次试验平均后 d′ = √k·(Δμ/σ)，d′=2 所需
k = (2σ_bg/Δμ)²。带限版（`vizprep.snr_metrics`）：2–20 Hz 带内方差
比（带外噪声不计入）。

**结果（第 4 轮全机制栈）**：最强电极 147°，果蝇信号 0.69 μV vs
背景 10.0 μV → 宽带 d′=2 需 **842** 次试验平均；**2–20 Hz 带限反而
需要 3019 次**。频谱解释：果蝇信号能量相当大部分在 >20 Hz（突触
时间常数 5–25 ms → 40–200 Hz），而 2–20 Hz 带内背景被 α 峰主导——
如果采集系统读高频带（避开 α、保留信号），SNR 会优于两个数字；
但真实头皮记录的高频带受肌电污染。这是"思想实验信号的可测性
取决于频带选择"的定量结论。（exp011 的旧 d′≈28/次 是旧工作点+无
背景下的历史记录，被本数字取代。）

**头模型参数敏感性**（`scripts/head_sensitivity.py`，核范数比例）：
电导率 ±20%、层厚 ±1 mm 的文献散布下，深部源的头皮幅值包络仅
**×0.82–×1.06**（最大杠杆是脑/头皮电导 1/σ 标度 −18%；颅骨 σ ±20%
只动 ±6%）。结论：头模型参数不是幅值不确定性的主要来源——回流
电流几何（数量级杠杆，§10）才是。

## 10. 回流判别实验 exp012 / exp012b（自研设计）

`experiments/exp012_return_constraint/`：当前符号体系下重跑闪光
ERG，三几何（t-bar 邻近 / 神经突跨区 / 均值位置）共享同一放电序列
（同种子，只换核），对照四个经典 ERG 锚点：on/平台 ∈[1,3]、
off/on ∈[0.3,1]、LMC@on ∈[0.5,1]、LMC@平台 ∈[0,0.5]。

**第一次结果（诚实未定论）**：无一变体全过；off/on 对所有变体为 0。
**exp012b（接入 exp003 的 τ_fall=2.5ms 非对称光转导后）**：结果与
对称条件**完全相同**——off 瞬变仍为零。机理：闪光结束时 R 偶极
正向回基线，而 L 群体从组胺抑制中恢复、其分量**负向**回基线，两者
反向抵消（exp003 当年在旧符号体系下两者同向才有正超射）。**判别
闭合路径收敛到 LMC 侧动力学**：L 群体反弹机制（sag/整流）或真实的
inverted-chloride 组胺电导（§12 A3）——后者与 #A3 是同一件事。
neurite 变体持续病理（L/R 偶极对消）；绝对幅值三变体差 ~10×，
头皮脑电绝对幅值的标定仍卡在此。

## 11. 已知局限与假设（诚实清单）

用户排除椭球/各向异性）；网络以质心球簇放置（真实皮层是折叠薄层）；
点电极、无参考定义（用户排除参考电极议题）。

**统计类**：单种子；校准只匹配均值放电率；SNR 用全带 std（α 带与
信号带部分重叠，带限 SNR 更严谨，§12）。

### 14a. L1/L2 分级电位（exp013b，建议与 A3 文献核实捆绑实施）

现状：真实的 L1/L2 是**不放电**的模拟电位细胞（分级电压传输，
continuous transmitter release），本管线用脉冲 LIF 代理（黑暗期
12.5 Hz 伪脉冲，文档 §11 已声明）。

为什么要做：① 板层是 ERG 的第二大偶极来源，分级释放会把 L 分量
从"事件量子化"变为"平滑连续"，改变其时间结构与幅度；② 它与
deferred 的 inverted-Cl 组胺电导（§12 A3）是**同一块生物学的两侧**
——真实 LMC 输入端（组胺氯电导）和输出端（分级释放）都非脉冲；
③ exp012b 证明 off 瞬变缺失的根源在 LMC 侧动力学。

实现步骤：
1. `simulation.py`：`GradedUnit`（漏积分器，无阈值/复位；释放率
   r(v) = sigmoid 斜率参数可校准）+ `ExponentialSynapses` 的 graded
   驱动模式（边状态 y 由突触前释放率一阶滤波驱动，替代事件投递）。
2. `pipeline`：`cal["L_GRADED"] = True` 开关；工作点第 5 轮校准
   （黑暗窗口 + ON/OFF 架构复验 + ERG 对形）。
3. 判据：L 分量波形平滑化程度；off/on 锚点是否改善（能否闭合
   exp012 判别）；头皮信号幅度的定量变化。
4. 预期影响：对头皮信号幅度方向不确定、量级中等（±30–50%：
   平滑传输减少高频量子化成分，tonic 释放可能增强低频偶极）；
   对 ERG 波形保真影响大。**建议先查文献再动**（与 A3 同一次调研）。

### 14c. 终末项：回流判别闭合 + 分级 L1/L2 进主管线（影响评估）
