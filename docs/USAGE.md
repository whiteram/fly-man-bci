# 使用手册（可视化页面 + 数据导出）

页面入口：`viz/index.html`（本地服务 `python -m http.server 8613` 后访问
`http://localhost:8613/index.html`）。数据由 `viz/data/viz_data.json`
提供，重新生成见 §6。

---

## 1. 页面布局

- **左侧 3D 视图**：透明人头 + 四球壳层内的果蝇视觉系统点云、头皮电极、
  头皮电位着色球；鼠标左键旋转、滚轮缩放、右键平移。
- **右侧信息面板**：标题与仿真说明、播放控制、刺激亮度条、通道热图、
  各层群体放电率曲线。
- **左上按钮列**：⏵（图层面板，默认折叠）、人头校准、电极编辑、
  10-20标定、视角标定。
- **时间控制**：暂停/播放、重放、1×/2×/4× 速度、进度条；
  刺激亮度条上的色块与当前刺激时段一一对应（颜色定义见
  docs/STIMULUS.md §3）。

## 3. 三种标定工作流（互相独立、自动保存）

### 3.1 人头校准（ sliders）
把透明头模对齐到电极球：缩放 / 俯仰 / 偏航 / 翻滚 / 三轴平移滑块 +
六个正交视角按钮（正面/背面/左侧/右侧/头顶/下巴/复位）。滑块即改即存
（localStorage `headFormCalib_v3`），「复制JSON」可导出为超参数快照。
视角按钮的方向由「视角标定」决定。

### 3.2 10-20 标定（电极帽）
六个受约束手柄 + 两个整体旋转滑块，**每次拖动后整帽按 10-20/10-10
比例规则实时重建**：

| 手柄/滑块 | 自由度 | 说明 |
|---|---|---|
| 金色 Cz | 1 | 沿耳平面圆滑动 = 整帽前后俯仰 |
| 金色 Fz / Fpz / Oz | 1×3 | 沿矢状弧滑动；拖动者按 10-20 百分比（20%/40%/40%）重新决定中轴弧 ni，中线按比例重排 |
| 青色 A1 / A2 | 1 | 沿耳位圆滑动，自动镜像；耳位角 th 驱动冠状环（C3/C4=0.4·th，T7/T8=0.8·th）与全部侧链 |
| 横转 yaw 滑块 | 1 | 整帽绕头顶轴旋转（对齐鼻中线） |
| 纵转 roll 滑块 | 1 | 整帽绕鼻轴倾（向左/右耳） |

面板实时显示 ni / th / yaw / roll。「复制JSON」交给管线重新生成
配置与布局（`viz/make_elec_layout.py` / `make_elec_configs.py` 会消费
它）；「恢复标准位」回到烘焙状态。状态存 localStorage `calib1020`，
页面启动时自动应用（不会出现启动显示旧布局的问题）。

### 3.3 视角标定（六个正交视图）
拖动金色「前」（鼻方向）与青色「顶」（头顶方向）两个手柄，后/底/左/右
自动正交得出（右 = A2 侧）。面板里的 正面/背面/左侧/右侧/头顶/下巴
按钮即时试看。存 localStorage `viewDirs`。

### 3.4 电极编辑（自由微调）
「电极编辑」模式下 45 个电极直接拖拽（波形为插值预览），红球可加自定义
锚点。调好后「复制JSON」交给管线。

## 4. 电极配置系统

下拉框四套：`std_1020_45`（波形已导出）、`std_1010_64`、`std_105_128`、
`egi_256`（后三套为插值预览——标题会注明）。切换即时重建电极/标签/
热图/头皮着色。自定义布局、格式 schema、重新生成命令见
**viz/ELEC_CONFIGS.md**。注意：只有 45/64 两套规则配置支持 10-20 标定
滑块；EGI/自定义配置会提示并阻止。

## 5. 波形数据：精确 vs 预览

- 页面波形来自上次导出（`viz/data/viz_data.json`），只对**导出时的
  45 通道**精确；
- 任何标定/拖拽之后，移动过的通道显示球面距离插值的**预览波形**
  （标题/面板会注明）；
- 定稿后交给管线重新导出（§6）即为精确数据。数字方法与误差量级见
  docs/TECHNICAL.md。

## 6. 数据导出（管线）

```bash
conda activate ffbm
python viz/export_data.py --elec-layout viz/data/elec_layout_1010.json \
                          --regions visual_bilateral=True,vpn_central=True,...
```

- `--elec-layout`：任意通道布局文件（name → [x,y,z]；可从
  elec_configs.json 提取，见 ELEC_CONFIGS.md §导出）；
- `--regions`：区域开关（`--help` 查看可用区域）；
- 耗时参考：核构建 361 s @45 导、≈513 s @64、≈1030 s @128、
  ≈1930 s @EGI241（线性；完整导出再加仿真与背景 EEG）；
- 建议后台运行，结束后 `viz/data/viz_data.json` 即页面新数据。
- 刺激协议参数（时段/对比度/漂移速度等）在 `src/ffbm/params.py` 的
  `stimulus` 节修改，详见 docs/STIMULUS.md。

## 7. 常见问题

- **页面打开看不到电极/标签**：图层面板里勾选「头皮电极」（⏵ 展开）。
- **调了标定后想回到交付状态**：对应面板点「恢复标准位」。
- **六个视角方向不对**：进「视角标定」拖「前」「顶」两个手柄。
- **波形看起来不对/很平**：确认当前配置是否为「插值预览」；精确波形
  需要按 §6 重导出。
