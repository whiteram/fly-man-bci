# 刺激协议文档（视觉）——实现、参数与"真实图像"可行性

适用范围：`viz/export_data.py`（自然刺激协议）、`src/ffbm/pipeline.py`
（刺激注入接口）、`src/ffbm/params.py`（参数注册表 `stimulus` 节）。

---

## 1. 总览：当前唯一的感官输入是视觉

当前仿真的全部感觉输入是**视觉**：光信号 → R1–R6 光感受器群体 →
板层（L1/L3/Mi1/Tm）→ T4/T5 → VPN → 中央脑。嗅觉/触觉/听觉通路在
连接组里存在，但未被装配（`ffbm.regions` 只开了视觉区），也没有对应的
前向刺激模型。

刺激的入口是一个**纯函数**：

```python
fp.simulate(circuit, cal, input_fn, ...)
# input_fn(t) -> 每个光感受器的亮度增量波形采样（见 §2）
```

仿真每 0.5 ms 调用一次 `input_fn(t)`，得到每个 R 细胞的亮度 λᵢ(t)
（无量纲，1 = 黑暗基底），再经光转导级联变成光电流。

## 2. 亮度 → 光电流的链路

```
λᵢ(t)（亮度，无量纲）
   │  ×I_LUM = 150 pA        （整体增益，params: stimulus.i_lum）
   ▼
两级一阶低通（τ = 10 ms ×2 ≈ 20 ms 感受器潜伏期）
   │  + 慢光适应（τ = 800 ms，平台下垂 30%）
   ▼
inc_f(t)（适应后的光电流增量，pA）
   │  + I_R_BASE = 130 pA    （黑暗基底电流，params: working_point）
   ▼
i_photo = I_R_BASE + inc_f  →  R 细胞的注入电流（LIF 输入）
```

亮度构造上**非负**（下限 0.05），不会出现负光强；参数
`PhotoCascadeVector` 对所有 R 细胞共享（无异质性），已对 exp002 强度
系列 / exp004 闪烁融合标定。

### 2.1 "800 ms"是适应增益，不是延迟

常见误读需要澄清：`PhotoCascade.step` 的信号通路只有
`y1 → y2` 两级 10 ms 低通——**闪烁/瞬态的响应潜伏期 ≈ 20 ms**，与
实测果蝇 R1-R6（20–50 ms 量级）一致。800 ms 分支是**乘性慢增益**：

```
g(t):  有光（inc>0）时以 τ=800 ms 缓慢趋向 1−30%（感光适应/脱敏）
       回到黑暗时缓慢恢复 1
输出 = g(t) × y2(t)
```

它只跟踪**分钟级以下、秒级以上的平均亮度包络**并下调增益——对
20–100 ms 的快速波动，g 几乎是常数，因此快信号基本无损通过。这正是
"光适应"的语义：走进烈日下，眼睛不是变瞎了 1 秒，而是敏感度在约 1 s
内降下来。真实果蝇的多时间尺度适应（~100 ms 快成分 + 秒级慢成分 +
瞳孔色素迁移）被压缩成这一个 800 ms 单时间常数现象学模型——这是
exp002 对 ERG 平台下垂形态标定的结果，不是响应延迟。

## 3. 时段协议（自然刺激，10.5 s）

协议参数全部在 **`src/ffbm/params.py` → `SECTIONS["stimulus"]`**（可在
那里修改；`python -m ffbm.params` 更新 docs/PARAMS.md；重跑导出生效）。

| 时段 | 时间 (ms) | 亮度定义 | 页面色条 |
|---|---|---|---|
| dark | 0–1500 | λ = 1（黑暗基线） | 蓝灰 |
| flicker | 1500–4500 | λ = 1 + C·f(t)，f 为 1/f 时间噪声 | 黄 |
| drift+ | 4500–6000 | 1/f 空间纹理沿偏好方向正向漂移 | 绿 |
| drift− | 6000–7500 | 同一影片**时间反演**回放 | 青 |
| band+ | 7500–9000 | DS 尺度带通纹理正向漂移 | 粉 |
| band− | 9000–10500 | 其时间反演 | 紫 |

其中 C = `stimulus.stim_contrast` = 2.0；纹理/噪声生成种子
`stimulus.seed` = 42。

### 各时段的数学构造

- **1/f 闪烁** `f(t)`：白噪声 FFT → 幅度除以 f^(1/2) → 逆 FFT → 归一化。
  全场均匀（所有 R 细胞相同），无空间结构。
- **空间纹理** `tex(x)`：8192 点 1/f 噪声铺满"眼张距 + 漂移程"。
- **drift 时段**：每个 R 细胞按**自己在偏好轴上的投影坐标**采样
  λᵢ(t) = 1 + C·tex(xᵢ − v·s(t))，v = `drift_speed` = 0.1 μm/ms，
  s(t) 随时段正放/反放。这是**空间上有结构**的刺激：不同位置的
  光感受器看到不同的亮度时间序列，前后顺序决定 T4/T5 的方向响应。
- **band 时段**：同 drift，但纹理经带通 k ∈ [1/45, 1/15] μm⁻¹——
  由板层柱间距 `lam_um` = 22 μm 设定，恰为 T4/T5 运动检测的特征尺度。
- **drift−/band−**：时间反演对照——同功率谱、反相关结构，用于分离
  "方向性响应"与"功率谱响应"。

### 偏好方向 e_ds 的来源（六角轴回归）

T4/T5 的偏好方向不由人工指定，而是从连接组注释回归：取左叶 Mi1 的
`assignedOlHex1/2`（六角小眼轴分配）与胞体位置做最小二乘，得到两根
六角轴方向 u、v，再合成为 e_ds = cos(−135°)·u + sin(−135°)·v
（−135° 沿用 exp005 的 DS 标定方向）。只回归左叶——两叶六角轴在物理
x 上镜像，联合回归会相互抵消。

## 4. 可修改的超参数一览（stimulus 节）

| 参数 | 默认 | 说明 |
|---|---|---|
| `seed` | 42 | 1/f 噪声与纹理的随机种子 |
| `t_epochs` | 见 §3 表 | 时段表（名称, 起, 止）；增删时段页面色条自动跟随 |
| `stim_contrast` | 2.0 | 亮度调制幅度（×基底 1） |
| `i_lum` | 150 pA | 亮度→光电流整体增益（标定值） |
| `drift_speed` | 0.1 μm/ms | 纹理漂移速度 |
| `lam_um` | 22 μm | 板层柱间距（band 时段的带通中心尺度） |

## 5. 接收"人类感知的图像"：视觉输入模块（已实现）

**可以，且已实现为可配置的通用视觉输入模块**。目录文件
`viz/data/visual_inputs.json` 定义若干"视觉输入"，导出时用
`--visual-input <id>` 选择：

```json
{"inputs": [
  {"id": "natural_1d", "kind": "line_scan",
   "label": "自然协议（1/f 闪烁+漂移）"},
  {"id": "demo_bounce", "kind": "video",
   "label": "演示：弹跳球（人类视频→果蝇眼）",
   "source": "data/stimuli/demo_bounce.npy",
   "fps": 30.0, "blur_px": 1.2, "lo": 0.05, "hi": 3.0}
]}
```

- `kind: "line_scan"` —— 原始自然协议（§3），参数在 params.py；
- `kind: "video"` —— 人类视频 → 小网膜采样，处理流水线：

```
(帧, 高, 宽) 灰度 .npy
   │ 1) 高斯模糊 σ=blur_px     —— 小网膜接受域（~5°）抗混叠
   │ 2) 逐帧 1%–99% 分位归一化 —— 映射到 [0,1]
   │ 3) 眼平面仿射映射         —— 每个光感受器的眼面坐标 (xᵢ,yᵢ)
   │                              (r_pos 在 a1/b1 基上的投影) 双线性
   │                              定位到图像像素
   ▼
λᵢ(帧号) = lo + (hi−lo)·帧[yᵢ, xᵢ]   （lo=0.05, hi=3.0）
   ▼
之后与 §2 完全相同（光转导 → LIF → 突触 → 前向核，零改动）
```

新增一套"视觉输入" = 在目录 JSON 里追加一个条目 + 放一个
(帧, 高, 宽) 的 `.npy`。真实视频转换脚本：

```bash
pip install imageio imageio-ffmpeg
python viz/make_stimulus_from_video.py clip.mp4 \
       viz/data/stimuli/my_clip.npy --fps 30 --duration 10.5
```

内置演示：`viz/make_demo_stimulus.py` 生成"弹跳球 + 移动暗条"的
人类可读视频（10.5 s × 30 fps），`--visual-input demo_bounce` 使用。

### 5.1 维度对照（为什么是这样映射）

| 维度 | 人类图像 | 果蝇 R1-R6 通路 | 处理 |
|---|---|---|---|
| 颜色 | RGB | **无色觉**（R1–R6 仅亮度） | 灰度化（luma 加权） |
| 空间 | 巨量像素 | ~2,265+1,112 个光感受器 = 等效像素 | 5° 接受域模糊 + 小网膜采样 |
| 视野 | 矩形整幅 | 保留群体覆盖的眼面区域 | 眼平面仿射映射（覆盖 R 群体外接矩形） |
| 亮度 | 任意/HDR | λ ∈ [0.05, hi] | 分位归一化 + lo/hi 映射 |
| 时间 | 24–60 fps | 20 ms 潜伏 + 适应 | 帧率可配；快运动被生物性低通 |

### 5.2 页面同步可视化（已实现）

视频输入导出时同步产出 `viz/data/stim_frames.bin`：每帧两幅预览——
**人类视频**（源帧降采样）与**果蝇眼采样**（全部光感受器采样值在眼
平面上的栅格化亮度图）。页面"刺激视图"面板（位于刺激亮度条上方）
两幅画布随仿真时间光标逐帧同步播放，与通道热图、放电率曲线、头皮
电位着色共用同一时间轴——直观对照"人看到什么 / 果蝇看到什么 /
神经与脑电怎么反应"。

## 6. 其他模态

暂无。若将来要加嗅觉等：连接组中对应感觉区的上游需要 (a) 输入模型、
(b) 该区的区域开关与电路装配（`ffbm.regions` 已支持按区启停）、
(c) 前向核（电流泛函自动适用）。刺激入口同样是一个 `input_fn(t)`。
