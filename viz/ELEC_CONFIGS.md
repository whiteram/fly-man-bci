# 电极配置文件说明（ELEC_CONFIGS）

本项目的头皮电极布局由一份配置目录文件描述：`viz/data/elec_configs.json`。
页面启动时自动加载它，图层面板顶部的「电极配置」下拉框可以在各套配置之间
实时切换；可视化管线通过 `--elec-layout` 消费同一份布局。

## 一、系统的层级关系

| 系统 | 电极间距 | 典型导联数 | 本项目配置 |
|---|---|---|---|
| 10-20（Jasper 1958） | 20% | 19–21 | `std_1020_45`（45 导：10-20 + 常用 10-10 中线/分度） |
| 10-10（Nuwer 1998 等） | 10% | 64–81 | `std_1010_64`（64 导经典 10-10 帽） |
| 10-5（Oostenveld & Praamstra 2001） | 5% | 128–256+ | `std_105_128`（128 导级别） |
| 商用 Geodesic 网 | 测地分布 | 128/256 | `egi_256`（EGI HydroCel GSN 256，面颈锥过滤后 241 点位） |

- **10-10** 是把 10-20 每条链的 20% 间隔二分（10% 间隔）。
- **10-5** 是在 10-10 基础上再二分（5% 间隔）。商用 128 导帽（EGI/BioSemi 等）
  使用自家编号（E1…E128 / A1…），学术对应物就是 10-5 系统；MNE-Python 的
  `standard_1005` 蒙太奇包含全部 343 个官方 10-05 点位名称与坐标。
- 本项目的 `std_105_128` = 在 64 导帽的每条 10% 链上取中点（5% 细分），
  新点位名称通过 MNE `standard_1005` 官方名称匹配获得（含 AFF/FFC/CCP/CPP/
  PPO/TPP/TTP/POO 复合名与 `h` 后缀半距名）。
- **`egi_256`** 是 EGI HydroCel GSN 256 网帽的真实几何（MNE `EGI_256` 蒙太奇，
  E1…E256 官方编号），经蒙太奇自带 nasion/lpa fiducial 做手性确定的刚体对齐
  变换到本项目标定框架；颈锥（40°）以下的裙边位点被剔除，保留 241 个头皮
  点位。注意：EGI 的 E 编号是厂商自定义顺序，**没有解剖学含义**；该配置
  与规则推导的 10-x 帽几何不同（测地网在额中线天然较稀疏），只支持查看
  与插值预览，不支持 10-20 规则标定。

## 二、文件格式

```json
{
  "_schema": "说明文字",
  "version": 3,
  "frame": { "ni_arc_deg": 223.6, "yaw_deg": 0.0, "roll_deg": -0.3 },
  "configs": [
    {
      "id": "std_1020_45",          // 唯一 ID
      "label": "10-20 系统",         // 界面显示名
      "kind": "std_1020_45",        // kind：见下表
      "count": 45,                  // 通道数（自动维护）
      "channels": {                 // 通道名 -> 单位方向向量 [x, y, z]
        "Cz": [0.04023, 0.15186, -0.98758],
        "..."
      }
    }
  ]
}
```

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✓ | 唯一标识，切切不可重复；建议 `自定义名_导数` |
| `label` | ✓ | 下拉框里显示的名字 |
| `kind` | ✓ | `std_1020_45` / `std_1010_64`：由 10-20 规则推导，可用标定滑块；`custom`（或其他值）：按坐标原样显示，规则标定被禁用 |
| `count` | ✓ | 通道数，须与 `channels` 条目数一致 |
| `channels` | ✓ | 每个通道的三维单位方向向量（从球心指向头皮电极位置），坐标顺序与导出数据一致 |

`channels` 的**键顺序 = 数据通道顺序**（热图行序、导出行序），调整顺序等同于
重新排列数据列，务必谨慎。

## 三、使用方式

### 页面切换
图层面板（左上 ⏵ 展开）顶部「电极配置」下拉框选择。切换后电极、名称标签、
头皮电位着色、通道热图立即重建。只有「已导出」标记的配置拥有精确波形；
其余配置的新增通道波形为球面距离插值预览（标题会注明）。

### 精确导出
确定使用某套配置后，把它单独导出为布局文件交给 `export_data.py`：

```bash
python -c "import json;from pathlib import Path;c=json.loads(Path('viz/data/elec_configs.json').read_text());k=[x for x in c['configs'] if x['id']=='std_1010_64'][0];Path('viz/data/elec_layout_active.json').write_text(json.dumps(k['channels']))"
conda activate ffbm
python viz/export_data.py --elec-layout viz/data/elec_layout_active.json \
    --regions visual_bilateral,vpn_central,ol_rest,central_brain,vnc --gpu
```

耗时参考（2026-09-16 起：GPU 循环 ~2 min；核构建随导联数近似线性，
45 导实测 ~1-1.5 min；**每套电极配置的核缓存只建一次**，之后同配置
热跑 ~2.5 min 端到端）：

| 配置 | 首次核构建估计 | 首次完整导出估计（含装配） | 同配置热跑 |
|---|---|---|---|
| 45 导 | ~1.5 min | ~7.5 min | ~2.5 min |
| 64 导 | ~2 min | ~8 min | ~2.5 min |
| 128 导 | ~4 min | ~10 min | ~3.5 min |
| EGI 241 点位 | ~7-8 min | ~14 min | ~8 min |

（无 GPU 时循环段 ~47 min/次；早期"45 导核构建 361 s"为多线程优化前
的旧实测，已被路线 A 的 ~15× 取代。）

### 自定义布局
1. 编辑 `viz/data/elec_configs.json`，按上面格式追加一个条目
   （`kind` 用 `"custom"`）；
2. 刷新页面，在下拉框选择即可；
3. 注意：`channels` 内的方向向量必须归一化（单位长度），且键名不要与
   既有通道重复。

### 重新生成内置配置
内置三套配置由当前标定框架（`calib_1020_export.json` 里的手柄/ni/yaw/roll，
缺省时用脚本内 ANCHORS 常量）推导：

```bash
python viz/make_elec_configs.py
```

重新标定（ni/th/yaw/roll 变化）后运行一次，三套配置会同步更新到新框架。
依赖：10-5/128 配置的命名需要 MNE-Python（`pip install mne`），未安装时
跳过该配置，其余照常生成。

## 四、标定与配置的关系

- 10-20 标定模式（页面「10-20标定」按钮）调整的是**推导规则参数**
  （ni、th、yaw、roll），仅对 `std_1020_45` / `std_1010_64` 两套规则配置有效；
- 调整完成后「复制JSON」交给管线重新生成本文件与烘焙布局；
- 视角标定（「视角标定」按钮）与电极配置无关，只影响六个正交视图的相机方向。
