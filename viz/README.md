# 3D 可视化 — 从神经放电到脑电的实时演示

自包含的 Three.js 页面，回放一整段真实仿真（exp009 递质符号工作点，
左叶 1.9 万神经元 / 167 万突触连接组，**自然刺激协议** 10.5 s）：

**刺激协议**（六个时段，图表底部标注）：
黑暗 1.5s → 空间均匀 1/f 闪烁 3s → 1/f 纹理沿偏好方向漂移 1.5s →
同一影片时间反演 1.5s → DS 尺度带通纹理漂移 1.5s → 反演 1.5s。
连续自然刺激产生连续波动的前向电位（不是方波——方波只出现在
开关式闪光协议下）。

**左侧 3D 场景**（可拖动旋转/缩放/平移）：
- 五层神经元按真实三维坐标显示（紫=R1-R6 光感受器、蓝=L1-L3 板层、
  绿=Mi/Tm、红=T4、橙=T5），亮度与点径随该层瞬时放电率脉动
- 三级突触连接采样线随突触前层的活动闪烁（R→L→Mi/Tm→T4/T5 信息流）
- 三个虚拟电极（眼表面/板层/髓质）：圆环随该通道电位幅度搏动
- 头壳边界（exp008 密封球，线框）；闪光时段全场泛光 + 光感受器层增亮
- 左上角图层开关（每层/连接/电极/头壳可单独隐藏）
- **🧠 人脑壳视图**（右上按钮切换）：整个网络 ×400 缩放到人脑尺度，
  放进**四层同心球壳**——脑(灰)/**脑脊液**(浅蓝，σ=1.79)/颅骨(白)/头皮(粉)
  ——标准四球 EEG 前向模型（Rush-Driscoll 类，见 src/ffbm/forward.py
  FourSpherePairField，与三球壳退化一致到 1e-8）；
  网络**贴枕极**放置（T4/T5 端距颅骨内壁 1.5mm，像真实视觉皮层），
  相机默认从枕侧看；**17 个头皮电极**均匀贴在头皮球面上（0 号在眼轴
  方向，洋红色，其余按与眼轴夹角排序）；头皮球面按电位插值**实时着色**
  （脑电地形图：蓝=负、红=正）——枕极放置后最强信号移到高夹角电极，
  与真实视觉诱发电位拓扑一致

**右侧信号面板**（像脑电图机一样实时画出）：
- 刺激亮度波形 + 六时段颜色标注 + 交互：播放/暂停、重放、0.5–4× 速度、
  时间轴拖动、**近 2 秒放大**开关（看 On/Off 瞬变细节）
- 三通道电极电位（逐毫秒由突触电流前向生成）+ 第 4 通道**人脑头皮×400·眼轴**
  （粉色；果蝇尺度时幅度约 μV 级 ×400 面积 ×3 层壳衰减，视角切换不影响该曲线）
- **头皮电极阵列热图 ×17**：全部 17 个头皮通道按时间 × 通道排布（行按与
  眼轴夹角 0°→180° 排序，蓝−红+，右侧色标 μV）；**"叠加人脑背景脑电"
  开关**把闭眼 α 波（10Hz 枕区主导 ~30μV）+ 1/f 活动 + 传感器噪声加进
  全部头皮通道——叠加后信号被淹没（果蝇信号 0.74μV vs 背景 10μV），
  d′=2 需约 731 次试验平均（完全在常规 VEP 实验范围内）
- 仿真机制（2026-09-13 精度升级）：OU 色噪声背景（膜波动 ~4mV）、
  电导基突触（驱动力依赖 + 半隐式稳定积分）、全链路 1ms+轴突传导延迟、
  工作点第 3 轮校准（黑暗期 T4 5.8 / T5 5.0 Hz，文献窗内）
- 五层群体放电率——可看到 L 层在亮段**被抑制**（组胺能）、漂移反向时
  T4/T5 的响应差异

## 使用

```bash
cd viz
python -m http.server 8000        # 任意本地服务器；file:// 直接打开会被浏览器拦截
# 浏览器访问 http://localhost:8000
```

文件：`index.html`（页面）、`data/viz_data.json`（回放数据，1.1MB，
已入库开箱即用）、`vendor/`（Three.js r128 本地副本，离线可用）。

## 重新生成数据

```bash
python viz/export_data.py        # ~9 min；重跑一次仿真并导出
```

导出内容：各层全部神经元坐标（居中，μm）、~1400 条采样连接、电极与
头壳几何、1 kHz 的刺激/五层放电率/三通道电位 + 17 头皮通道时间序列
（头皮核按电极逐个构建，3 球壳解析解）。

## 已知简化

- 放电以"层平均速率调制点云亮度"呈现（逐脉冲渲染 2 万细胞尚不现实）；
  连接线为静态采样，透明度由突触前层活动驱动
- 电位绝对幅值未标定（沿用 exp009 工作点），形态与相对变化可信
